
```card

back: "D — между двумя чёрными. G и A — внутри группы из трёх: G слева, A справа."
tags: [music, keyboard, notes]
```

```card
front: "MIDI-номер middle C и правило пересчёта"
back: "C4 = 60. Плюс полутон = плюс 1, плюс октава = плюс 12. Значит C5 = 72, C3 = 48, A4 (440 Гц) = 69."

```

```card
front: "Почему DAW иногда показывает C3 там, где ждёшь C4"
back: "Буквенные имена октав не стандартизованы: научная нотация зовёт ноту 60 C4, а Yamaha исторически C3. Однозначен только номер 60."
tags: [music, keyboard, midi]
```

```card
front: "Сколько чёрных клавиш в октаве и как называется двойное имя чёрной клавиши"
back: "Пять. Двойное имя — энгармонизм: C# = Db, D# = Eb, F# = Gb, G# = Ab, A# = Bb."
```
