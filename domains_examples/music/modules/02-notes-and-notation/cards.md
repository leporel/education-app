# Карточки — ноты и нотация

Тридцать карточек на всю систему координат курса. Первые две группы — обязательный
минимум, без них дальше не идём. MIDI-группу проще всего вбить: там чистая арифметика.


```card
front: "MIDI-номера крайних клавиш рояля на 88 клавиш"
back: "A0 = 21 (самая низкая) и C8 = 108 (самая высокая)."
tags: [music, midi]
```

```card
front: "Формула MIDI-номера по имени ноты"
back: "MIDI = 12 × (номер октавы + 1) + позиция ноты в октаве, где C = 0, C# = 1, D = 2 ... B = 11. Пример: A4 = 12 × 5 + 9 = 69."
tags: [music, midi, formula]
```

```card
front: "Как из MIDI-номера получить имя ноты и октаву"
back: "Позиция = n % 12 (0 = C ... 11 = B), октава = n / 12 − 1 целочисленно. Пример: 67 → 67 % 12 = 7 → G, 67 / 12 − 1 = 4 → G4."
tags: [music, midi, formula]
```

```card
front: "Формула частоты по MIDI-номеру"
back: "частота = 440 × 2^((n − 69) / 12). Для n = 81 получается 880 Гц, для n = 60 — примерно 261.63 Гц."
tags: [music, midi, frequency, formula]
```

```card
front: "Во сколько раз меняется частота на один полутон"
back: "В 2^(1/12) ≈ 1.0595 раза, то есть примерно на 5.9 %. Двенадцать таких шагов дают ровно ×2."
tags: [music, frequency, temperament]
```

```card
front: "MIDI-номера открытых струн гитары"
back: "E2 = 40, A2 = 45, D3 = 50, G3 = 55, B3 = 59, E4 = 64."
tags: [music, midi, guitar]
```

```card

back: "MIDI-номер 60 — это C4 в научной нотации и C3 в системе Yamaha/Cubase. Разница ровно в октаву в подписи. Доверяйте номеру, а не букве."
```
