# Модуль 04 — Типы, структуры, enum и сопоставление

> Теперь, когда владение уложено, строим из него данные. Здесь Rust по-настоящему расходится
> с Go: **есть настоящие сумм-типы** (`enum`), **исчерпывающий `match`**, и **нет `nil`** —
> вместо него `Option<T>`, который заставляет обработать «ничего». Для Go-разработчика это,
> возможно, самый приятный модуль: половина классических nil-багов тут невозможна.

## Цель

После модуля ты:

1. Знаешь скалярные и составные типы (числа, `bool`, `char`, кортежи, массивы) и явные
   правила приведения; помнишь про выражения-`if`/`loop`, shadowing, `const`/`static` и
   циклы с `break`-значением.
2. Объявляешь `struct` (три вида), пишешь методы в блоке `impl`, понимаешь `self`/`&self`/`&mut self`.
3. Используешь `enum` как сумм-тип с данными внутри вариантов — то, чего в Go нет.
4. Разбираешь значения через `match` (включая guards, `@`, `..`, `matches!`) и понимаешь,
   почему **исчерпываемость** — это сила.
5. Заменяешь `nil` на `Option<T>` и обрабатываешь его через `match`, `if let`, `let else`,
   и комбинаторы (`map`, `unwrap_or`).
