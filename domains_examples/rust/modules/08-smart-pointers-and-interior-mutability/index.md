# Модуль 08 — Умные указатели и внутренняя изменяемость

> «Один владелец» — отличное правило, но иногда жизни нужно больше: значение в куче с
> рекурсией (`Box`), несколько владельцев одних данных (`Rc`/`Arc`), изменение через
> неизменяемую ссылку (`Cell`/`RefCell`). Это «клапаны давления» поверх строгих правил —
> с понятной ценой и понятными рисками. И `Arc` здесь — прямой мост в конкурентность (модуль 09).

## Цель

После модуля ты:

1. Используешь `Box<T>` для размещения значения в куче и для рекурсивных типов.
2. Понимаешь `Rc<T>` (несколько владельцев, подсчёт ссылок, один поток) и его потокобезопасного
   брата `Arc<T>`.
3. Понимаешь **внутреннюю изменяемость**: `Cell<T>`/`RefCell<T>` — менять данные через `&`,
   с проверкой правил заёма **в рантайме** (а не на компиляции).
4. Знаешь паттерн `Rc<RefCell<T>>` (общий изменяемый узел) и его опасности.
5. Понимаешь утечки через циклы `Rc` и лечение через `Weak<T>`.
6. Пользуешься шпаргалкой выбора «значение → `Box` → `Rc` → `RefCell` → `Arc<Mutex>`» и
   понимаешь, почему спускаться по ней надо неохотно.
7. Знаешь, как сделать «инициализировать один раз» без `static mut` (`OnceLock`).
