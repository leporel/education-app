# Модуль 01 — JavaScript под капотом TypeScript

> «TypeScript — это JavaScript, который сходил к репетитору». Но репетитор не меняет
> характер ученика. Чтобы понять TS, надо сперва познакомиться с самим JavaScript —
> со всеми его причудами.

## Цель

После модуля ты:

1. Понимаешь, что TypeScript — это **надстройка над JavaScript**, и почему типы
   полностью исчезают перед запуском.
2. Уверенно владеешь базовой моделью JS: значения и типы, `let`/`const`, функции как
   значения, **замыкания**, коварный `this`, **прототипы** вместо классов.
3. Свободно читаешь повседневный синтаксис: объекты и массивы, методы массивов,
   **деструктуризацию**, `...` (spread/rest), опциональную цепочку `?.` — и помнишь про
   **ссылочную семантику** объектов.
4. Понимаешь, как в JS устроены ошибки (`throw` / `try/catch`) и почему это не Go-шный
   `(value, error)`.
5. Знаешь, чем `null` отличается от `undefined`, почему `0.1 + 0.2 !== 0.3`, и за что
   все ненавидят `==`.
6. Имеешь интуицию про **event loop** — почему JS однопоточный, но «не висит».
7. Можешь читать чужой JS-код и не пугаться.

## Предпосылки

- Опыт программирования (у тебя есть — Go). Никакого JS знать заранее не нужно.

## Порядок прохождения

1. Прочитать `theory.md` целиком — это фундамент, без него дальше будет вязко.
2. Пройти урок `lessons/01-values-and-closures.md`.
3. Пройти урок `lessons/02-objects-arrays-destructuring.md`.
4. Прогнать `drills.md`, параллельно запустить SRS по `cards.md`.

В конце `theory.md` есть **глоссарий** — если по ходу встретилось незнакомое слово
(«рантайм», «hoisting», «мутация»), сначала заглядывай туда.

## Зачем это вообще

Соблазн — пропустить «джаваскрипт» и сразу пойти «к типам». Это ловушка. Половина
загадочных ошибок TypeScript на самом деле — поведение JavaScript, которое TS честно
описывает, но не может отменить. Понимая рантайм, ты перестаёшь спорить с компилятором
и начинаешь с ним сотрудничать.
