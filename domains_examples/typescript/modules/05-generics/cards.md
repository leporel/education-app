# Карточки

## Основы

```card
front: Что такое параметр типа <T> в дженерике?
back: Переменная для типов (не для значений). При вызове на её место подставляется конкретный тип, связь между местами использования сохраняется.
tags: [ts, generics]
```

```card
front: Нужно ли указывать <T> при каждом вызове дженерик-функции?
back: Обычно нет — TS выводит T из аргументов. Явно указывают, только когда выводить неоткуда (например, first<number>([])).
tags: [ts, generics, inference]
```

```card
front: Почему с чистым <T> (без ограничений) почти ничего нельзя делать внутри функции?
back: T может быть любым типом, поэтому нет гарантированных свойств/методов. Чтобы что-то использовать, нужно ограничение extends.
tags: [ts, generics]
```

## Ограничения

```card
front: Как ограничить T типами, у которых есть свойство length?
back: "function f<T extends { length: number }>(x: T) — T extends { length: number } требует наличие length:number."
tags: [ts, generics, constraints]
```

```card
front: Чем ограничения дженериков в TS отличаются от Go?
back: "В Go ограничение — интерфейс (методы) или type set. В TS — любой тип-выражение: форма объекта, union, keyof T, другой параметр типа. Гибче."
tags: [ts, generics, go]
```

```card
front: "Что делает сигнатура getProp<T, K extends keyof T>(obj: T, key: K): T[K]?"
back: "Типобезопасный доступ к свойству: K — любой ключ объекта T, T[K] — тип значения под этим ключом. Несуществующий ключ запрещён, тип результата точен."
tags: [ts, generics, keyof]
```

## Default и контейнеры

```card
front: Что такое default-параметр типа? Пример.
back: "Тип по умолчанию для дженерика: type ApiResponse<T = unknown> = {...}. Используется, если тип не указан явно."
tags: [ts, generics, default]
```

```card
front: Можно ли параметризовать класс? Что даёт class Stack<T>?
back: Да. Stack<number> — типобезопасный стек чисел, Stack<string> — строк. Один класс, множество типобезопасных применений.
tags: [ts, generics, class]
```

## Вариантность и здравый смысл

```card
front: Если Dog — подтип Animal, можно ли Dog[] использовать как Animal[]?
back: "Для чтения — да (ковариантность): читать собак как животных безопасно. При записи TS местами оптимистичен. Это явление называется вариантностью."
tags: [ts, variance]
```

```card
front: "Эвристика: когда параметр типа <T> лишний?"
back: Если он встречается в сигнатуре только один раз и ни с чем не связан. Дженерик нужен, чтобы СВЯЗАТЬ несколько мест одним типом (вход-выход, аргументы, контейнер-содержимое).
tags: [ts, generics, style]
```

## Дженерики и рантайм

```card
front: В чём принципиальная разница между <T> и any?
back: "any ВЫКЛЮЧАЕТ проверку типов, дженерик её ПЕРЕНОСИТ: тип с места вызова доезжает до результата. firstAny(['hi']) даёт any, firstT(['hi']) даёт string | undefined."
tags: [ts, generics, any]
```

```card
front: Почему внутри дженерика нельзя написать new T() или x instanceof T?
back: "Параметры типа стираются при компиляции — в рантайме имени T нет. Нужный приём: передать фабрику (() => T) или конструктор (new (...args) => T) аргументом."
tags: [ts, generics, erasure]
```

```card
front: Как принято называть параметры типа?
back: T (type), K (key), V (value), E (element/error), U/R для второго типа и результата. Для сложных API — осмысленно (TItem, TResult).
tags: [ts, generics, style]
```
