# Урок 02 — Лаборатория битов: двоичная, hex и маски

## Разогрев

- Одна hex-цифра = 4 бита, один байт = две hex-цифры. Одна восьмеричная цифра = 3 бита.
- `x % 2ᵏ = x & (2ᵏ − 1)` и `x / 2ᵏ = x >> k` — для неотрицательных x.
- `x & (x−1)` сбрасывает младший установленный бит, `x & (−x)` его выделяет.

Подробности — во [второй части теории](../theory-2-binary-and-bits.md).

## Упражнение 1. Перевод туда и обратно

Возьмём число 202 и прогоним его по кругу 10 → 2 → 16 → 10.

```text
202 / 2 = 101, ост. 0
101 / 2 =  50, ост. 1
 50 / 2 =  25, ост. 0
 25 / 2 =  12, ост. 1
 12 / 2 =   6, ост. 0
  6 / 2 =   3, ост. 0
  3 / 2 =   1, ост. 1
  1 / 2 =   0, ост. 1
снизу вверх: 11001010₂
группами по 4: 1100 1010 → C A → 0xCA
обратно: 0xCA = 12·16 + 10 = 192 + 10 = 202 ✓
```

Обратите внимание: между двоичной и hex мы не делили вообще — только перегруппировали.
Это и есть вся выгода шестнадцатеричной записи.

```drill
type: fill-in
prompt: "Запишите 0xB7 в двоичной системе (8 цифр, без префикса)."
answer: "10110111"
check: exact
hint: "B = 1011, 7 = 0111"
```

## Упражнение 2. Маски флагов

Смоделируем набор прав. Три бита, значения от 0 до 7 — те самые «восьмеричные» права Unix.

```go
type Perm uint8

const (
	Exec  Perm = 1 << 0 // 001
	Write Perm = 1 << 1 // 010
	Read  Perm = 1 << 2 // 100
)

func (p Perm) Has(f Perm) bool { return p&f != 0 }
func (p Perm) With(f Perm) Perm { return p | f }
func (p Perm) Without(f Perm) Perm { return p &^ f } // AND NOT
```

Разберём `chmod 640` руками:

```text
6 = 110 → Read|Write        — владелец читает и пишет
4 = 100 → Read              — группа только читает
0 = 000 →                   — остальные ничего
```

И встречный вопрос: что такое `0755`? `7 = 111` (rwx), `5 = 101` (r-x), `5 = 101` (r-x) —
классические права исполняемого файла.

```drill
type: fill-in
prompt: "Права заданы восьмерично как 0644. Сколько бит в этом числе установлено (единиц в двоичной записи)?"
answer: "4"
check: exact
hint: "6 = 110 (две единицы), 4 = 100 (одна), 4 = 100 (одна)"
```

## Упражнение 3. Popcount своими руками

Классический трюк Кернигана: пока число не ноль, сбрасываем младший установленный бит и
считаем итерации. Число итераций равно числу единиц, а не числу битов — для разреженных
масок это заметно быстрее наивного цикла по 64 позициям.

```go
func popcount(x uint64) int {
	n := 0
	for x != 0 {
		x &= x - 1 // убрали одну единицу
		n++
	}
	return n
}
```

Проследим на 0b10110100 (180):

```text
шаг 0: 1011 0100
шаг 1: 1011 0000   — сбросили бит 2
шаг 2: 1010 0000   — сбросили бит 4
шаг 3: 1000 0000   — сбросили бит 5
шаг 4: 0000 0000   — сбросили бит 7
итого 4 единицы
```

В продакшене, конечно, `bits.OnesCount64` — одна процессорная инструкция. Но понимать, что
там внутри, полезно: тот же приём лежит в основе перебора всех подмножеств маски.

## Упражнение 4. Переполнение вживую

```go
var a int32 = math.MaxInt32
fmt.Println(a, a+1) // 2147483647 -2147483648

lo, hi := 0, math.MaxInt32
fmt.Println((lo + hi) / 2)   // работает
lo, hi = math.MaxInt32-1, math.MaxInt32
fmt.Println((lo + hi) / 2)   // здесь int32 уже переполнился бы
fmt.Println(lo + (hi-lo)/2)  // безопасный вариант
```

Математически `a + 1` не «сломалось» — оно посчиталось по модулю 2³², а результат
интерпретирован в дополнительном коде. Это ровно то же кольцо вычетов, что и в задаче про
часы, просто модуль равен 4294967296.


## Упражнение 5. Остаток по степени двойки

Проверим равенство `x % 16 == x & 15` и убедимся, что для отрицательных оно ломается.

```go
for _, x := range []int{0, 6, 15, 16, 214, -1} {
	fmt.Println(x, x%16, x&15)
}
// -1 %16 = -1, но -1 & 15 = 15 — расхождение
```

Для `-1` обе формулы «правы по-своему»: `&` даёт математический остаток 15, а `%` — знаковый
−1. Ещё один повод помнить про `((x % n) + n) % n`.

```drill
type: free-form
prompt: "Объясните, почему x & (2ᵏ − 1) равно x mod 2ᵏ для неотрицательных x. Опирайтесь на позиционную запись."
answer: "2ᵏ − 1 — это маска из k младших единиц. AND с ней обнуляет все разряды с весами 2ᵏ и выше. Но каждый такой разряд вносит вклад, кратный 2ᵏ, то есть на остаток по модулю 2ᵏ не влияет. Остаётся ровно сумма младших k разрядов, а это и есть остаток."
check: manual
```

## Итог

Двоичная и шестнадцатеричная системы — это не «другие числа», а другая одежда на тех же
величинах, и переход между ними бесплатный, потому что 16 = 2⁴. Битовые операции — это
поразрядная логика, выполняемая за один такт; из неё вырастают маски флагов, popcount и
проверка степени двойки. Переполнение целых — не авария, а арифметика по модулю 2ⁿ, и
единственные места, где о ней надо помнить специально, — суммы больших индексов и
произведения. Дальше — [урок 03](./03-hashing-and-huge-numbers.md), где мы соединим биты
с хешированием и научимся оценивать «сколько это, 2¹²⁸».
