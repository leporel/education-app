# Урок 02 — Читаем и рисуем графики

Теория к уроку: [`theory-2-functions-and-logarithms.md`](../theory-2-functions-and-logarithms.md).

График — это не украшение к формуле, а способ увидеть поведение целиком. Программисту
это знакомо: график латентности на дашборде говорит больше, чем таблица из тысячи строк.
В этом уроке две задачи: **научиться вытаскивать факты из готового графика** и
**набрасывать график по формуле от руки**, без калькулятора.

## Что вообще можно прочитать с графика

Смотрим на картинку и отвечаем на пять вопросов:

1. **Где функция определена.** Есть ли дырки, вертикальные обрывы, обрезанный слева край.
2. **Нули функции.** Точки пересечения с осью `x` — там, где `f(x) = 0`.
3. **Значение при `x = 0`.** Точка пересечения с осью `y`.
4. **Растёт или убывает** и на каких участках. Где меняется направление.
5. **Куда уходит на краях.** Растёт неограниченно, выходит на полку, прижимается к
   асимптоте.

Потренируемся на конкретной картинке:

```text
  y
  4│  •                              •
  3│
  2│     •                        •
  1│
  0├────────•──────────────•──────────► x
 -1│           •        •
 -2│              •  •
    ─────┬────┬────┬────┬────┬────┬───
        -2   -1    0    1    2    3
```

Что читается: функция определена везде, нулей два (примерно при `x = −1` и `x = 3`),
при `x = 0` значение отрицательное, сначала убывает, потом растёт, минимум около `x = 1`,
на краях уходит вверх. Это парабола, направленная вверх, со сдвинутой вершиной —
что-то вида `y = (x − 1)² − 4`. Проверим нули: `(x − 1)² = 4` даёт `x − 1 = ±2`,
то есть `x = 3` и `x = −1`. Совпало с картинкой.

```drill
type: multiple-choice
prompt: "На графике функция определена при всех x, кроме одной точки; слева от этой точки значения уходят вниз без предела, справа — вверх без предела, а при больших по модулю x график прижимается к оси x. Какая это функция?"
options: ["y = x²", "y = 1/x", "y = √x", "y = abs(x)"]
answer: "y = 1/x"
check: exact
hint: "две асимптоты — обе оси координат"
```

## Рисуем прямую y = kx + b

Прямая задаётся двумя числами, поэтому и рисуется по двум точкам. Проще всего взять
пересечения с осями.

Возьмём `y = 2x − 4`.

```text
x = 0  →  y = −4            — точка (0, −4), пересечение с осью y
y = 0  →  2x − 4 = 0        — приравняли к нулю
          x = 2             — точка (2, 0), пересечение с осью x
```

```text
  y
  2│                    ╱
  0├──────────────╱───────────► x
 -2│        ╱
 -4├──╱  ← b = −4
    ┬────┬────┬────┬────┬──
   -1    0    1    2    3
   наклон k = 2: шаг вправо на 1 поднимает линию на 2
```

Смысл коэффициентов стоит проговорить вслух: `b` — где линия стартует на вертикальной
оси, `k` — на сколько она поднимается за один шаг вправо. Если `k` отрицательный, линия
идёт вниз. Если `k = 0` — горизонталь `y = b`.

## Рисуем параболу y = x²

Парабола рисуется по вершине и симметрии. Вершина `y = x²` — в точке `(0, 0)`, дальше
достаточно посчитать три точки справа и отразить их налево.

```text
x = 1  →  y = 1
x = 2  →  y = 4
x = 3  →  y = 9
```

```text
  y
  9│  •                       •
  4│    •                  •
  1│      •            •
  0└────────•──────•──────────► x
    -3  -2  -1  0  1  2  3
```

Главное, что нужно унести: расстояния между точками растут — `1, 4, 9` вместо `1, 2, 3`.
Это и есть «квадратичный рост» в живом виде: удвоив `x`, значение увеличиваем вчетверо.
Ровно так же ведёт себя алгоритм с двойным вложенным циклом.

## Рисуем гиперболу y = 1/x и модуль y = abs(x)

Для гиперболы считаем точки по обе стороны от нуля:

```text
x = 0.25 → y = 4        x = −0.25 → y = −4
x = 0.5  → y = 2        x = −0.5  → y = −2
x = 1    → y = 1        x = −1    → y = −1
x = 2    → y = 0.5      x = −2    → y = −0.5
x = 4    → y = 0.25     x = −4    → y = −0.25
```

```text
  y
  4│ •
  2│   •
  1│      •
  0├────────•───•───•─────► x   (асимптота y = 0)
 -1│  •
 -2│ •
    ↑ асимптота x = 0
```

Ноль в область определения не входит, и «дырка» на графике — это ровно то же самое, что
паника при делении на ноль в коде. Обе ветви к осям приближаются, но не касаются.

Модуль рисуется ещё проще: правая половина — это прямая `y = x`, левая — её зеркальное
отражение `y = −x`.

```text
  y
  3│ ╲                 ╱
  2│   ╲             ╱
  1│     ╲         ╱
  0└───────╲─────╱────────► x
    -3  -2  -1  0  1  2  3
```

Излом в нуле — не дефект рисунка, а честное свойство функции: слева она убывает,
справа растёт, и «поворот» происходит мгновенно. У параболы дно круглое, у модуля —
острое, и это различие вполне практическое: методы, которые ищут минимум, двигаясь по
наклону, на круглом дне сходятся спокойно, а на остром начинают перепрыгивать точку
минимума туда-сюда. Отсюда, например, разница в поведении регуляризаций, построенных
на квадрате и на модуле.

Полезно также заметить, что все четыре графика этого урока рисуются одним и тем же
приёмом: посчитать три-четыре удобные точки, отметить особенности (пересечения с осями,
вершину, асимптоты, излом) и соединить их плавной линией. Никакой отдельной техники
для каждой функции запоминать не нужно.

```drill
type: free-form
prompt: "Постройте от руки график y = −x + 3. Найдите обе точки пересечения с осями, скажите, растёт функция или убывает, и объясните, как это видно из знака k."
answer: "При x = 0 получаем y = 3 — точка (0, 3). При y = 0 получаем x = 3 — точка (3, 0). k = −1 отрицательный, значит шаг вправо опускает линию на 1: функция убывает на всей области определения."
check: manual
```

```drill
type: fill-in
prompt: "Функция y = x² − 9. В каких точках её график пересекает ось x? Перечислите через запятую по возрастанию."
answer: "-3, 3 | −3, 3 | -3,3"
check: fuzzy
hint: "приравняйте к нулю и вспомните разность квадратов"
```

## Итог

- С графика читаются пять вещей: область определения, нули, значение в нуле,
  участки роста и убывания, поведение на краях.
- Прямая `y = kx + b` рисуется по двум точкам; `b` — старт на оси `y`, `k` — подъём за
  шаг вправо. Отрицательный `k` — убывание.
- Парабола `y = x²` — по вершине и симметрии; расстояния между значениями растут, это
  и есть квадратичный рост.
- Гипербола `y = 1/x` — две ветви и две асимптоты; ноль исключён из области определения,
  как деление на ноль исключено в коде.
- Модуль `y = abs(x)` — галочка: справа `y = x`, слева `y = −x`, излом в нуле.
- Полезная привычка: увидев формулу, за десять секунд набросать форму графика. Это тот
  же навык, что «увидев цикл в цикле, ожидать квадратичного времени».
