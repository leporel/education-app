# Карточки

Определения, обозначения, формулы и несколько карточек «что здесь не так» — в них
на лицевой стороне написана распространённая ошибка, а на обороте объяснение.

## Выражения и разложение на множители

```card
front: "Чем выражение отличается от уравнения?"
back: "Выражение — рецепт вычисления (2x + 6), даёт число по заданному x. Уравнение — утверждение о равенстве двух выражений (2x + 6 = 14), верное лишь при некоторых x. Уравнение решают, выражение вычисляют."
tags: [algebra, definitions]
```

```card
front: "Распределительный закон и что происходит с минусом перед скобкой"
back: "a(b + c) = ab + ac. Минус перед скобкой меняет знак каждого слагаемого внутри: −(b + c) = −b − c. Поэтому 5 − (x + 2) = 3 − x."
tags: [algebra, simplification]
```

```card
front: "(a + b)² = ?"
back: "a² + 2ab + b². Слагаемое 2ab — площадь двух прямоугольников a×b в разрезанном квадрате со стороной a + b."
tags: [algebra, formulas]
```

```card
front: "(a − b)² = ?"
back: "a² − 2ab + b². Знак меняется только у среднего члена; b² остаётся положительным."
tags: [algebra, formulas]
```

```card
front: "a² − b² = ?"
back: "(a − b)(a + b) — разность квадратов. Один из самых полезных приёмов разложения на множители."
tags: [algebra, formulas]
```

```card
front: "(a + b)³ и (a − b)³ = ?"
back: "(a + b)³ = a³ + 3a²b + 3ab² + b³; (a − b)³ = a³ − 3a²b + 3ab² − b³. Коэффициенты 1, 3, 3, 1; во втором случае знаки чередуются."
tags: [algebra, formulas]
```

```card
front: "a³ + b³ и a³ − b³ = ?"
back: "a³ + b³ = (a + b)(a² − ab + b²); a³ − b³ = (a − b)(a² + ab + b²). Мнемоника — «неполный квадрат с противоположным знаком в середине»."
tags: [algebra, formulas]
```

```card
front: "Что здесь не так? (a + b)² = a² + b²"
back: "Потеряно слагаемое 2ab. Проверка на a = b = 1: слева (1 + 1)² = 4, справа 1 + 1 = 2. Верно: (a + b)² = a² + 2ab + b²."
tags: [algebra, mistakes]
```

```card
front: "Три способа разложить выражение на множители"
back: "1) вынести общий множитель: 6x² + 9x = 3x(2x + 3); 2) узнать формулу: x² − 25 = (x − 5)(x + 5); 3) группировка: x³ + x² + x + 1 = (x + 1)(x² + 1). Плюс через корни: ax² + bx + c = a(x − x₁)(x − x₂)."
tags: [algebra, factoring]
```

## Уравнения и неравенства

```card
front: "Какие преобразования уравнения законны (равносильны)?"
back: "Прибавить или вычесть одно и то же из обеих частей; умножить или разделить обе части на ненулевое число; раскрыть скобки и привести подобные внутри части. Деление на выражение, которое может быть нулём, — не законно."
tags: [algebra, equations]
```

```card
front: "Решение линейного уравнения ax + b = 0"
back: "x = −b/a при a ≠ 0. Если a = 0 и b = 0 — решением является любое x; если a = 0, а b ≠ 0 — решений нет."
tags: [algebra, equations]
```

```card
front: "Когда знак неравенства переворачивается?"
back: "При умножении или делении обеих частей на отрицательное число. Прибавление и вычитание знак не меняют. Проверка: 3 < 5, умножаем на −2, получаем −6 > −10."
tags: [algebra, inequalities]
```

```card
front: "Что здесь не так? Из −2x < 6 следует x < −3"
back: "Делили на −2 — отрицательное число, значит знак должен перевернуться: x > −3. Проверка подстановкой x = 0: −0 < 6 верно, значит 0 входит в ответ, а в x < −3 он не входит."
tags: [algebra, mistakes, inequalities]
```

```card
front: "Что такое дискриминант и что он различает?"
back: "D = b² − 4ac для уравнения ax² + bx + c = 0. При D > 0 два разных корня, при D = 0 один, при D < 0 вещественных корней нет."
tags: [algebra, quadratic]
```

```card
front: "Формула корней квадратного уравнения"
back: "x = (−b ± √D)/(2a), где D = b² − 4ac, a ≠ 0. Знаменатель 2a — целиком, ошибка «делить только первое слагаемое» очень частая."
tags: [algebra, quadratic]
```

```card
front: "Формулы Виета"
back: "Для ax² + bx + c = 0: x₁ + x₂ = −b/a и x₁·x₂ = c/a. Для приведённого x² + px + q = 0: сумма корней −p, произведение q. Быстрый способ угадать целые корни и проверить найденные."
tags: [algebra, quadratic]
```

```card
front: "Что здесь не так? В уравнении 2x² − 7x + 3 = 0 дискриминант равен −49 − 24"
back: "b = −7, значит b² = 49, а не −49: квадрат отрицательного числа положителен. Правильно D = 49 − 24 = 25."
tags: [algebra, mistakes, quadratic]
```

## Системы и пропорции

```card
front: "Два способа решить систему двух линейных уравнений"
back: "Подстановка — выразить одну переменную и подставить во второе уравнение. Сложение (elimination) — сложить или вычесть уравнения так, чтобы одна переменная исчезла."
tags: [algebra, systems]
```

```card
front: "Геометрический смысл системы двух линейных уравнений"
back: "Каждое уравнение — прямая на плоскости, решение — точка пересечения. Три случая: пересекаются (одно решение), параллельны (решений нет, получается 0 = 5), совпадают (бесконечно много, получается 0 = 0)."
tags: [algebra, systems]
```

```card
front: "Главное свойство пропорции"
back: "a/b = c/d ⇔ a·d = b·c при b ≠ 0 и d ≠ 0 — «умножение крест-накрест». Зная три числа из четырёх, четвёртое находят одним умножением и одним делением."
tags: [algebra, proportions]
```

## Функции и графики

```card
front: "Определение функции"
back: "Правило, которое каждому элементу области определения сопоставляет ровно один элемент результата. Один вход — один выход. Формула лишь один из способов задать правило; годятся таблица, график или код."
tags: [algebra, functions]
```

```card
front: "Что такое область определения и множество значений?"
back: "Область определения (domain) — все допустимые входы. Множество значений (range) — все достижимые выходы. Ограничения обычно возникают из трёх запретов: деление на ноль, чётный корень из отрицательного, логарифм неположительного."
tags: [algebra, functions]
```

```card
front: "Что означают k и b в y = kx + b?"
back: "k — угловой коэффициент, наклон: на сколько вырастет y при увеличении x на 1. b — сдвиг по вертикали, значение при x = 0. При k > 0 прямая идёт вверх, при k < 0 вниз, при k = 0 горизонтальна."
tags: [algebra, graphs]
```

```card
front: "Форма графиков y = x², y = 1/x, y = √x, y = abs(x)"
back: "x² — парабола, вершина в нуле, симметрична, растёт всё быстрее. 1/x — гипербола из двух ветвей, асимптоты x = 0 и y = 0. √x — половина параболы набок, только x ≥ 0, растёт всё медленнее. Модуль — галочка с изломом в нуле."
tags: [algebra, graphs]
```

```card
front: "Что такое асимптота?"
back: "Прямая, к которой график подходит сколь угодно близко, но не достигает её. У y = 1/x асимптоты — обе оси координат."
tags: [algebra, graphs]
```

## Экспонента и логарифм

```card
front: "Чем показательная функция отличается от степенной?"
back: "В показательной переменная стоит в показателе (y = 2ˣ), в степенной — в основании (y = x²). При x = 10 это 1024 против 100, при x = 20 разница уже в тысячи раз."
tags: [algebra, exponent]
```

```card
front: "Определение логарифма"
back: "log_a(b) = c равносильно aᶜ = b, при a > 0, a ≠ 1, b > 0. Словами — «в какую степень возвести a, чтобы получить b». Логарифм это просто степень, записанная с другого конца."
tags: [algebra, logarithm]
```

```card
front: "Три главных закона логарифма"
back: "log_a(x·y) = log_a x + log_a y; log_a(x/y) = log_a x − log_a y; log_a(xⁿ) = n·log_a x. Логарифм превращает умножение в сложение — ради этого его и придумали."
tags: [algebra, logarithm]
```

```card
front: "Чему равны log_a(1), log_a(a), a^(log_a x), log_a(aˣ)?"
back: "log_a(1) = 0, log_a(a) = 1, a^(log_a x) = x при x > 0, log_a(aˣ) = x. Последние два выражают то, что возведение в степень и логарифм — взаимно обратные операции."
tags: [algebra, logarithm]
```

```card
front: "Формула перехода к другому основанию"
back: "log_a x = log_b x / log_b a. Нужна, потому что библиотеки обычно дают только натуральный и десятичный логарифм. Пример: log₂ 1000 = log₁₀ 1000 / log₁₀ 2 ≈ 3/0.30103 ≈ 9.97."
tags: [algebra, logarithm]
```

```card
front: "Почему в оценках сложности не пишут основание логарифма?"
back: "Из формулы перехода log_a n = log_b n / log_b a: логарифмы по разным основаниям отличаются постоянным множителем, не зависящим от n. Поэтому O(log₂ n) и O(log₁₀ n) — один класс роста."
tags: [algebra, logarithm, growth]
```

```card
front: "Что здесь не так? log(x + y) = log x + log y"
back: "В сумму раскладывается логарифм произведения, а не суммы. Проверка: log₂(4 + 4) = log₂ 8 = 3, но log₂ 4 + log₂ 4 = 4. Верно: log(xy) = log x + log y."
tags: [algebra, mistakes, logarithm]
```

```card
front: "Сколько бит нужно для N различных значений?"
back: "Потолок от log₂ N, то есть ⌈log₂ N⌉: b бит кодируют 2ᵇ комбинаций, нужно 2ᵇ ≥ N. Для N = 1000 это 10 бит. Тем же числом выражается количество шагов бинарного поиска."
tags: [algebra, logarithm, code]
```

```card
front: "Что такое число e и чем оно особенное?"
back: "e ≈ 2.718281828, число Эйлера, основание натурального логарифма ln. Особенность: у функции eˣ скорость роста в каждой точке равна самому значению функции."
tags: [algebra, exponent]
```

```card
front: "Что такое логарифмическая шкала и зачем она на дашбордах?"
back: "Ось, где равные отрезки означают равные отношения (1, 10, 100, 1000), а не равные разности. Позволяет уместить на одном графике и 10 мс, и 10 с; экспоненциальный рост на ней выглядит прямой линией."
tags: [algebra, logarithm, code]
```
