## Блок 4. Объяснить своими словами

```drill
type: free-form
prompt: "Объясните коллеге, почему в записи O(log n) не указывают основание логарифма, а в O(2ⁿ) основание принципиально. Приведите формулы."
answer: "Смена основания логарифма — умножение на константу (log_a n = log_b n / log_b a), а константы в big-O выбрасываются. У экспоненты основание сидит в показателе: 3ⁿ = 2^(n·log₂3), то есть показатель умножается на 1.585, и это меняет класс роста."
check: manual
```

```drill
type: free-form
prompt: "Ваш сервис при аварии зависимости уходит в шторм ретраев. Опишите схему backoff с jitter, объясните роль каждого элемента (base, cap, 2^k, случайность) и что сломается, если убрать любой из них."
answer: "base задаёт стартовую паузу; 2^k быстро разводит попытки одного клиента; cap не даёт задержке уйти в часы и защищает от переполнения; jitter random(0, delay) разводит попытки разных клиентов, без него тысяча клиентов синхронно бьёт по восстанавливающемуся сервису (thundering herd)."
check: manual
```

```drill
type: free-form
prompt: "Объясните, что такое производная, в терминах вашего мониторинга: приведите два примера метрик, где одна является производной другой, и укажите единицы измерения."
answer: "Пример: счётчик обработанных запросов (штук) и RPS (штук в секунду) — RPS есть производная счётчика по времени. Второй пример: занятое место на диске (ГБ) и скорость заполнения (ГБ в сутки); деление свободного места на эту производную даёт прогноз времени до заполнения."
check: manual
```

```drill
type: free-form
prompt: "Вам показывают график «средний CPU за 5 минут» и утверждают, что сервис не нагружен. Объясните через интеграл, что именно усредняется, и почему такой график может скрывать проблему."
answer: "График показывает (1/T)·∫ load(t) dt по окну T = 5 минут, то есть площадь под кривой нагрузки, поделённую на длину окна. Короткий пик до 100 % на 10 секунд почти не поднимает среднее, но именно он даёт таймауты. Нужно смотреть максимумы и процентили, а не только среднее."
check: manual
```
