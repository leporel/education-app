# Карточки

## Рост и big-O

```card
front: Иерархия роста от самой быстрой функции к самой медленной
back: 1 < log n < √n < n < n log n < n² < n³ < 2ⁿ < n!
hint: Между n и n² «прячется» n log n
tags: [growth]
```

```card
front: "T(n) = O(f(n)) — что это значит формально?"
back: "Существуют c > 0 и n₀ такие, что T(n) ≤ c·f(n) для всех n ≥ n₀. То есть начиная с некоторого размера входа T растёт не быстрее f с точностью до константы."
tags: [big-o]
```

```card
front: Чем Θ(f) отличается от O(f)
back: "O — только верхняя граница (не быстрее f). Θ — одновременно верхняя и нижняя, точная оценка роста. n = O(n²) верно, но n = Θ(n²) — нет."
tags: [big-o]
```

```card
front: Что означает Ω(f)
back: Нижняя граница роста — функция растёт не медленнее f с точностью до константы.
tags: [big-o]
```

```card
front: Два правила упрощения выражения до big-O
back: "1) выбросить константные множители (5n → n); 2) выбросить младшие слагаемые (n² + 100n + 5000 → n²)."
tags: [big-o]
```

```card
front: Почему в O(log n) не пишут основание логарифма
back: "Смена основания — умножение на константу: log_a n = log_b n / log_b a, а константы в big-O выбрасываются."
tags: [logs]
```

```card
front: А почему в O(2ⁿ) основание важно
back: "Потому что константа попадает в показатель: 3ⁿ = 2^(n·log₂3), то есть показатель умножается, а не сама функция."
tags: [logs]
```

```card
front: Сколько примерно шагов сделает алгоритм O(n²) при n = 10⁶ и сколько это времени при 10⁹ операций в секунду
back: "10¹² шагов ≈ 1000 секунд ≈ 17 минут."
tags: [growth]
```

```card
front: Сколько сравнений делает бинарный поиск в миллионе элементов
back: "≈ 20 (log₂ 10⁶ ≈ 19.93, округляем вверх). В миллиарде — 30."
tags: [logs]
```

```card
front: До какого n реально доживает алгоритм за 2ⁿ и за n!
back: "2ⁿ — примерно до n = 40 (10¹² шагов); n! — до n = 20 (2.4·10¹⁸ шагов ≈ 77 лет уже на грани). Дальше только эвристики."
tags: [growth]
```

```card
front: Самое полезное чтение log₂ n для программиста
back: Сколько раз можно поделить n пополам, пока не дойдём до 1.
tags: [logs]
```

```card
front: Что даёт log-log график
back: "Степенная функция y = c·nᵏ становится на нём прямой с наклоном k. Приём для замера: если точки легли на прямую с наклоном 2 — у вас O(n²)."
tags: [logs]
```

```card
front: Гармоническое число Hₙ и его асимптотика
back: "Hₙ = Σ(i=1..n) 1/i ≈ ln n + γ, где γ ≈ 0.5772 (постоянная Эйлера — Маскерони)."
tags: [sums]
```

```card
front: Где в бэкенде встречаются гармонические числа
back: "Среднее число сравнений в quicksort (≈ 2n·ln n), длины цепочек в хеш-таблице, задача о сборе купонов (n·Hₙ)."
tags: [sums]
```

```card
front: "T(n) = 2T(n/2) + n — какая это сложность и какой алгоритм"
back: "Θ(n log n); merge sort. Уровней рекурсии log n, на каждом суммарно n работы."
tags: [recurrence]
```

```card
front: "T(n) = T(n/2) + 1 — какая это сложность"
back: "Θ(log n); бинарный поиск."
tags: [recurrence]
```

```card
front: Что означает запись n → ∞
back: "Не «n равно бесконечности», а «смотрим, к чему приближается выражение, когда n растёт неограниченно»."
tags: [limits]
```

```card
front: Чему равен предел (3n² + 5n)/(n² + 1) при n → ∞
back: "3. Делим числитель и знаменатель на n²: (3 + 5/n)/(1 + 1/n²) → 3/1."
tags: [limits]
```

```card
front: 0.999… больше, меньше или равно 1
back: "Ровно равно. Это предел последовательности 0.9, 0.99, 0.999, … Проверка: x = 0.999…, 10x = 9.999…, 9x = 9, x = 1."
tags: [limits]
```

## Производная и градиент

```card
front: Производная в одном предложении
back: Наклон касательной к графику в точке, то есть мгновенная скорость изменения функции.
tags: [derivative]
```

```card
front: Определение производной через предел
back: "f′(x) = lim(h→0) (f(x + h) − f(x))/h"
tags: [derivative]
```

```card
front: Производные xⁿ, eˣ, ln x, √x
back: "(xⁿ)′ = n·x^(n−1); (eˣ)′ = eˣ; (ln x)′ = 1/x; (√x)′ = 1/(2√x)"
tags: [derivative]
```

```card
front: Цепное правило
back: "(f(g(x)))′ = f′(g(x)) · g′(x) — производная внешней в точке внутренней, умножить на производную внутренней. Основа backpropagation."
tags: [derivative]
```

```card
front: Как найти минимум гладкой функции
back: "Решить f′(x) = 0, затем проверить вторую производную: f″(x) > 0 — минимум, f″(x) < 0 — максимум."
tags: [derivative]
```

```card
front: Что такое градиент ∇f и его главное свойство
back: "Вектор частных производных (∂f/∂w₁, …, ∂f/∂wₙ). Указывает направление наискорейшего роста функции; −∇f — наискорейшего убывания."
tags: [gradient]
```

```card
front: Формула шага градиентного спуска
back: "w ← w − α·∇f(w), где α — learning rate. Слишком большой α — расходимся, слишком маленький — ползём вечно."
tags: [gradient]
```

```card
front: Формула метода Ньютона и её частный случай для √a
back: "x ← x − f(x)/f′(x); для f(x) = x² − a получается x ← (x + a/x)/2. Сходится квадратично."
tags: [newton]
```

## Интеграл и экспонента

```card
front: Интеграл простыми словами
back: "Накопленная величина — площадь под графиком; предел суммы прямоугольников f(xᵢ)·Δx при Δx → 0."
tags: [integral]
```

```card
front: Основная теорема анализа в одной фразе
back: "Дифференцирование и интегрирование взаимно обратны: если F′ = f, то ∫(a..b) f dx = F(b) − F(a)."
tags: [integral]
```

```card
front: Как выразить среднюю нагрузку за окно через интеграл
back: "среднее = (1/T)·∫(0..T) load(t) dt — ровно то, что показывает «average CPU за 5 минут»."
tags: [integral]
```

```card
front: Что такое число e и чему примерно равно
back: "e = lim(n→∞)(1 + 1/n)ⁿ ≈ 2.71828 — потолок непрерывного начисления 100 % процентов."
tags: [exponential]
```

```card
front: Правило 70
back: "Время удвоения ≈ 70 / процент роста за период. Рост 10 % в месяц → удвоение за 7 месяцев. Выводится из t = ln 2 / r."
tags: [exponential]
```

```card
front: Связь half-life и λ в формуле N₀·e^(−λt)
back: "T½ = ln 2 / λ ≈ 0.693/λ. Записи e^(−λt) и 2^(−t/T½) описывают одну и ту же кривую."
tags: [exponential]
```

```card
front: Формула exponential backoff и зачем нужен jitter
back: "delay = min(cap, base·2^k). Экспонента разводит попытки одного клиента, jitter (random(0, delay)) — попытки разных клиентов, иначе thundering herd."
tags: [exponential, backend]
```

```card
front: Формула EWMA и её эффективное окно
back: "avgₖ = α·xₖ + (1 − α)·avgₖ₋₁; вес наблюдения падает как (1−α)ⁱ, окно памяти ≈ 1/α."
tags: [exponential, backend]
```
