# Упражнения

Считайте руками, а потом проверяйте кодом — брутфорс по всем `2ⁿ` строкам занимает
пять строк на Go и снимает все сомнения. Истинностные значения записываем как
`true` / `false`.

## Вычисление значений

```drill
type: fill-in
prompt: "Вычисли значение выражения ¬(true ∧ false). Ответ — true или false."
answer: "true"
check: exact
hint: "сначала скобка, потом отрицание"
```

```drill
type: fill-in
prompt: "Вычисли p ⇒ q при p = true, q = false. Ответ — true или false."
answer: "false"
check: exact
hint: "это единственная строка, где импликация ложна"
```

```drill
type: fill-in
prompt: "Вычисли p ⇒ q при p = false, q = false. Ответ — true или false."
answer: "true"
check: exact
hint: "обещание, условие которого не наступило, не нарушено"
```

```drill
answer: "¬a ∧ ¬b"
check: exact
hint: "отрицание входит внутрь и переворачивает связку"
```

```drill

```

## Импликация и контрапозиция

```drill
type: fill-in
prompt: "Раскрой отрицание импликации: ¬(p ⇒ q) = ___"
answer: "p ∧ ¬q | p && !q"
check: fuzzy
hint: "посылка верна, заключение — нет"
```

```drill
type: multiple-choice
prompt: "Утверждение: «если сервис получил валидный токен, он обрабатывает запрос». Какое из перечисленных — контрапозиция?"
options: ["Если сервис обработал запрос, токен был валидным", "Если сервис не обработал запрос, токен не был валидным", "Если токен невалиден, сервис не обрабатывает запрос", "Если токен валиден, сервис не обрабатывает запрос"]
answer: "Если сервис не обработал запрос, токен не был валидным"
check: exact
hint: "контрапозиция к p ⇒ q — это ¬q ⇒ ¬p: обе части отрицаются И меняются местами"
```

```drill
type: multiple-choice
prompt: "То же утверждение: «если сервис получил валидный токен, он обрабатывает запрос». Какое из перечисленных — обратное (converse), которому исходное НЕ равносильно?"
options: ["Если сервис обработал запрос, токен был валидным", "Если сервис не обработал запрос, токен не был валидным", "Если токен невалиден, сервис не обрабатывает запрос", "Сервис всегда обрабатывает запрос"]
```

## Объясни и проверь

```drill
type: free-form
prompt: "Объясни своими словами, почему импликация p ⇒ q истинна, когда p ложно, — и почему это не произвол, а единственный разумный выбор."
answer: "Импликация — обещание «если p, то q». Нарушить его можно ровно одним способом: p наступило, а q нет. Если p не наступило, претензий предъявить не к чему, значит, обещание не нарушено, значит, истинно. Любой другой выбор сломал бы полезные утверждения вида «для всех n: если n делится на 4, то n чётное» — они обязаны оставаться истинными и для нечётных n, где посылка ложна."
check: manual
tags: [implication, explain]
```

```drill
type: free-form
prompt: "Проверь кодом: напиши на Go перебор всех восьми комбинаций a, b, c и убедись, что a ∧ (b ∨ c) равносильно (a ∧ b) ∨ (a ∧ c). Затем сломай одну связку и убедись, что перебор находит несовпадение."
answer: "Три вложенных цикла по []bool{false, true}; на каждой итерации сравнить left := a && (b || c) и right := (a && b) || (a && c); при left != right напечатать набор и выйти. Для сломанной версии, например (a && b) || (a || c), несовпадение находится уже на a = false, b = false, c = true."
check: manual
tags: [go, verify]
```

```drill
type: free-form
prompt: "Докажи индукцией: сумма первых n нечётных чисел 1 + 3 + 5 + … + (2n − 1) равна n². Выпиши базу и переход отдельными шагами, каждый шаг с причиной."
answer: "База n = 1: слева 1, справа 1² = 1, совпало. Переход: пусть 1 + 3 + … + (2k − 1) = k². Тогда 1 + 3 + … + (2k − 1) + (2(k+1) − 1) = k² + (2k + 1) — подставили предположение; = k² + 2k + 1 — раскрыли; = (k + 1)² — свернули квадрат суммы. Это и есть утверждение для k + 1. База и переход доказаны, значит, формула верна для всех n ≥ 1."
check: manual
tags: [induction, proof]
```

```drill
type: free-form
prompt: "Докажи контрапозицией: если n² нечётное, то n нечётное. Объясни, почему прямое доказательство здесь неудобно."
answer: "Контрапозиция: если n чётное, то n² чётное. Пусть n = 2k — определение чётности; тогда n² = 4k² = 2·(2k²) — вынесли двойку; 2k² целое, значит, n² чётное. Контрапозиция равносильна исходному, значит, исходное доказано. Прямо неудобно: из «n² = 2m + 1» структуру самого n вытащить трудно, а из «n = 2k» она уже дана."
check: manual
tags: [contrapositive, proof]
```

```drill
type: free-form
prompt: "Приведи контрпример из двух элементов, показывающий, что ∀x ∃y R(x, y) и ∃y ∀x R(x, y) — разные утверждения. Объясни, какая из формул сильнее."
answer: "Пусть x и y пробегают {1, 2}, а R(x, y) истинно только для пар (1, 1) и (2, 2). Тогда ∀x ∃y R(x, y) истинно: для x = 1 подходит y = 1, для x = 2 подходит y = 2. А ∃y ∀x R(x, y) ложно: ни y = 1, ни y = 2 не подходят обоим x. Сильнее вторая формула — она требует одного универсального y; из неё первая следует, а обратно нет."
check: manual
tags: [quantifier, counterexample]
```
