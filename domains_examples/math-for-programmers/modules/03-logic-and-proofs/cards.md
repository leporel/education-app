# Карточки

Определения, обозначения, законы и разбор ловушек. Символы читаются вслух —
проговаривайте ответ словами, а не только «узнавайте» его.

## Обозначения и связки

```card
front: "Как читается p ∧ q и когда истинно?"
back: "«p и q». Истинно только когда истинны оба. В Go: p && q."
hint: "«домик вверх» — И"
tags: [logic, notation]
```

```card
front: "Как читается p ∨ q и когда истинно?"
back: "«p или q». Истинно, когда истинен хотя бы один — в том числе когда оба. В Go: p || q."
hint: "«домик вниз» — ИЛИ; это НЕисключающее или"
tags: [logic, notation]
```

```card
front: "Что означает p ⊕ q и как записать в Go?"
back: "XOR, исключающее «или»: истинно ровно когда одно из двух истинно. В Go для bool это p != q."
tags: [logic, notation, xor]
```

```card
front: "Как читается p ⇒ q и как выразить через ¬ и ∨?"
back: "«из p следует q», «если p, то q». Равно ¬p ∨ q. В Go: !p || q."
tags: [logic, implication]
```

```card
front: "Как читается p ⇔ q?"
back: "«p равносильно q», «p тогда и только тогда, когда q». Истинно, когда значения совпадают. В Go: p == q."
tags: [logic, notation]
```

```card
front: "Каков приоритет логических операций от сильного к слабому?"
back: "¬ → ∧ → ∨ и ⊕ → ⇒ → ⇔. Поэтому ¬p ∧ q читается как (¬p) ∧ q, а не как ¬(p ∧ q)."
hint: "как минус, умножение, сложение"
tags: [logic, notation]
```

```card
front: "Сколько строк в таблице истинности для n переменных?"
back: "Ровно 2 в степени n. Одна переменная — 2 строки, две — 4, три — 8, десять — 1024."
tags: [logic, truth-table]
```

```card
front: "Чем высказывание отличается от предиката?"
back: "Высказывание либо истинно, либо ложно (2 + 2 = 4). Предикат — высказывание с параметром P(x), значение появляется только после подстановки x. В Go это bool и func(T) bool."
hint: "вопрос и команда высказываниями не являются"
tags: [logic, definition]
```

## Импликация и её родственники

```card
front: "В каком единственном случае p ⇒ q ложно?"
back: "Когда p истинно, а q ложно. Нарушенное обещание. Во всех остальных трёх случаях импликация истинна."
tags: [logic, implication]
```

```card
front: "Почему «ложь ⇒ что угодно» истинно?"
back: "Импликация — обещание «если p, то q». Если условие p не наступило, обещание нельзя нарушить, значит, оно не нарушено — то есть истинно."
hint: "истинность впустую, vacuous truth"
tags: [logic, implication]
```

```card
front: "Что такое обратное (converse) и противоположное (inverse) к p ⇒ q?"
back: "Обратное — q ⇒ p, противоположное — ¬p ⇒ ¬q. Исходному ни то, ни другое не равносильно (они равносильны между собой). «Делится на 4 ⇒ чётное» верно, «чётное ⇒ делится на 4» — нет (6)."
tags: [logic, implication]
```

```card
front: "Что такое контрапозиция к p ⇒ q и почему она полезна?"
back: "Это ¬q ⇒ ¬p — единственное из трёх преобразований, равносильное исходному. Полезна, когда доказывать «с конца» проще, чем напрямую."
tags: [logic, implication, proof]
```

```card
front: "Чему равно ¬(p ⇒ q)?"
back: "p ∧ ¬q. Отрицание импликации — это не импликация, а конъюнкция: посылка верна, заключение нет."
tags: [logic, implication]
```

## Законы булевой алгебры

```card
front: "Сформулируй закон де Моргана для ¬(p ∧ q)"
back: "¬(p ∧ q) = ¬p ∨ ¬q. Отрицание входит внутрь скобок и переворачивает связку."
hint: "«не оба» = «хотя бы один не»"
tags: [logic, de-morgan, law]
```

```card
front: "Сформулируй закон де Моргана для ¬(p ∨ q)"
back: "¬(p ∨ q) = ¬p ∧ ¬q. Снова: отрицание внутрь, связка переворачивается."
hint: "«ни один не» = «не первый И не второй»"
tags: [logic, de-morgan, law]
```

```card
front: "Что такое законы поглощения (absorption)?"
back: "p ∨ (p ∧ q) = p и p ∧ (p ∨ q) = p. Если внутри скобок повторяется то, что уже стоит снаружи, скобки часто выкидываются целиком."
tags: [logic, law, simplification]
```

```card
front: "Как выглядит дистрибутивность для логических связок?"
back: "p ∧ (q ∨ r) = (p ∧ q) ∨ (p ∧ r) и p ∨ (q ∧ r) = (p ∨ q) ∧ (p ∨ r). Второй закон в обычной арифметике неверен."
tags: [logic, law, simplification]
```

```card
front: "Чему равны p ∧ p, p ∨ p, p ∧ ¬p, p ∨ ¬p?"
back: "p ∧ p = p и p ∨ p = p (идемпотентность, в арифметике аналога нет). p ∧ ¬p = false (противоречие), p ∨ ¬p = true (исключённое третье)."
tags: [logic, law]
```

```card
front: "Что такое тавтология, противоречие и выполнимая формула?"
back: "Тавтология истинна при любых значениях переменных; противоречие ложно при любых; выполнимая формула истинна хотя бы при одном наборе. Формулы F и G равносильны ровно тогда, когда F ⇔ G — тавтология."
tags: [logic, definition]
```

## Кванторы

```card
front: "Как читается ∀x P(x) и что нужно, чтобы это опровергнуть?"
back: "«для любого x верно P(x)». Опровергается одним контрпримером — элементом x, для которого P(x) ложно."
hint: "∀ — перевёрнутая A, All"
tags: [logic, quantifier]
```

```card
front: "Как читается ∃x P(x) и что нужно, чтобы это доказать?"
back: "«существует x, для которого P(x)». Доказывается предъявлением одного свидетеля."
hint: "∃ — зеркальная E, Exists"
tags: [logic, quantifier]
```

```card
front: "Чему равно ¬∀x P(x) и чему ¬∃x P(x)?"
back: "¬∀x P(x) = ∃x ¬P(x) («не все» = «нашёлся тот, кто не»); ¬∃x P(x) = ∀x ¬P(x) («ни одного» = «все не»)."
tags: [logic, quantifier, negation]
```

```card
front: "Чем ∀r ∃h Handles(h, r) отличается от ∃h ∀r Handles(h, r)?"
back: "Первое: у каждого запроса есть свой обработчик. Второе (сильнее): есть один обработчик на все запросы. Из второго следует первое, но не наоборот."
tags: [logic, quantifier, nested]
```

```card
front: "Какие значения у ∀ и ∃ на пустом множестве?"
back: "∀ по пустому множеству истинно (нет контрпримеров), ∃ по пустому множеству ложно (нет свидетелей). То же самое возвращают allOf и anyOf на пустом слайсе."
hint: "vacuous truth, «истинность впустую»"
tags: [logic, quantifier, edge-case]
```

```card
front: "Какой код соответствует кванторам ∀ и ∃?"
back: "∀ — цикл вида for … { if !P(x) { return false } } с return true в конце; ∃ — for … { if P(x) { return true } } с return false в конце."
tags: [logic, quantifier, go]
```

## Техники доказательства

```card
front: "Чем прямое доказательство отличается от доказательства контрапозицией?"
back: "Прямое: предполагаем p и разворачиваем определения до q. Контрапозиция: доказываем ¬q ⇒ ¬p — то же утверждение, но заходим с другой стороны. Выбирают контрапозицию, когда заключение содержит отрицание."
tags: [proof]
```

```card
front: "Схема доказательства от противного"
back: "Предполагаем отрицание утверждения (для импликации это p ∧ ¬q) и выводим противоречие вида r ∧ ¬r. Значит, предположение ложно, а утверждение верно."
hint: "√2 иррационально; простых бесконечно много"
tags: [proof, contradiction]
```

```card
front: "Из каких двух шагов состоит математическая индукция и почему это не жульничество?"
back: "База: доказать P(n₀) подстановкой. Переход: доказать P(k) ⇒ P(k+1). Это не круг в рассуждении: доказывается импликация, а она ничего не утверждает про истинность посылки. База — первая ступенька, переход — возможность шагнуть на следующую."
tags: [proof, induction]
```

```card
front: "Чем сильная индукция отличается от обычной?"
back: "В переходе предполагается P(m) для всех m от базы до k, а не только P(k). Нужна, когда шаг опирается на несколько меньших случаев — разложение n = a·b на множители или рекурсия «разделяй и властвуй»."
tags: [proof, induction]
```

```card
front: "Как индукция соответствует циклу?"
back: "База — состояние перед входом в цикл, переход — тело цикла (если инвариант верен до итерации, он верен после), вывод — инвариант на выходе из цикла."
tags: [proof, induction, invariant]
```

```card
front: "Что требуется от разбора случаев, чтобы он был корректным?"
back: "Случаи должны покрывать все возможности и не оставлять дыр. Классический промах — разбор «положительное или отрицательное» без нуля."
tags: [proof, cases]
```

## Что здесь не так

```card
front: "Что не так: ¬(a ∧ b) переписали как ¬a ∧ ¬b"
back: "Забыли перевернуть связку. Правильно ¬a ∨ ¬b. Проверка: при a = true, b = false исходное истинно, а ¬a ∧ ¬b ложно."
tags: [logic, mistake, de-morgan]
```

```card
front: "Что не так: «если токен истёк, запрос отклонён», значит «если запрос отклонён, токен истёк»"
back: "Это подмена импликации обратной: из p ⇒ q вывели q ⇒ p. Не равносильно. Отклонить могли и по другой причине."
tags: [logic, mistake, implication]
```

```card
front: "Что не так: n² + n + 41 даёт простое при n от 0 до 39, значит, оно простое всегда"
back: "Сорок проверок — не доказательство утверждения с ∀. При n = 40 получаем 1681 = 41², не простое. Та же логика применима к зелёным тестам."
tags: [proof, mistake, counterexample]
```

```card
front: "Что не так: рефакторинг !(a() && b()) в !a() || !b() «ничего не меняет»"
back: "Логически формулы равносильны, но из-за короткого замыкания меняется, когда вызывается b(). Если b() ходит в базу или пишет метрику, поведение программы изменится."
tags: [logic, mistake, go]
```
