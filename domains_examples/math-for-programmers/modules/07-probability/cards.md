# Карточки

## Основы

```card
front: Классическое определение вероятности и его обязательное условие
back: "P(A) = число благоприятных исходов / число всех исходов. Работает только если все элементарные исходы равновероятны — иначе формула даёт бессмыслицу вроде «встречу динозавра или нет, значит 50%»."
tags: [основы]
```

```card
front: Три аксиомы вероятности простыми словами
back: "1) P(A) ≥ 0. 2) P(всего пространства) = 1. 3) Для несовместных событий вероятности складываются. Всё остальное выводится из них."
tags: [основы]
```

```card
front: Правило дополнения и зачем оно нужно
back: "P(не A) = 1 − P(A). Главное применение — «хотя бы один»: P(хотя бы один) = 1 − P(ни одного). Прямой счёт почти всегда длиннее."
tags: [основы]
```

```card
front: Правило сложения для произвольных событий
back: "P(A или B) = P(A) + P(B) − P(A и B). Это формула включения-исключения, делённая на размер пространства. Без вычитания пересечение считается дважды."
tags: [основы]
```

```card
front: Три трактовки вероятности
back: "Классическая (симметрия, равновероятные исходы), частотная (предел доли при многих повторениях), субъективная/байесовская (мера уверенности). Правила у всех трёх одинаковые."
tags: [основы]
```

## Условная вероятность и Байес

```card
front: "Определение условной вероятности P(A при условии B)"
back: "Равна P(A и B) / P(B) при P(B) > 0. Интуиция: узнав B, мы сузили пространство до B и считаем долю A внутри него."
tags: [условная]
```

```card
front: Правило умножения вероятностей
back: "P(A и B) = P(B)·P(A при условии B) = P(A)·P(B при условии A). Упрощается до P(A)·P(B) только при независимости."
tags: [условная]
```

```card
front: Чем несовместные события отличаются от независимых?
back: "Несовместные не могут произойти вместе, P(A и B) = 0 — это максимальная зависимость. Независимые могут происходить вместе, и P(A и B) = P(A)·P(B). Это противоположные понятия, а не синонимы."
tags: [независимость]
```

```card
front: Теорема Байеса
back: "P(H при условии A) = P(A при условии H)·P(H) / P(A), где P(A) раскрывается формулой полной вероятности. Позволяет перевернуть условную вероятность."
tags: [байес]
```

```card
front: Формула полной вероятности
back: "Если гипотезы H₁…Hₖ разбивают пространство на непересекающиеся части, то P(A) = Σ P(Hᵢ)·P(A при условии Hᵢ) — взвешенная сумма по сценариям."
tags: [байес]
```

```card
front: Почему тест с точностью 99% на редкую болезнь почти ничего не значит?
back: "При распространённости 0.1% и 5% ложноположительных из 100 000 человек положительны 99 больных и 4995 здоровых. Вероятность болезни при положительном тесте — 99/5094 ≈ 1.9%. Решает базовая частота, а не точность теста."
tags: [байес]
```

```card
front: Что такое «ошибка прокурора»?
back: "Подмена P(улика при невиновности) на P(невиновность при улике). Это разные числа: первое может быть 0.001, а второе — 0.9, если подозреваемых миллион."
tags: [байес]
```

```card
front: Табличный метод Байеса — в чём приём?
back: "Взять условную популяцию (например, 100 000 человек), разложить её по всем ветвям дерева абсолютными числами и посчитать долю. Ошибиться труднее, чем в формуле, а результат тот же."
tags: [байес]
```

## Случайные величины

```card
front: Что такое случайная величина?
back: "Функция, превращающая исход эксперимента в число. Бросили два кубика — записали сумму. В коде это буквально функция от исхода."
tags: [случайные-величины]
```

```card
front: Матожидание — определение и главное свойство
back: "E[X] = Σ xᵢ·P(X = xᵢ) — «центр тяжести» распределения. Главное свойство: линейность E[X + Y] = E[X] + E[Y], которая верна ВСЕГДА, даже для зависимых величин."
tags: [матожидание]
```

```card
front: Дисперсия — две формулы и зачем корень
back: "Var(X) = E[(X − E[X])²] = E[X²] − (E[X])². Стандартное отклонение σ = √Var(X) нужно, чтобы вернуться в исходные единицы: дисперсия измеряется в квадратах."
tags: [дисперсия]
```

```card
front: Когда дисперсии можно складывать?
back: "Var(X + Y) = Var(X) + Var(Y) только для независимых величин. Матожидание складывается всегда — в этом ключевая асимметрия."
tags: [дисперсия]
```

```card
front: Как масштабирование влияет на дисперсию и σ?
back: "Var(cX) = c²·Var(X), поэтому σ(cX) = |c|·σ(X). Умножили величину на 2 — дисперсия выросла вчетверо, σ вдвое."
tags: [дисперсия]
```

## Распределения

```card
front: Биномиальное распределение — что моделирует и параметры
back: "Число успехов в n независимых опытах с вероятностью p. P(X=k) = C(n,k)p^k(1−p)^(n−k), E = np, Var = np(1−p)."
tags: [распределения]
```

```card
front: Геометрическое распределение — что моделирует
back: "Номер первой успешной попытки. P(X=k) = (1−p)^(k−1)·p, E[X] = 1/p. Это модель retry: при p = 0.9 в среднем 1.11 попытки."
tags: [распределения]
```

```card
front: Распределение Пуассона — что моделирует и чем примечательно
back: "Число событий за фиксированный интервал (запросы в секунду). P(X=k) = λ^k·e^(−λ)/k!. Примечательно тем, что E = Var = λ, поэтому σ = √λ."
tags: [распределения]
```

```card
front: Экспоненциальное распределение — что моделирует
back: "Время до следующего события. P(X > t) = e^(−λt), E = 1/λ. Если события идут по Пуассону с интенсивностью λ, интервалы между ними экспоненциальны с тем же λ."
tags: [распределения]
```

```card
front: Свойство отсутствия памяти — у кого есть и что означает?
back: "У геометрического и экспоненциального. P(X > s+t при условии X > s) = P(X > t): прождав час, вы не приблизились к цели. Поэтому экспоненциальным нельзя моделировать износ — стареющая деталь память имеет."
tags: [распределения]
```

```card
front: Центральная предельная теорема простыми словами
back: "Сумма или среднее многих независимых одинаково распределённых величин приближённо нормальны почти при любом исходном распределении. Отсюда колокол в росте людей, ошибках измерений, суммарной задержке из многих стадий."
tags: [цпт]
```

```card
front: "Правило 68–95–99.7"
back: "Внутри μ ± 1σ лежит около 68% значений, μ ± 2σ — 95%, μ ± 3σ — 99.7%. Работает для нормального распределения и НЕ работает для латентности с длинным правым хвостом."
tags: [цпт]
```

```card
front: Закон больших чисел и его практический смысл
back: "Среднее по выборке сходится к матожиданию при росте числа наблюдений. Это лицензия на Монте-Карло: миллион прогонов даёт надёжную оценку. Точность растёт как 1/√trials."
tags: [цпт]
```

## Приложения

```card
front: "Парадокс дней рождения — правило и вывод"
back: "Для 50% шанса совпадения нужно около 1.177·√N значений из пространства размера N, а не N/2. Для 365 дней это 23 человека; для 64-битных id — 2³² ≈ 4.3 миллиарда."
tags: [коллизии]
```

```card
front: Вероятность отказа хотя бы одного из n узлов
back: "1 − (1−p)ⁿ, где p — вероятность отказа одного узла. Приближение при малом p: ≈ 1 − e^(−np) ≈ np. Для 100 узлов доступностью 99.9% это ≈ 9.5%."
tags: [надёжность]
```

```card
front: Формула ложного срабатывания Bloom-фильтра
back: "p_fp ≈ (1 − e^(−kn/m))^k, где m — бит, k — хеш-функций, n — элементов. Оптимальное k = (m/n)·ln2. При 10 битах на элемент и k = 7 это около 0.8%."
tags: [приложения]
```

```card
front: Сколько бакетов хеш-таблицы останется пустыми при n = m?
back: "E[пустых] = m·(1 − 1/m)ⁿ ≈ m·e^(−n/m); при n = m это ≈ 0.368m, то есть треть. Считается линейностью матожидания через индикаторы."
tags: [приложения]
```

```card
front: Как проверить любую вероятностную выкладку?
back: "Монте-Карло: повторить эксперимент миллион раз через math/rand/v2 и взять долю или среднее. Если симуляция и формула расходятся, ошибка почти всегда в формуле."
tags: [код, go]
```

```card
front: Что даёт math/rand/v2 для симуляций?
back: "Float64() — равномерное на [0,1); IntN(n) — целое 0..n−1; NormFloat64() — стандартное нормальное (масштабируется как σ·x + μ); ExpFloat64() — экспоненциальное со средним 1 (делится на λ); Perm(n) — случайная перестановка."
tags: [код, go]
```
