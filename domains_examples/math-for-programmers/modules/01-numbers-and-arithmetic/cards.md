# Карточки — числа и арифметика

Карточки на обозначения, правила и типовые ловушки этого модуля. Обозначения имеет
смысл прогонять чаще остального: они возвращаются во всех следующих модулях.

## Обозначения

```card
front: "∈  и  ∉"
back: "«принадлежит» и «не принадлежит». x ∈ A — x является элементом множества A. Код: наличие ключа в map."
tags: [notation, sets]
```

```card
front: "ℕ, ℤ, ℚ, ℝ"
back: "натуральные (1, 2, 3, …), целые (…, −1, 0, 1, …), рациональные (записываются дробью p/q), вещественные (вся числовая прямая). ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ."
tags: [notation, numbers]
```

```card
front: "∀"
back: "«для любого», «для всех». ∀x P(x) — свойство P верно для каждого x. Код: цикл, который возвращает false на первом нарушении."
tags: [notation, logic]
```

```card
front: "∃"
back: "«существует», «найдётся хотя бы один». ∃x P(x). Код: цикл, который возвращает true на первом совпадении."
tags: [notation, logic]
```

```card
front: "Σ"
back: "«сумма». Σ по i от 1 до n от aᵢ — сложить a₁ … aₙ. Код: sum := 0; for i := 1; i <= n; i++ { sum += a[i] }"
tags: [notation]
```

```card
front: "∏"
back: "«произведение». ∏ по i от 1 до n от aᵢ — перемножить a₁ … aₙ. Тот же цикл, но p *= a[i], и начинать с 1, а не с 0."
tags: [notation]
```

```card
front: "|x|"
back: "модуль (абсолютная величина) — расстояние от x до нуля, всегда ≥ 0. |−7| = 7. В коде math.Abs. Полезно как |a − b| — расстояние между a и b."
tags: [notation]
```

```card
front: "⌊x⌋  и  ⌈x⌉"
back: "«пол» (округление вниз) и «потолок» (округление вверх). ⌊3.7⌋ = 3, ⌈3.2⌉ = 4. Для отрицательных: ⌊−3.2⌋ = −4, ⌈−3.7⌉ = −3."
hint: скобка со «столиком внизу» — вниз, с «крышей вверху» — вверх
tags: [notation]
```

```card
front: "n!"
back: "«эн факториал» — 1 · 2 · … · n. По определению 0! = 1. Растёт быстрее любой степени: 20! уже больше 2⁶⁰."
tags: [notation]
```

## Дроби и проценты

```card
front: "Как сложить a/b + c/d?"
back: "Привести к общему знаменателю: a/b + c/d = (a·d + c·b)/(b·d), потом сократить. Складывать числители и знаменатели по отдельности нельзя."
tags: [fractions]
```

```card
front: "Как разделить дробь на дробь?"
back: "Умножить на перевёрнутую: (a/b) : (c/d) = (a/b) · (d/c) = (a·d)/(b·c)."
tags: [fractions]
```

```card
front: "Как превратить 2¾ в неправильную дробь?"
back: "Целую часть умножить на знаменатель и прибавить числитель: (2·4 + 3)/4 = 11/4. Обратно — деление с остатком: 11 = 4·2 + 3."
tags: [fractions]
```

```card
front: "p% от числа X — это сколько?"
back: "X · p/100. Процент — просто дробь со знаменателем 100."
tags: [percent]
```

```card
front: "После роста на p% получилось Y. Каким было исходное значение?"
back: "было = Y / (1 + p/100). Делим, а не вычитаем: процент считался от старого значения."
hint: 120 после +20% → 120 / 1.2 = 100, а не 96
tags: [percent]
```

```card
front: "Величина растёт на p% n раз подряд. Итог?"
back: "X · (1 + p/100)ⁿ — множители перемножаются, а не складываются. 100 при +5% пять раз ≈ 127.63, а не 125."
tags: [percent]
```

```card
front: "Чем «процент» отличается от «процентного пункта»?"
back: "Рост конверсии с 3% до 5% — это +2 процентных пункта и одновременно +66% относительно. В отчётах путаница между ними меняет вывод целиком."
tags: [percent]
```

## Степени, корни, порядки

```card
front: "aᵐ · aⁿ = ?"
back: "aᵐ⁺ⁿ — при умножении степеней с одинаковым основанием показатели складываются. При делении вычитаются, при возведении степени в степень перемножаются."
tags: [powers]
```

```card
front: "Почему a⁰ = 1?"
back: "Из правила деления: aⁿ / aⁿ = aⁿ⁻ⁿ = a⁰, а слева стоит 1. Определение выбрано так, чтобы правило не сломалось. Требуется a ≠ 0."
tags: [powers]
```

```card
front: "a⁻ⁿ = ?"
back: "1/aⁿ. Отрицательный показатель означает «в знаменатель». 2⁻³ = 1/8."
tags: [powers]
```

```card
front: "Почему a^(1/2) = √a?"
back: "Если правило (aᵐ)ⁿ = aᵐⁿ должно работать, то (a^(1/2))² = a¹ = a. Число, квадрат которого равен a, — это √a. Общий случай: a^(m/n) = ⁿ√(aᵐ)."
tags: [powers, roots]
```

```card
front: "Чему равно −3², а чему (−3)²?"
back: "−3² = −(3²) = −9: степень сильнее унарного минуса. (−3)² = 9. Скобки решают всё."
tags: [powers, order]
```

```card
front: "Что такое научная запись и порядок величины?"
back: "m · 10ᵏ, где 1 ≤ |m| < 10; k — порядок величины. В коде пишется 6.02e23. При умножении порядки складываются — на этом строятся оценки в уме."
tags: [scientific]
```

## Остаток, пол, потолок

```card
front: "Деление с остатком — формальная запись"
back: "a = b·q + r, где 0 ≤ r < b. q — неполное частное, r — остаток. 17 = 5·3 + 2."
tags: [division]
```

```card
front: "Чему равно −7 mod 3 в математике и −7 % 3 в Go?"
back: "В математике 2 (остаток всегда неотрицательный). В Go −1 (знак берётся от делимого). Исправление: ((a % n) + n) % n."
hint: отсюда берутся отрицательные индексы шардов
tags: [division, go]
```

```card
front: "Как посчитать ⌈a/b⌉ целочисленно, без float?"
back: "(a + b − 1) / b при a ≥ 0, b > 0. Это формула пагинации: pages := (n + size - 1) / size."
tags: [division, ceil]
```

## Числа в компьютере

```card
front: "Диапазон знакового и беззнакового n-битного типа"
back: "знаковый: от −2ⁿ⁻¹ до 2ⁿ⁻¹ − 1; беззнаковый: от 0 до 2ⁿ − 1. Единица вычитается, потому что ноль тоже занимает значение."
tags: [machine, int]
```

```card
front: "Как в дополнительном коде получить −x?"
back: "Инвертировать все биты и прибавить 1. Старший бит имеет вес −2ⁿ⁻¹, поэтому 1111 1111 (8 бит) = −128 + 127 = −1."
tags: [machine, int]
```

```card
front: "Что делает Go при переполнении int?"
back: "Молча заворачивает по модулю 2ⁿ. int8(127) + 1 даёт −128, uint8(0) − 1 даёт 255. Ни паники, ни предупреждения."
tags: [machine, int]
```

```card
front: "Из чего состоит float64 по IEEE 754?"
back: "1 бит знака + 11 бит порядка + 52 бита мантиссы. Значение ≈ (−1)^s · 1.f · 2^(e − 1023). Это научная запись с основанием 2 и конечной длиной."
tags: [machine, float]
```

```card
front: "До какого числа float64 представляет целые точно?"
back: "До 2⁵³ = 9 007 199 254 740 992 включительно. Дальше шаг сетки становится 2 и больше — поэтому большие id в JSON передают строкой."
tags: [machine, float]
```

```card
front: "Почему 0.1 + 0.2 != 0.3?"
back: "Конечной двоичной дробью записываются только дроби со знаменателем-степенью двойки. 1/10 в двоичной — бесконечная периодическая, как 1/3 в десятичной. Ошибка появляется уже при записи литералов, а не при сложении."
tags: [machine, float]
```

```card
front: "Чем NaN опасен при сравнении?"
back: "NaN не равен ничему, включая себя: NaN == NaN даёт false. Проверять только math.IsNaN(x). Возникает из 0/0, √ отрицательного, Inf − Inf."
tags: [machine, float]
```

## Что здесь не так

```card
front: "Что не так: 1/2 + 1/3 = 2/5"
back: "Сложены числители и знаменатели по отдельности. Верно: (1·3 + 1·2)/(2·3) = 5/6. Прикидка сразу ловит ошибку: 0.5 + 0.33 ≈ 0.83, а 2/5 = 0.4."
tags: [mistakes, fractions]
```

```card
front: "Что не так: «цена упала на 20%, потом выросла на 20% — вернулись к исходной»"
back: "Множители перемножаются: 0.8 · 1.2 = 0.96. Итог — минус 4% от исходной цены. Проценты считаются от разных баз."
tags: [mistakes, percent]
```

```card
front: "Что не так: сравнение float через |a − b| < 1e-15 для значений порядка 1e15"
back: "Шаг сетки float64 около 1e15 равен 0.125 — он крупнее допуска, и сравнение вырождается в ==. Нужен относительный допуск: |a − b| ≤ eps · max(|a|, |b|)."
tags: [mistakes, float]
```
