# Карточки

Обозначения, определения и формулы модуля. Часть карточек — «что здесь не так»:
на лицевой стороне утверждение, на обороте разбор.

## Обозначения

```card
front: "x ∈ A"
back: "«x принадлежит A». В Go: _, ok := m[x] — значение ok и есть x ∈ A."
tags: [sets, notation]
```

```card
front: "A ⊆ B"
back: "«A — подмножество B»: каждый элемент A лежит в B. Формально ∀x (x ∈ A ⇒ x ∈ B). Допускает A = B; строгий вариант A ⊂ B дополнительно требует A ≠ B."
tags: [sets, notation]
```

```card
front: "∅"
back: "Пустое множество. Мощность 0, подмножество любого множества. Не путать с {∅} — там один элемент."
tags: [sets, notation]
```

```card
front: "Что означает вертикальная черта в записи {x ∈ ℕ | x чётное}?"
back: "«таких, что». Слева от черты — откуда берём кандидатов, справа — условие-фильтр. Это filter в коде."
hint: set-builder notation
tags: [sets, notation]
```

```card
front: "|A| — как читается и что значит?"
back: "«мощность A» — количество элементов конечного множества. В коде len(set)."
tags: [sets, notation]
```

```card
front: "P(A)"
back: "Булеан (power set) — множество всех подмножеств A, включая ∅ и само A."
tags: [sets, notation]
```

```card
front: "A × B"
back: "Декартово произведение — множество всех упорядоченных пар (a, b), где a ∈ A и b ∈ B."
tags: [sets, notation]
```

```card
front: "f: A → B"
back: "«функция f из A в B»: каждому элементу A сопоставлен ровно один элемент B. A — область определения, B — область прибытия."
tags: [functions, notation]
```

## Операции над множествами

```card
front: "A ∪ B — определение"
back: "Объединение: {x | x ∈ A или x ∈ B}. Всё, что лежит хотя бы в одном из двух."
tags: [sets, operations]
```

```card
front: "A ∩ B — определение"
back: "Пересечение: {x | x ∈ A и x ∈ B}. Только то, что лежит в обоих сразу."
tags: [sets, operations]
```

```card
front: "A \\ B — определение и главное предупреждение"
back: "Разность: {x | x ∈ A и x ∉ B}. Несимметрична: A \\ B и B \\ A — разные множества."
tags: [sets, operations]
```

```card
front: "A △ B — определение"
back: "Симметрическая разность: (A \\ B) ∪ (B \\ A) — то, что лежит ровно в одном из двух. Аналог XOR, удобный «diff по составу»."
tags: [sets, operations]
```

```card
front: "Дополнение A — что обязательно нужно указать?"
back: "Универсум U. Дополнение = U \\ A, и без явного U вопрос «что не в A» не имеет ответа."
tags: [sets, operations]
```

```card
front: "Законы де Моргана для множеств"
back: "дополнение(A ∪ B) = Ā ∩ B̄; дополнение(A ∩ B) = Ā ∪ B̄. Это перевод логических законов де Моргана на язык множеств."
tags: [sets, laws]
```

## Мощности и подсчёт

```card
front: "Формула включения-исключения для двух множеств"
back: "|A ∪ B| = |A| + |B| − |A ∩ B|. Общие элементы посчитаны дважды, лишнее вычитаем."
tags: [sets, cardinality]
```

```card
front: "|A ∪ B ∪ C| = ?"
back: "|A| + |B| + |C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|"
tags: [sets, cardinality]
```

```card
front: "Чему равна |P(A)|, если |A| = n, и почему?"
back: "2ⁿ. Подмножество — это битовая маска: по каждому из n элементов независимое решение «брать / не брать»."
tags: [sets, cardinality]
```

```card
front: "|A × B| = ?"
back: "|A| · |B|. Два вложенных цикла: внешний делает |A| шагов, внутренний |B| на каждом."
tags: [sets, cardinality]
```

## Отношения

```card
front: "Что такое бинарное отношение R из A в B?"
back: "Любое подмножество R ⊆ A × B, то есть просто множество пар. В коде — func(a, b) bool, список смежности или таблица связей."
tags: [relations]
```

```card
front: "Рефлексивность, симметричность, антисимметричность, транзитивность — формально"
back: "∀a: a R a; a R b ⇒ b R a; (a R b и b R a) ⇒ a = b; (a R b и b R c) ⇒ a R c."
tags: [relations]
```

```card
front: "Какие три свойства делают отношение эквивалентностью?"
back: "Рефлексивность, симметричность, транзитивность. Такое отношение разбивает множество на непересекающиеся классы."
tags: [relations, equivalence]
```

```card
front: "Что такое класс эквивалентности [a]?"
back: "[a] = {x ∈ A | x ~ a} — все элементы, «одинаковые» с a. Классы либо совпадают, либо не пересекаются и вместе покрывают всё A."
tags: [relations, equivalence]
```

```card
front: "Какие три свойства задают частичный порядок?"
back: "Рефлексивность, антисимметричность, транзитивность. Часть пар при этом может быть несравнима."
tags: [relations, order]
```

```card
front: "Чем линейный (полный) порядок отличается от частичного?"
back: "Дополнительным требованием сравнимости: ∀a,b верно a ≼ b или b ≼ a. Сортировка требует именно линейного порядка."
tags: [relations, order]
```

```card
front: "Что такое топологическая сортировка на языке порядков?"
back: "Достройка частичного порядка до линейного: выбор одного из допустимых линейных продолжений. Их обычно несколько."
tags: [relations, order]
```

## Функции

```card
front: "domain, codomain, image — в чём разница?"
back: "domain — откуда берём аргументы; codomain — объявленное множество-цель; image — реально получаемые значения. Всегда image ⊆ codomain."
tags: [functions]
```

```card
front: "Инъекция — определение и практический смысл"
back: "f(x) = f(y) ⇒ x = y: разные входы дают разные выходы. Так обязан работать генератор id — без склеек."
tags: [functions]
```

```card
front: "Сюръекция — определение"
back: "∀b ∈ B ∃a ∈ A: f(a) = b. Образ покрывает всю область прибытия, недостижимых значений нет."
tags: [functions]
```

```card
front: "Когда существует обратная функция f⁻¹?"
back: "Ровно когда f — биекция (инъекция + сюръекция). Без инъективности непонятно, какой прообраз вернуть; без сюръективности часть значений нечего декодировать."
tags: [functions]
```

```card
front: "g ∘ f — как читать и в каком порядке применяется?"
back: "«g после f»: (g ∘ f)(x) = g(f(x)). Сначала выполняется внутренняя f. Для биекции f⁻¹ ∘ f = id."
tags: [functions]
```

```card
front: "Какие из ℕ, ℤ, ℚ, ℝ счётны?"
back: "ℕ, ℤ и ℚ счётны (есть биекция с ℕ). ℝ несчётно — диагональный аргумент Кантора."
tags: [functions, countability]
```

## Что здесь не так

```card
front: "Что не так: «{1} ∈ {1, 2}»"
back: "Элемент множества {1, 2} — число 1, а не множество {1}. Верно 1 ∈ {1, 2} и {1} ⊆ {1, 2}."
tags: [sets, mistakes]
```

```card
front: "Что не так: «|A ∪ B| = |A| + |B|»"
back: "Верно только для непересекающихся множеств. В общем случае нужно вычесть |A ∩ B|, иначе общие элементы посчитаны дважды."
tags: [sets, mistakes]
```

```card
front: "Что не так: «хеш можно расхешировать, просто алгоритм сложный»"
back: "Дело не в сложности: хеш не инъективен. Входов бесконечно много, выходов конечное число, поэтому у значения много прообразов."
tags: [functions, mistakes]
```

```card
front: "Что не так: «компаратор x.Priority < y.Priority годится для sort.Slice»"
back: "Если приоритеты совпадают, элементы несравнимы — это частичный порядок. Результат становится невоспроизводимым. Нужен вторичный ключ или стабильная сортировка."
tags: [relations, order, mistakes]
```
