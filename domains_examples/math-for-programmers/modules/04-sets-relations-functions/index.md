# Множества, отношения, функции

Самый «программистский» модуль дискретной базы: почти всё здесь уже написано у вас
в коде, просто под другими именами. Множество — `map[T]struct{}`, отношение —
таблица связей, эквивалентность — дедупликация, порядок — компаратор сортировки.
Задача модуля — сделать эти соответствия явными.

## Цель

- Свободно читать и писать `∈`, `⊆`, `∪`, `∩`, `\`, `△`, `|A|`, `A × B`, `f: A → B` —
  и переводить каждый из этих значков в код без запинки.
- Считать мощности: `|A ∪ B|` через формулу включения-исключения, `|P(A)| = 2ⁿ`,
  `|A × B| = |A| · |B|`.
- Видеть в рабочих задачах знакомые объекты: набор прав — множество, дедупликация —
  классы эквивалентности, `sort.Slice` — линейный порядок, `map[K]V` — частичная
  функция, SQL `JOIN` — декартово произведение с фильтром.
- Различать инъекцию, сюръекцию и биекцию и понимать, почему обратная функция
  существует ровно у биекций (и почему id-генератор обязан быть инъективным,
  а хеш — наоборот, не обязан).
