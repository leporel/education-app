# Карточки

## Векторы и нормы

```card
front: Вектор — два взгляда на один объект
back: "Список чисел (для кода) и стрелка-смещение (для интуиции). Вектор не привязан к точке: важно только смещение."
tags: [vectors]
```

```card
front: Как складывают векторы и умножают на скаляр
back: "v + w = (v₁+w₁, …, vₙ+wₙ) — поэлементно; c·v = (c·v₁, …, c·vₙ) — растягивает стрелку, отрицательное c разворачивает."
tags: [vectors]
```

```card
front: Три нормы — L2, L1, L∞
back: "L2 = √(Σ vᵢ²) — по прямой; L1 = Σ abs(vᵢ) — по улицам; L∞ = max abs(vᵢ) — худшая компонента. Всегда ‖v‖∞ ≤ ‖v‖₂ ≤ ‖v‖₁."
tags: [norms]
```

```card
front: Чему равны L2, L1 и L∞ нормы вектора (3, −4)
back: "L2 = 5, L1 = 7, L∞ = 4"
tags: [norms]
```

```card
front: Когда выбирают L1, а когда L∞
back: "L1 — устойчивость к выбросам и разреженность (lasso), сетки. L∞ — гарантии вида «ни одна компонента не отклонилась больше чем на ε» (SLA)."
tags: [norms]
```

```card
front: Расстояние между векторами и нормализация
back: "d(v, w) = ‖v − w‖; нормализация v̂ = v/‖v‖₂ даёт вектор того же направления длины 1."
tags: [vectors]
```

```card
front: Определение скалярного произведения
back: "v · w = Σ(i=1..n) vᵢwᵢ — сумма попарных произведений компонент. Результат число, не вектор."
tags: [dot]
```

```card
front: Геометрическая форма скалярного произведения
back: "v · w = ‖v‖·‖w‖·cos θ, где θ — угол между векторами."
tags: [dot]
```

```card
front: Что означает v · w = 0
back: Векторы ортогональны (перпендикулярны). Положительное значение — смотрят в одну сторону, отрицательное — в разные.
tags: [dot]
```

```card
front: Чему равно v · v
back: "‖v‖² — квадрату длины. Удобно: длину в квадрате можно считать без извлечения корня."
tags: [dot]
```

```card
front: Формула косинусной близости и диапазон значений
back: "cos(v, w) = (v · w)/(‖v‖·‖w‖); значения в [−1, 1]: 1 — одно направление, 0 — ортогональны, −1 — противоположны."
tags: [cosine]
```

```card
front: Почему в поиске по embeddings берут косинус, а не евклидово расстояние
back: "Длина вектора кодирует побочное (длину текста, частоту, уверенность модели), а смысл сидит в направлении. Косинус убирает влияние длины."
tags: [cosine, embeddings]
```

```card
front: Что упрощается, если все векторы нормализованы
back: "cos(v, w) = v · w, а ‖v − w‖² = 2 − 2·(v · w). Сортировка по косинусу и по евклидову расстоянию даёт один и тот же порядок — векторные базы этим пользуются."
tags: [cosine, embeddings]
```

```card
front: Длина проекции вектора v на направление w
back: "(v · w)/‖w‖"
tags: [dot]
```

## Матрицы

```card
front: Матрица — два взгляда
back: "Таблица чисел m × n и линейное преобразование пространства (тянет, сжимает, поворачивает, наклоняет; не изгибает и не двигает начало координат)."
tags: [matrices]
```

```card
front: Что означают столбцы матрицы
back: "Куда уезжают базисные векторы: первый столбец — образ e₁ = (1,0), второй — образ e₂ = (0,1)."
tags: [matrices]
```

```card
front: Формула умножения матрицы на вектор
back: "(A·v)ᵢ = Σⱼ aᵢⱼ·vⱼ — i-я компонента есть скалярное произведение i-й строки на v. Эквивалентно: A·v — линейная комбинация столбцов A с коэффициентами vⱼ."
tags: [matrices]
```

```card
front: Формула умножения матриц и правило размерностей
back: "(A·B)ᵢⱼ = Σₖ aᵢₖ·bₖⱼ; (m × n)·(n × p) = (m × p) — внутренние размеры должны совпадать."
tags: [matrices]
```

```card
front: Почему A·B ≠ B·A и как это читать
back: "A·B значит «сначала B, потом A», как f(g(x)). «Растянуть, потом повернуть» и «повернуть, потом растянуть» дают разные картинки — отсюда баги с порядком трансформаций."
tags: [matrices]
```

```card
front: Матрицы поворота, масштаба и сдвига в 2D
back: "Поворот на θ — [[cos θ, −sin θ], [sin θ, cos θ]]; масштаб — [[sx, 0], [0, sy]]; сдвиг — [[1, k], [0, 1]]."
tags: [transformations]
```

```card
front: Что делает единичная матрица I
back: "Ничего: I·v = v, A·I = I·A = A. Единицы на главной диагонали, нули везде ещё. Аналог числа 1."
tags: [matrices]
```

```card
front: Что такое обратная матрица и формула для 2×2
back: "A⁻¹ отменяет преобразование: A·A⁻¹ = I. Для 2×2: A⁻¹ = (1/det A)·[[d, −b], [−c, a]]."
tags: [matrices]
```

```card
front: Определитель 2×2 и его геометрический смысл
back: "det [[a, b], [c, d]] = ad − bc — во сколько раз меняется площадь. Отрицательный — отражение, единица — площадь сохранилась (поворот)."
tags: [determinant]
```

```card
front: Что означает det A = 0
back: "Площадь схлопнулась в ноль: преобразование необратимо, A⁻¹ не существует, строки линейно зависимы, система не имеет единственного решения."
tags: [determinant]
```

```card
front: Что такое транспонирование
back: "Aᵀ — отражение относительно главной диагонали, строки становятся столбцами; (Aᵀ)ᵢⱼ = aⱼᵢ. Размер m × n превращается в n × m."
tags: [matrices]
```

```card
front: Как записать систему линейных уравнений в матричном виде
back: "A·x = b, где A — матрица коэффициентов, x — вектор неизвестных, b — вектор правых частей."

```

```card
front: Три элементарные операции метода Гаусса
back: "Поменять две строки местами; умножить строку на ненулевое число; прибавить к строке другую, умноженную на число. Цель — треугольный вид."
tags: [systems]
```

```card
front: Как по результату метода Гаусса понять число решений
back: "Строка вида 0 0 0 | c с c ≠ 0 — решений нет. Строка из одних нулей (появилась свободная переменная) — решений бесконечно много. Иначе — единственное решение."
tags: [systems]
```

```card
front: Сложность метода Гаусса
back: "O(n³). Для n = 1000 это около секунды, для n = 10⁶ уже нужны итеративные методы."
tags: [systems]
```

```card
front: Нормальные уравнения метода наименьших квадратов
back: "AᵀA·x = Aᵀb — так решается переопределённая система (точек больше, чем неизвестных), например подгонка прямой под облако точек."
tags: [least-squares]
```

```card
front: Определение собственного вектора
back: "A·v = λ·v при v ≠ 0. Преобразование не поворачивает такой вектор, а только растягивает или сжимает в λ раз."
tags: [eigen]
```

```card
front: Как PageRank связан с собственными векторами
back: "Устойчивое распределение случайного сёрфера удовлетворяет M·p = p, то есть является собственным вектором матрицы переходов с λ = 1. Считают степенным методом: p ← M·p до сходимости."
tags: [eigen]
```

```card
front: Почему не стоит решать систему через x = A⁻¹b
```
