# Математика для программиста

Учебный домен: **вспомнить школьную математику и достроить её до той, которой реально
пользуется бэкенд-разработчик** — дискретная математика, вероятность, статистика,
интуиция роста функций и производных, основы линейной алгебры. Для взрослого
программиста (Go), который «когда-то всё это знал», а теперь пропускает формулы глазами.

Подача: каждый модуль начинается с «Вспоминаем школу», ни один символ не используется
без объяснения, каждая идея показана и формулой, и коротким кодом, который можно
запустить и проверить. Формулы — обычным текстом (`x²`, `√n`, `Σ`), без LaTeX.

## Как проходить

По порядку: модули 01–02 — «вспомнить школу», их нельзя пропускать, даже если кажется,
что помнишь. Модули 03–06 — дискретная база, 07–08 — вероятность и статистика (самое
частое в работе), 09–11 — рост, линейная алгебра и структуры. Внутри модуля:
`theory.md` → `lessons/` → `drills.md`, карточки `cards.md` в SRS параллельно. Формулы
проверять кодом: если Σ можно посчитать циклом — посчитай.
