# План обучения

Упорядоченный план модулей. Статусы: `todo` / `in-progress` / `done`.
План — не догма: можно менять порядок, вставлять модули, резать лишние.

Базис: взрослый программист (Go), школьная математика забыта. Цель — вспомнить и
достроить до рабочего минимума разработчика. Формулы — обычным текстом, каждая идея
подтверждается кодом.

      порядок действий, деление с остатком, научная запись; int/float/переполнение в
      компьютере; словарь обозначений (Σ, ∈, |x|, ⌊x⌋, n!) — **todo**.

## Идеи на потом

- Численные методы: погрешности, метод Ньютона, почему `0.1 + 0.2 != 0.3` вглубь.
- Теория информации: энтропия, сжатие, почему хеш 256 бит «достаточно».
- Криптография для разработчика: группы, эллиптические кривые интуитивно.
- Оптимизация: линейное программирование, градиентный спуск руками.
- Отдельный домен `algorithms` — алгоритмическая секция интервью поверх этой базы.
