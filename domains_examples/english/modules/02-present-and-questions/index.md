# Модуль 02 — Настоящее время, отрицания и вопросы

## Цель

После модуля ты умеешь не только утверждать, но и **отрицать** и **спрашивать**, а
также различаешь два настоящих времени:

1. Строишь отрицание в present simple через `don't / doesn't`.
2. Задаёшь вопросы через `do / does` и вопросительные слова (`what, where, who…`).
3. Строишь present continuous (`am/is/are + глагол-ing`) — действие прямо сейчас.
4. Чувствуешь разницу: present simple (вообще, регулярно) vs continuous (сейчас).
5. Задаёшь вопросы про подлежащее (`Who lives here?` — без помощника).
6. Пользуешься `can / can't` («могу, умею, можно») — включая `Can I have…?` для просьб.
