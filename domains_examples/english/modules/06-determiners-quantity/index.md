# Модуль 06 — Количество и определители

## Цель

Как сказать «немного / много / сколько-то / этот / тот» по-английски — и почему выбор
зависит от того, **считается** ли существительное. После модуля ты:

1. Различаешь исчисляемые и неисчисляемые существительные (`a book` vs `water`).
2. Используешь `some / any` (утверждение vs вопрос/отрицание).
3. Выбираешь `much / many / a lot of` и `a few / a little`.
4. Указываешь на предметы: `this / that / these / those`.
5. Сравниваешь: `cheaper than`, `more expensive than`, `as hot as`, `the best` — включая
   неправильные `good → better → the best`.
