# Упражнения

Выбор определителя по исчисляемости и типу предложения.

## Блок 1. Исчисляемость

```drill
type: multiple-choice
prompt: "Какое слово неисчисляемое (нет множ. числа)?"
options: [book, cat, money, apple]
answer: money
check: exact
```

```drill
type: multiple-choice
prompt: "Где ошибка?"
options: [two books, some water, three informations, a few days]
answer: three informations
check: exact
hint: information — неисчисляемое
```

```drill
type: fill-in
prompt: "The news ___ good today. (be)"
answer: is
check: exact
hint: news — единственное число
```

## Блок 2. some / any

```drill
type: fill-in
prompt: "I have ___ money. (утверждение)"
answer: some
check: exact
```

```drill
type: fill-in
prompt: "Do you have ___ questions? (вопрос)"
answer: any
check: exact
```

```drill
type: fill-in
prompt: "There aren't ___ apples in the fridge."
answer: any
check: exact
```

```drill
type: multiple-choice
prompt: "«Не хотите ли чаю?»:"
options: [Would you like any tea?, Would you like some tea?, Do you like any tea?, Would you any tea?]
answer: Would you like some tea?
check: exact
hint: вежливое предложение → some
```

## Блок 3. much / many / a few / a little

```drill
type: fill-in
prompt: "How ___ books do you have? (исчисляемое)"
answer: many
check: exact
```

```drill
type: fill-in
prompt: "I don't have ___ time. (неисчисляемое)"
answer: much
check: exact
```

```drill
type: multiple-choice
prompt: "«У меня много друзей» (естественно):"
options: [I have much friends., I have many friends., I have a lot of friends., I have a little friends.]
answer: I have a lot of friends.
check: exact
hint: в утверждении нейтральнее a lot of
```

```drill
type: fill-in
prompt: "I have ___ water left. (немного, неисчисляемое)"
answer: a little
check: fuzzy
```

```drill
type: fill-in
prompt: "She has ___ friends here. (несколько, исчисляемое)"
answer: a few
check: fuzzy
```

## Блок 4. this / that / these / those

```drill
type: fill-in
prompt: "___ book (рядом, ед.) is mine."
answer: This
check: fuzzy
```

```drill
type: fill-in
prompt: "___ shoes (рядом, множ.) are new."
answer: These
check: fuzzy
```

```drill
type: multiple-choice
prompt: "«Те люди шумные» (далеко, множ.):"
options: [This people are loud., That people are loud., These people are loud., Those people are loud.]
answer: Those people are loud.
check: exact
```

```drill
type: translate
prompt: "Переведи: Что это? (рядом)"
answer: What is this? | What's this?
check: fuzzy
```

```drill
type: free-form
prompt: "Напиши 3 предложения: одно с some/any, одно про количество (much/many/a lot of), одно с указателем (this/these…)."
answer: "Например: I have some coffee but I don't have any tea. There are a lot of books here. These books are interesting. (проверь исчисляемость и тип предложения)"
check: manual
```

## Блок 5. Сравнение

```drill
type: fill-in
prompt: "This cafe is ___ (cheap) than that one."
answer: cheaper
check: exact
hint: короткое слово → -er
```

```drill
type: fill-in
prompt: "Coffee is ___ (expensive) than tea."
answer: more expensive
check: fuzzy
hint: длинное слово → more
```

```drill
type: fill-in
prompt: "Today is ___ (happy) day of my life."
answer: the happiest
check: fuzzy
hint: превосходная степень + the; y → i
```

```drill
type: multiple-choice
prompt: "«Он старше меня»:"
options: [He is older me., He is more older than me., He is older than me., He is the older than me.]
answer: He is older than me.
check: exact
```

```drill
type: multiple-choice
prompt: "Где ошибка?"
options: [better than tea, more interesting than the film, worse than yesterday, more better than before]
answer: more better than before
check: exact
hint: сравнение делается один раз
```

```drill
type: translate
prompt: "Переведи: Это лучший кофе в городе."
answer: This is the best coffee in the city. | It's the best coffee in town.
check: fuzzy
hint: превосходная степень → the best
```

```drill
type: translate
prompt: "Переведи: Чай не такой горячий, как кофе."
answer: Tea is not as hot as coffee. | Tea isn't as hot as coffee.
check: fuzzy
hint: as … as, форма без -er
```

```drill
type: fill-in
prompt: "good → ___ → ___ (сравнительная, превосходная — через запятую)"
answer: better, the best
check: fuzzy
```

```drill
type: free-form
prompt: "Сравни две вещи из своей жизни: одна фраза с коротким прилагательным (-er + than), одна с длинным (more + than), одна в превосходной степени (the …est / the most …)."
answer: "Например: Tea is cheaper than coffee. My new flat is more comfortable than the old one. This is the best cafe near my house. (проверь: than на месте, the в превосходной, никаких «more older»)"
check: manual
```
