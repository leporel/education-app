# Карточки

Исчисляемость, `some/any`, `much/many/a lot of`, `a few/a little`, указатели.

## Исчисляемость

```card
front: Исчисляемое vs неисчисляемое — в чём суть?
back: исчисляемое считается поштучно и имеет множ. число (a book → books); неисчисляемое — масса/абстракция без множ. числа (water, money, time)
tags: [countable]
```

```card
front: Назови частые неисчисляемые слова, которые по-русски считаются
back: money, information, advice, news, bread, furniture, hair (всегда ед. ч.!)
tags: [countable, trap]
```

```card
front: Как посчитать неисчисляемое? (advice, water)
back: "через «контейнер»: a piece of advice, a glass of water, two pieces of furniture"
tags: [countable]
```

```card
front: "\"The news ___ good.\" — глагол?"
back: is (news — единственное число!)
tags: [countable, trap]
```

## some / any

```card
front: some или any — в утверждениях?
back: some (I have some money. There are some apples.)
tags: [some-any]
```

```card
front: some или any — в вопросах и отрицаниях?
back: any (Do you have any money? There aren't any apples.)
tags: [some-any]
```

```card
front: "\"Не хотите ли кофе?\" — some или any?"
back: some (Would you like some coffee?) — вежливое предложение → some
tags: [some-any, exception]
```

## much / many / a lot of

```card
front: «много» + исчисляемое множественное?
back: many (many books, many people, how many?)
tags: [quantity]
```

```card
front: «много» + неисчисляемое?
back: much (much water, much time, how much?)
tags: [quantity]
```

```card
front: Что звучит нейтральнее much/many в утверждениях?
back: a lot of / lots of (I have a lot of friends — лучше, чем "many friends")
tags: [quantity]
```

```card
front: "\"Сколько времени?\" / \"Сколько книг?\""
back: How much time? / How many books?
tags: [quantity]
```

## a few / a little

```card
front: «несколько» + исчисляемое?
back: a few (a few friends, a few days)
tags: [quantity]
```

```card
front: «немного» + неисчисляемое?
back: a little (a little water, a little time)
tags: [quantity]
```

## this / that / these / those

```card
front: this / that / these / those — таблица
back: this=этот (близко, ед.), that=тот (далеко, ед.), these=эти (близко, множ.), those=те (далеко, множ.)
tags: [demonstrative]
```

```card
front: "\"Эти туфли новые.\" — собрать"
back: These shoes are new.
hint: множ. + близко → these
tags: [demonstrative]
```

```card
front: "\"Что это?\" — собрать"
back: What is this? (What's this?)
tags: [demonstrative]
```

```card
front: "this или these: ___ books"
back: these books (множ. → these)
tags: [demonstrative]
```

## Сравнение: bigger / more expensive / the best

```card
front: По какому признаку выбирают -er или more?
back: "по длине слова: один слог (или два на -y) → -er / the -est; длиннее → more / the most"
tags: [comparison]
```

```card
front: big / cheap → сравнительная и превосходная?
back: bigger — the biggest; cheaper — the cheapest (короткое слово удваивает согласную)
tags: [comparison]
```

```card
front: happy / easy → сравнительная и превосходная?
back: happier — the happiest; easier — the easiest (y → i)
tags: [comparison]
```

```card
front: expensive / interesting → сравнительная и превосходная?
back: more expensive — the most expensive; more interesting — the most interesting
tags: [comparison]
```

```card
front: good / bad → сравнительная и превосходная?
back: good → better → the best; bad → worse [wɜːs] → the worst
tags: [comparison, irregular]
```

```card
front: many/much и little → сравнительная?
back: more (больше) и less (меньше); превосходные — the most / the least
tags: [comparison, irregular]
```

```card
front: «Он старше меня» — собрать
back: He is older than me. (без than нельзя — русский падеж не работает)
tags: [comparison]
```

```card
front: Почему нельзя "more older" или "more better"?
back: "сравнение делается один раз: либо -er, либо more. Правильно: older, better"
tags: [comparison, error]
```

```card
front: «Чай такой же горячий, как кофе» — собрать
back: Tea is as hot as coffee. (между as … as — обычная форма, без -er)
tags: [comparison]
```

```card
front: Нужен ли артикль в превосходной степени?
back: "да, the: the best coffee, the biggest room, the most interesting book"
tags: [comparison, article]
```

## Термины и связи с другими модулями

```card
front: Что такое определитель (determiner)?
back: "слово-ярлычок перед существительным про «сколько/чей/какой именно»: a, the, some, any, much, this, my. Их не ставят по два подряд (❌ the my book)"
tags: [term]
```

```card
front: Где искать правила множественного числа?
back: "модуль 01, урок 04 (pronouns-and-plurals): cat → cats, city → cities, box → boxes, child → children"
tags: [term, plural]
```

```card
front: Как сказать безличное русское «есть / имеется»?
back: "there is (один) / there are (много): \"There is a problem.\" Разбор — модуль 07, урок 01"
tags: [term]
```
