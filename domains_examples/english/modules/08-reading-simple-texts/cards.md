# Карточки

Стратегии, лексика вывесок/сообщений, «ложные друзья».

## Стратегии

```card
front: Главное правило чтения на чужом языке?
back: схватывать суть, а не переводить каждое слово; в словарь — только за тем, без чего смысл рушится
tags: [strategy]
```

```card
front: Что такое chunking при чтении?
back: резать длинное предложение на смысловые куски (подлежащее | сказуемое | дополнение | обстоятельство), читать группами
tags: [strategy]
```

```card
front: Что такое когнаты?
back: слова, похожие на русские/интернациональные (problem, idea, doctor, taxi) — узнаются без словаря
tags: [strategy]
```

## Сокращения в сообщениях

```card
front: pls / thx / asap
back: please / thanks / as soon as possible (как можно скорее)
tags: [abbreviation]
```

```card
front: btw / fyi
back: by the way (кстати) / for your information (к сведению)
tags: [abbreviation]
```

```card
front: "\"Running late, sorry.\" — что значит и почему без I?"
back: «Опаздываю, извини». В сообщениях часто роняют подлежащее (I'm) для скорости.
tags: [message]
```

## Кубики слов (приставки и суффиксы)

```card
front: un- / dis- — что делают со словом?
back: "отрицание: unhappy (несчастный), unknown, disagree (не соглашаться), disappear"
tags: [word-building]
```

```card
front: -er / -or — что делают со словом?
back: "«тот, кто делает»: teacher (учитель), driver, visitor"
tags: [word-building]
```

```card
front: -ful vs -less?
back: -ful = полный чего-то (useful — полезный), -less = без чего-то (useless — бесполезный)
tags: [word-building]
```

```card
front: -ly — что делает со словом?
back: "превращает в наречие «как?»: slow → slowly (медленно), quick → quickly"
tags: [word-building]
```

```card
front: care → четыре слова?
back: careful (осторожный), careless (беспечный), carefully (осторожно), caring (заботливый)
tags: [word-building]
```

```card
front: В какой форме искать слово в словаре?
back: "в словарной: worked → work, children → child, bigger → big"
tags: [strategy]
```

## Незнакомые конструкции при чтении

```card
front: Увидел have/has/had рядом с глаголом — как читать?
back: "составное время: смысл несёт последнее слово, помощник добавляет «уже / ещё раньше». I have finished = я уже закончил"
tags: [reading]
```

```card
front: Увидел was/were + третья форма (was closed) — как читать?
back: "с предметом что-то сделали, исполнитель не важен: «магазин был закрыт»"
tags: [reading]
```
