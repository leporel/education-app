# Модуль 05 — Предлоги места, времени и движения

## Цель

Предлоги — маленькие слова, которые трудно перевести «один-в-один» с русского, потому
что логика стоит за ними другая. После модуля ты:

1. Выбираешь `in / on / at` для **места** (точка → поверхность → объём).
2. Выбираешь `in / on / at` для **времени** (та же логика «масштаба»).
3. Описываешь **движение**: `to`, `into`, `from`, `through`.
4. Знаешь частые связки «глагол + предлог» (`look at`, `listen to`, `wait for`,
   `pay for`, `look for`, `afraid of`).
5. Говоришь «как долго» и «до каких пор»: `for two hours`, `until 6`, `by 6`,
   `from 9 to 5`, `during the film`.
6. Владеешь остальной горстью бытовых предлогов (`with, without, of, about, near,
   between, behind, under, across`) и первой пятёркой фразовых глаголов.
