# Урок 02 — `in / on / at`: время

Приятный сюрприз: та же тройка `in/on/at` работает для времени по той же логике
масштаба. Задача урока — закрепить «чем точнее время, тем точечнее предлог».

## Разогрев

Из прошлого урока: `at` = точка, `on` = поверхность, `in` = объём. Сейчас перенесём это
на время, думая о «размере промежутка».

## Новая тема

### Масштаб времени

- **`at`** — **момент / час** (точка во времени): `at 7 o'clock`, `at noon`,
  `at midnight`, `at night`.
- **`on`** — **день / дата** («поверхность дня»): `on Monday`, `on 25 March`,
  `on my birthday`.
- **`in`** — **большой промежуток** (внутри него): `in March`, `in 2026`, `in summer`,
  `in the morning`, `in the evening`.

Мнемоника по убыванию: **`in` (год/месяц) → `on` (день) → `at` (час).**

### Исключения, которые надо знать (частотные)

- `at night` — точка! (НЕ `in night`), но `in the morning / afternoon / evening`.
- `at the weekend` (британский) / `on the weekend` (американский).
- **Без предлога:** `today`, `tomorrow`, `yesterday`, `this/next/last week`
  (❌ `in tomorrow` → ✅ `tomorrow`).

## Разобранные примеры

1. «Встреча в 3 часа.» → `The meeting is at 3 o'clock.` (час → at)
2. «Увидимся в понедельник.» → `See you on Monday.` (день → on)
3. «Я родился в 1990.» → `I was born in 1990.` (год → in)
4. «Утром я пью кофе.» → `In the morning I drink coffee.` (часть дня → in the)
5. «Ночью холодно.» → `It's cold at night.` (исключение → at)

## Итог

Время — тот же образ масштаба: **`at` для часа/момента** (`at 7`, `at night`), **`on` для
дня/даты** (`on Monday`), **`in` для большого промежутка** (`in March`, `in 2026`,
`in the morning`). Помни исключения: `at night`, но `in the morning`; `today/tomorrow`
без предлога. Следующий урок — движение (`to/into/from`) и приклеенные предлоги.
