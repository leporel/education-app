# Урок 01 — Неопределённый артикль `a / an`

Артиклей в русском нет, поэтому начнём с самого простого флага: `a/an` — «один какой-то,
новый, неизвестный». Задача урока — ставить его автоматически перед исчисляемым в
единственном числе.

## Разогрев

Один факт: артикль для англоязычного — не украшение, а **информация**. `a/an` сообщает:
«предмет новый, ты его ещё не знаешь, один из многих».

## Новая тема

### Когда `a/an`

Перед **исчисляемым существительным в единственном числе**, когда предмет не конкретный,
упомянут впервые, «какой-то один»:

> `I need a pen.` — нужна какая-нибудь ручка.
> `There is a problem.` — есть некая проблема.
> `She is a teacher.` — она учитель (одна из профессии).

### `a` или `an` — по звуку

Выбор только ради удобства произношения, ориентир — **звук**, не буква:
- согласный звук → `a`: `a cat`, `a dog`, `a university` («ю» — согласный).
- гласный звук → `an`: `an apple`, `an egg`, `an hour` (немая `h` → гласный звук).

### Где `a/an` НЕ ставится

- множественное число: ❌ `a cats` → `cats`.
- неисчисляемое: ❌ `a water` → `water`.
(Для «несколько» там будет `some` — это модуль 06.)

## Разобранные примеры

1. «Мне нужна ручка.» → `I need a pen.`
2. «Она съедает яблоко каждый день.» → `She eats an apple every day.` (гласный звук)
3. «Он ждал час.» → `He waited for an hour.` (немая h)
4. «Это университет.» → `It is a university.` (звук «ю»)
5. «У меня есть машина.» → `I have a car.` (не опускай артикль — частая русская ошибка!)

## Итог

`a/an` — «один какой-то, новый», ставится перед исчисляемым в единственном числе.
`a` перед согласным звуком, `an` — перед гласным (ориентир — звук: `a university`,
`an hour`). Перед множественным и неисчисляемым его нет. Главное — **не опускай артикль
по русской привычке** (`I have a car`, не `I have car`). Следующий урок — `the`.
