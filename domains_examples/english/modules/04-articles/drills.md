# Упражнения

Вставь `a`, `an`, `the` или ничего (нулевой артикль). Думай о «флаге известности».

## Блок 1. a / an

```drill
type: fill-in
prompt: "I need ___ pen. (любая ручка)"
answer: a
check: exact
```

```drill
type: fill-in
prompt: "She eats ___ apple every day."
answer: an
check: exact
hint: гласный звук
```

```drill
type: fill-in
prompt: "He waited for ___ hour."
answer: an
check: exact
hint: h немая → гласный звук
```

```drill
type: multiple-choice
prompt: "Выбери правильное:"
options: [an university, a university, the university (если про любой), university]
answer: a university
check: exact
hint: звучит «ю» — согласный звук
```

## Блок 2. the

```drill
type: fill-in
prompt: "Close ___ door, please. (дверь в комнате одна)"
answer: the
check: exact
```

```drill
type: fill-in
prompt: "I bought a book. ___ book is great."
answer: The
check: fuzzy
hint: второе упоминание → известное
```

```drill
type: fill-in
prompt: "___ sun is very bright today."
answer: The
check: fuzzy
hint: солнце одно → единственное в контексте
```


```drill

```

```drill
type: fill-in

```

```drill

```



## Блок 5. Частотные случаи the и нулевого артикля

```drill
type: fill-in

hint: превосходная степень → the
```



```drill

```



```drill
type: free-form
prompt: "Объясни своими словами, чем русский заменяет артикли, и переведи оба варианта: «В комнату вошёл мужчина» / «Мужчина вошёл в комнату»."
answer: Русский показывает известность порядком слов и словами «один / какой-то / тот самый». «В комнату вошёл мужчина» = A man came into the room (новый). «Мужчина вошёл в комнату» = The man came into the room (уже известный).
check: manual
```
