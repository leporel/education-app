# Карточки

`was/were`, помощник `did`, топ неправильных глаголов (зубрить!), `going to` / `will`.

## to be в прошлом

```card
front: to be в прошлом для I / he / she / it
back: was → I was, she was
tags: [past, to-be]
```

```card
front: to be в прошлом для you / we / they
back: were → you were, they were
tags: [past, to-be]
```

```card
front: "\"Ты был там?\" — собрать"
back: Were you there?
hint: to be спрашивает сам, без did
tags: [past, to-be]
```

## Помощник did

```card
front: Помощник для отрицания/вопроса в прошлом (все лица)?
```


## Правильные глаголы (-ed)

```card
front: Как образуется прошлое у правильных глаголов?
back: + -ed для всех лиц (work → worked). На -e → +d (live → lived). Согл.+y → -ied (study → studied).
tags: [past, regular]
```

```card
front: stop → прошлое?
back: stopped (короткое слово удваивает согласную)
tags: [past, regular, spelling]
```

## Будущее

```card
front: Формула "going to" + когда?
back: am/is/are + going to + глагол. План, намерение, видимый признак.
tags: [future, going-to]
```

```card
front: "\"Я собираюсь учить английский.\" — собрать"
back: I am going to learn English.
tags: [future, going-to]
```

```card
front: Формула "will" + когда?
back: will + голый глагол (все лица). Решение в момент речи, предсказание, обещание.
tags: [future, will]
```

```card
front: "\"Я тебе помогу.\" (решил сейчас) — собрать"
back: I will help you. (I'll help you.)
tags: [future, will]
```

```card
front: will + not = ?

```


## Как звучит -ed

```card
front: Когда -ed звучит как лишний слог [ɪd]?
back: "только после t/d: wanted [ˈwɒntɪd], needed, started. В остальных случаях — просто [t] или [d]"
tags: [past, pronunciation]
```

```card
front: worked и played — чем отличаются на слух?
back: worked [wɜːkt] — глухой [t] (после глухого k); played [pleɪd] — звонкий [d]
tags: [past, pronunciation]
```

## Узнавание при чтении

```card
front: Увидел в тексте "I have finished" — как понимать?
back: have/has + третья форма = «уже случилось, и это важно сейчас». Смысл несёт последнее слово
tags: [reading]
```

```card
front: Увидел "I was working when she called" — как понимать?
back: was/were + глагол-ing = «в тот момент было в процессе»
tags: [reading]
```

```card
front: Увидел "The shop was closed" — как понимать?
back: "be + третья форма = с предметом что-то сделали, исполнитель не важен: «магазин был закрыт»"
tags: [reading]
```

## Термины

```card
front: Что такое «три формы глагола»?
back: "go — went — gone: словарная (V1), прошлое (V2), причастие (V3, живёт при помощнике: have gone). Сейчас нужны первые две"
tags: [term]
```

```card
front: Правильный vs неправильный глагол — простыми словами?
back: правильный делает прошлое по правилу +ed (work → worked); неправильный имеет своё прошлое (go → went)
tags: [term]
```
