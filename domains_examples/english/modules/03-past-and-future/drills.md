# Упражнения

Past simple (`was/were`, `-ed`, неправильные), помощник `did`, будущее `going to`/`will`.

## Блок 1. was / were

```drill
type: fill-in
prompt: "I ___ tired yesterday."
answer: was
check: exact
```

```drill
type: fill-in
prompt: "They ___ at home."
answer: were
check: exact
```

```drill
type: translate
prompt: "Переведи: Ты был там?"
answer: Were you there?
check: fuzzy
hint: to be спрашивает сам
```

## Блок 5. Будущее: going to / will

```drill
type: translate
prompt: "Переведи: Я собираюсь учить английский."
answer: I am going to learn English. | I'm going to learn English.
check: fuzzy
```

```drill
type: translate
prompt: "Переведи: Холодно. Я закрою окно. (решение сейчас)"
answer: It's cold. I'll close the window. | It is cold. I will close the window.
check: fuzzy
hint: спонтанное решение → will
```

```drill
type: multiple-choice
prompt: "«Мы переезжаем в следующем году» (готовый план):"
options: [We will move next year., We are going to move next year., We move next year., We moving next year.]
answer: We are going to move next year.
check: exact
hint: план → going to
```

```drill
type: multiple-choice
prompt: "Где ошибка?"
options: [She will come., He will comes., I won't go., Will you help me?]
answer: He will comes.
check: exact
hint: will + голый глагол, без -s
```

```drill
type: free-form
prompt: "Напиши 3 предложения: что ты делал вчера (past), твой план на будущее (going to), и спонтанное обещание (will)."
answer: "Например: Yesterday I worked and saw a friend. I am going to learn Japanese. I'll call you later. (проверь: did/неправильные, going to + глагол, will + голый глагол)"
check: manual
```


```drill

```

```drill
type: free-form
prompt: "Прочитай и перескажи по-русски: «The shop was closed, so we went to a cafe. We had never been there before, but the coffee was great.»"
answer: «Магазин был закрыт, поэтому мы пошли в кафе. Мы там никогда раньше не были, но кофе был отличный.» (was closed — с магазином что-то сделали; had never been — до того момента)
check: manual
```

## Блок 9. Как звучит -ed

```drill
type: multiple-choice
prompt: "В каком слове -ed даёт лишний слог [ɪd]?"
options: [worked, played, wanted, lived]
answer: wanted
check: exact
hint: лишний слог только после t/d
```

```drill
type: free-form
prompt: "Раздели на группы по звучанию -ed: stopped, needed, opened, watched, started, played."
answer: "[t]: stopped, watched; [d]: opened, played; [ɪd]: needed, started (лишний слог только после t/d)"
check: manual
```
