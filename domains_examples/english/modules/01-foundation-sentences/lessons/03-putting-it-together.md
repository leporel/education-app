# Урок 03 — Собираем живые предложения

Теория есть, детали есть — пора собрать всё в работающий навык. Этот урок почти весь —
практика: один алгоритм сборки и много перевода RU→EN на бытовых сценах.

## Разогрев

Три инструмента из прошлых уроков, всё в одном месте:

- **Порядок:** Subject → Verb → Object. Подлежащее обязательно (нет — `it`).
- **Описание** (кто/какой/где) → `to be`: I — am, he/she/it — is, остальные — are.
- **Действие** (обычный факт) → present simple; для he/she/it глагол с `-s`.

## Новая тема: алгоритм сборки предложения

Когда нужно сказать что-то по-английски, прогоняй мысль через три вопроса:

1. **Кто действует?** → ставь подлежащее первым. Нет осмысленного → `it`.
2. **Это описание или действие?**
   - Описание (он какой / кто / где) → `to be` (`am/is/are`).
   - Действие (делает что-то) → обычный глагол. `he/she/it`? → не забудь `-s`.
3. **Что дальше?** → дополнение и остаток по порядку SVO.

Прогоним вслух на одной фразе — «Она дома и пьёт кофе»:

- «Она дома» → описание (где) → `She is at home`.
- «(она) пьёт кофе» → действие, she → +s → `she drinks coffee`.
- Склеиваем через `and`: **`She is at home and drinks coffee.`**

## Разобранные примеры

Сцена за сценой — обычный бытовой английский, без техники:

1. **«Доброе утро! Я устал, но счастлив.»**
   - `Good morning! I am tired but happy.`
   - Два описания подряд держит один `to be`: `I am tired but happy` (не нужно второе
     `am`).

2. **«Моя сестра живёт здесь. Она любит этот город.»**
   - `My sister lives here. She likes this city.`
   - `sister` = «она» = 3-е лицо → `lives`, `likes` — обе с `-s`.

3. **«Нам нужно больше времени. Кофе холодный.»**
   - `We need more time. The coffee is cold.`
   - Действие (`need`, we → без -s) + описание (`is`).

4. **«Они работают сегодня, но я нет.»**
   - `They work today, but I don't.`
   - `don't` (= do not) — это уже отрицание; пока просто запомни оборот «but I don't»
     как готовую фразу, разберём механику в модуле 02.

5. **Ловушка:** «Я иду домой.»
   - ❌ `I am go home.` — смешали `to be` и глагол.
   - ✅ `I go home.` — просто действие.

## Итог

Любое простое предложение собирается одним алгоритмом: **кто → описание или действие →
остаток по SVO.** Описание держит `to be`, действие — обычный глагол с `-s` для
he/she/it. Несколько описаний подряд может тянуть один `to be` (`tired but happy`).
Не смешивай `to be` с обычным глаголом. На этом каркас готов — ты умеешь строить
утверждения. Дальше (модуль 02) — как сказать «нет» и как задать вопрос.
