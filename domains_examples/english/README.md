# Английский язык

Бытовой английский с нуля-после-школы: научиться **самому строить предложения** и
**читать обычный, не технический текст**. Цель — функциональный повседневный язык, а
не академическое совершенство и не подготовка к экзаменам.

## Файлы

- [`CLAUDE.md`](./CLAUDE.md) — инструкции для Claude по этому домену.
- [`memory.md`](./memory.md) — память: что выучено, слабости, рабочие приёмы.
- [`roadmap.md`](./roadmap.md) — план обучения.

## Модули

- [`01-foundation-sentences`](./modules/01-foundation-sentences/index.md) — каркас
  предложения: порядок слов, `to be`, местоимения (`I/me/my/mine`), present simple, `-s`,
  множественное число, чтение транскрипции.
- [`02-present-and-questions`](./modules/02-present-and-questions/index.md) — отрицания
  и вопросы (`do/does`), вопросы про подлежащее (`Who lives here?`), `can`,
  present continuous, simple vs continuous.
- [`03-past-and-future`](./modules/03-past-and-future/index.md) — past simple
  (`was/were`, `-ed`, неправильные, `did`), маркеры прошлого, `there was/were`, будущее
  (`going to` / `will`), узнавание составных времён при чтении.
- [`04-articles`](./modules/04-articles/index.md) — артикли `a/an/the` и нулевой.
- [`05-prepositions`](./modules/05-prepositions/index.md) — предлоги места, времени и
  движения; «как долго» (`for/until/by/during`); приклеенные предлоги и первые фразовые
  глаголы.
- [`06-determiners-quantity`](./modules/06-determiners-quantity/index.md) —
  исчисляемость, `some/any`, `much/many`, `this/that`, степени сравнения
  (`cheaper than`, `the best`).
- [`07-everyday-vocabulary`](./modules/07-everyday-vocabulary/index.md) — частотная
  бытовая лексика по темам (люди, дом, еда, время, погода, деньги), числа, часы, даты и
  готовые вежливые фразы.
- [`08-reading-simple-texts`](./modules/08-reading-simple-texts/index.md) — стратегии
  чтения бытовых текстов: суть-вперёд, когнаты и ложные друзья, разбор слова на части,
  контекст, chunking.
