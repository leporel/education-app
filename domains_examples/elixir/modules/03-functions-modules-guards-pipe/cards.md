# Карточки

## Функции и модули

```card
front: Чем отличаются def и defp?
back: def — публичная функция модуля (видна снаружи), defp — приватная (видна только внутри модуля). Вызов чужой defp снаружи → UndefinedFunctionError. Аналог экспортируемых/неэкспортируемых функций пакета в Go.
tags: [elixir, functions]
```

```card
front: Что возвращает функция Elixir и где return?
back: Возвращается значение последнего выражения тела. Оператора return нет вообще. «Ранний выход» выражается через multi-clause или case/cond, а не return.
tags: [elixir, functions, return]
```

```card
front: Что такое арность и почему `foo/1` ≠ `foo/2`?
back: Арность — число аргументов функции. Идентичность функции = имя + арность. foo/1 и foo/2 — две РАЗНЫЕ функции, не перегрузка. В доках, ошибках и &-захвате арность указывают всегда (String.split/2).
tags: [elixir, arity]
```

## Multi-clause и guards

```card
front: Что такое multi-clause функция и как выбирается ветка?
back: Несколько «голов» одной функции с разными образцами в аргументах. Рантайм пробует их сверху вниз и выполняет первую совпавшую (pattern matching как диспетчер вместо if/switch). Ни одна не подошла → FunctionClauseError.
tags: [elixir, multiclause]
```

```card
front: Почему порядок clause важен?
back: "Clause проверяются сверху вниз, выполняется первая совпавшая. Общий образец `_` сверху перехватит всё, и специфичные ниже не сработают. Правило: специфичное — выше, общее (_) — последним."
tags: [elixir, multiclause, order]
```

```card
front: Зачем нужны guards (when) и какое у них ограничение?
back: "Образец проверяет форму; guard добавляет условие на значение (диапазон, тип, сравнение): `def f(n) when is_integer(n) and n > 0`. Ограничение: только чистые безопасные конструкции (сравнения, булева логика, type-checks, in), нельзя звать произвольные свои функции."
tags: [elixir, guards]
```

```card
front: Куда деть логику, которая не помещается в guard?
back: В тело функции через case/cond, либо разбить на функции. Guard обязан быть чистым и быстро вычислимым, поэтому произвольные вызовы там запрещены. Свой переиспользуемый guard — через defguard.
tags: [elixir, guards]
```

## Пайп

```card
front: Что делает оператор `|>` и почему стдлиб «data-first»?
back: "Пайп подставляет значение слева ПЕРВЫМ аргументом функции справа: `x |> f(y)` == `f(x, y)`. Читается сверху вниз как конвейер. Поэтому стдлиб спроектирована так, что главные данные идут первым аргументом (Enum.map(list, f)) — под удобный пайп."
tags: [elixir, pipe]
```

```card
front: Перепиши `c(b(a(x)))` через пайп.
back: "`x |> a() |> b() |> c()`. Пайп превращает вложенные вызовы «изнутри наружу» в конвейер сверху вниз, не меняя семантики."
tags: [elixir, pipe]
```

## Анонимные функции и рекурсия

```card
front: Как вызвать анонимную функцию и чем это отличается от именованной?
back: "Анонимную — через точку: `f.(args)`. Именованную — `Mod.fun(args)`. Точка обязательна и отличает «вызвать значение-функцию» от обращения к полю. `square = fn x -> x*x end; square.(5)`."
tags: [elixir, anonymous-fn]
```

```card
front: Что значит `&(&1 * 2)` и `&String.upcase/1`?
back: Capture-синтаксис. `&(&1 * 2)` — короткая анонимная функция, &1 это первый аргумент (== fn x -> x*2 end). `&String.upcase/1` — захват существующей именованной функции по имени/арности как значения (для передачи в Enum.map и т.п.).
tags: [elixir, capture]
```

```card
front: Как заменить цикл for из Go в Elixir?
back: Рекурсией с аккумулятором (или Enum/Stream поверх неё). База — пустой список возвращает acc, шаг — обрабатывает голову и рекурсивно идёт по хвосту с обновлённым acc. Мутируемого счётчика нет — новый acc передаётся в следующий вызов.
tags: [elixir, recursion]
```

```card
front: Что такое хвостовой вызов и почему он важен для рекурсии?
back: Рекурсивный вызов, стоящий ПОСЛЕДНИМ действием clause. BEAM выполняет его без роста стека (tail-call optimization) — рекурсия с аккумулятором не переполнит стек даже на длинных списках, работая как цикл. Рекурсия `h + sum(t)` (не хвостовая) копит стек.
tags: [elixir, tail-call, recursion]
```

## Директивы модулей

```card
front: "alias, import, require — что делает каждая?"
back: "alias сокращает имя модуля (alias MyApp.Accounts.User → User.new()). import втягивает функции, чтобы звать без префикса (обязательно с only:). require нужен только для МАКРОСОВ модуля (require Logger). Все три лексические — действуют только там, где написаны."
tags: [elixir, alias, import, require]
```

```card
front: "Почему import без only: считается плохой практикой?"
back: "Втянутые «все подряд» функции делают код нечитаемым: непонятно, откуда взялась функция и не конфликтует ли она с локальной. По умолчанию бери alias (сокращение имени), а import применяй точечно: import Enum, only: [map: 2]."
tags: [elixir, import, style]
```

```card
front: "Зачем нужен require Logger, если для Enum ничего не требуется?"
back: "Logger.info и подобные — это МАКРОСЫ: компилятор должен раскрыть их в твоём файле, поэтому модуль нужно предварительно require. Обычные функции (Enum.map) доступны без директив, максимум им нужен alias для сокращения имени."
tags: [elixir, require, macro]
```

## Дефолты и пайп

```card
front: "Как объявить дефолтный аргумент у multi-clause функции?"
back: "Одной заголовочной clause без тела: def join(list, sep \\\\ \", \") — а дальше обычные clause без дефолтов. Если написать \\\\ в каждой clause, компилятор скажет «defines defaults multiple times»."
tags: [elixir, defaults, multiclause]
```

```card
front: "Что делают then/2 и tap/2 в конвейере?"
back: "then(value, fun) применяет произвольную функцию к значению — спасение, когда значение нужно НЕ первым аргументом. tap(value, fun) выполняет побочный эффект (лог, печать) и пропускает значение дальше без изменений. then заменяет неуклюжее |> (fn x -> ... end).()."
tags: [elixir, pipe, then, tap]
```

```card
front: "Как посмотреть промежуточное значение в пайпе, не ломая его?"
back: "|> IO.inspect(label: \"после filter\") — печатает с меткой и ВОЗВРАЩАЕТ значение дальше по конвейеру. Ещё есть dbg(): печатает весь пайп по шагам с промежуточными результатами и указанием файла/строки (в iex — с пошаговым режимом). В коммит отладочную печать не оставляют."
tags: [elixir, debug, inspect, dbg]
```
