# Урок 03 — Ретроспектива: разбор работ по чек-листу и план на месяц

Сессия 40 минут, и рисовать в ней почти не придётся. Это урок-инструмент: вы один раз
проходите процедуру разбора и выходите с личным планом на месяц. Дальше вы будете
повторять её сами раз в неделю по 15 минут.

Что нужно: все работы, накопленные за время обучения (или фотографии из `misc/`),
блокнот для записей, таймер. Разложите работы на столе или полу в порядке от самых
старых к самым новым.

## Разогрев (5 минут)

Не разминка руки, а разминка глаза:

1. Возьмите три работы разного времени и посмотрите на них с четырёх метров. Что
   читается? Что превратилось в кашу?
2. Уменьшите их превью до размера ногтя — на превью выживают только большие массы и фокус.

Запишите одну строку: что изменилось между самой старой и самой новой работой. Только
факт, без оценок.

## Часть 1. Разбор по чек-листу (15 минут)

Возьмите **пять** работ (не все — иначе процедура растянется и вы её больше не повторите)
и пройдите каждую по семи пунктам. Отвечать строго **да/нет**, без рассуждений:

1. **Композиция.** Есть один фокус? Кадр поделён неравными частями?
2. **Пропорции.** Проверял ли я их измерением? Где ошибка больше всего?
3. **Перспектива.** Параллели сходятся? Линия горизонта одна и та же для всех предметов?
4. **Форма и свет.** Источник один? Есть терминатор, ядро тени, рефлекс?
5. **Края.** Есть разные типы краёв или всё одинаково резкое?
6. **Тон.** Использован весь диапазон — от чистой бумаги до почти чёрного?
7. **Что стало лучше**, чем месяц назад?

Седьмой пункт обязателен и не подлежит пропуску. Разбор, состоящий только из ошибок,
демотивирует — и вы просто перестанете его делать.

Правило записи: **ошибка превращается в действие**. Не «плохие тени», а «не сгустил
ядро за терминатором — сделать это отдельным шагом на следующих трёх работах». Не
«кривая перспектива», а «не отмечал линию горизонта первой — отмечать всегда».

```drill
type: free-form
prompt: "Разбор пяти работ. 15 минут. Пройти каждую по семи пунктам чек-листа, отвечая да/нет, и переформулировать каждую найденную ошибку в конкретное действие."
answer: "Разобраны ровно пять работ по всем семи пунктам; ответы даны в форме да/нет, без рассуждений; каждая ошибка записана как действие, а не как оценка; отдельно записано, что стало лучше; «разбор занял 15 минут и не превратился в самобичевание»"
check: manual
```

## Часть 2. Три слабых места (7 минут)

Пройдите по своим записям и выпишите **три** самых часто повторяющихся замечания. Не
десять — три. Больше трёх задач одновременно не тренируется.

Типичные кандидаты, чтобы было с чем сверяться: эллипсы с углами; голова великовата, ноги
коротковаты; всё в средних тонах, нет ни белого, ни чёрного; все края одинаково резкие;
фокуса нет; фигура «плавает».

Для каждого из трёх слабых мест выберите **одно конкретное упражнение** из drills
соответствующего модуля. Не «поработать над тоном», а «упражнение на тональную шкалу и
попадание в ступень, три раза в неделю».

```drill
type: free-form
prompt: "Три слабых места. 7 минут. Выписать три самых частых замечания из разбора и подобрать к каждому одно конкретное упражнение из drills нужного модуля."
answer: "Выписаны ровно три слабых места, не больше; каждое сформулировано конкретно, а не «рисовать лучше»; к каждому подобрано названное упражнение из конкретного модуля; указана частота выполнения; «список поместился в четыре строки»"
check: manual
```

## Часть 3. План на месяц (10 минут)

Теперь соберите месяц. Формат — четыре недели, каждая с одним фокусом. Опирайтесь на
таблицу 90 дней из [`theory-2-sketching-habit.md`](../theory-2-sketching-habit.md), но
подставьте **свои** три слабых места вместо тем, которые уже даются легко.

Каркас, который стоит просто заполнить:

| Неделя | Фокус (слабое место) | Ежедневно 20–40 мин | Критерий «прошёл» |
|---|---|---|---|
| 1 | | разминка 5 мин + упражнение + удовольствие | |
| 2 | | | |
| 3 | | | |
| 4 | | ретроспектива в конце недели | |

Правила заполнения:

1. **Одна тема на неделю.** Две темы в неделю — это ноль тем.
2. **Критерий «прошёл» должен быть проверяемым.** «Стало лучше» не годится. «Попадаю в
   заданную ступень тона с точностью ±1» — годится.
3. **Каждый день имеет три части**: разминка 5 минут (всегда одинаковая), упражнение,
   рисование ради удовольствия. Правило 50% не обсуждается: без удовольствия обучение
   выгорает за месяц.
4. **Впишите минимальную версию сессии** на плохой день: пять минут, одна страница
   жеста. Один пропуск допустим, два подряд — нет.
5. **Впишите два скетча с натуры в неделю**: короткий и получасовой.
6. **Назначьте день ретроспективы** — конкретный, например воскресенье вечером.

```drill
type: free-form
prompt: "План на месяц. 10 минут. Заполнить таблицу из четырёх недель: фокус недели, ежедневная практика по трём частям, проверяемый критерий; вписать минимальную версию сессии, два скетча с натуры в неделю и день ретроспективы."
answer: "В каждой неделе ровно один фокус; критерии сформулированы измеримо, а не как «стало лучше»; в каждом дне есть разминка, упражнение и рисование для удовольствия; вписаны минимальная версия сессии и день ретроспективы; «план висит на видном месте рядом с материалами»"
check: manual
```

## Часть 4. Про плато (3 минуты)

Прогресс идёт ступенями: период роста, потом ощущение, что стало хуже. Причина не в
деградации, а в том, что **глаз растёт быстрее руки** — вы начали видеть ошибки,
которых раньше не замечали.

Впишите в план строчку «если кажется, что стало хуже» и три пункта под ней:

- сменить жанр на неделю (натюрморты → улица, люди → предметы);
- уменьшить задачу до пяти минут в день;
- достать работы месячной давности и сравнить — только с собой, не с интернетом.

## Чек-лист урока

- Разобраны пять работ по всем семи пунктам.
- Каждая ошибка переформулирована в конкретное действие.
- Записано, что стало лучше.
- Выписаны ровно три слабых места, не больше.
- К каждому подобрано конкретное упражнение из drills.
- План на четыре недели заполнен, у каждой недели один фокус.
- Критерии «прошёл» измеримы.
- Вписаны минимальная версия сессии, два скетча с натуры в неделю, день ретроспективы.
- Есть заготовка «если кажется, что стало хуже».

## Итог

Вы прошли все восемь модулей — и главное, что осталось в руках, это не набор приёмов, а
рабочий цикл: **посмотреть → решить композицию → построить → разложить свет и тень →
уточнить края → разобрать и записать вывод**. Этот цикл одинаков для чайника, улицы и
портрета; меняется только сложность формы.

Дальше домен превращается из курса в практику. Возвращайтесь к теории того модуля, чья
тема всплывёт в очередной ретроспективе. Направления для роста собраны в конце
[`theory-2-sketching-habit.md`](../theory-2-sketching-habit.md) — выбирайте одно на
несколько месяцев, а не все сразу.

И последнее, самое практичное: держите карандаш и блокнот на виду, фотографируйте
работы по датам и сравнивайте себя только с собой месяц назад. Всё остальное — вопрос
накопленных часов, а они у вас теперь идут.
