# Карточки

Композиционные правила и механика привычки. Вторая часть карточек не про рисование, а
про то, как продолжать рисовать — она не менее важна.

## Композиция

```card
front: "Что такое композиция?"
back: "Решения, принятые до первой линии: что в кадре, что за кадром, куда смотрит зритель, как распределены тональные массы"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Где решается композиция — на большом листе или на миниатюре?"

```

```card
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Правило кадрирования краёв"

```

```card
front: "Что такое видоискатель (viewfinder)?"
back: "Прямоугольное окошко в куске картона или рамка из пальцев, сквозь которую выбирают кадр на натуре"
```

```card
front: "Что такое фокус (focal point) и сколько его должно быть?"
back: "Место, куда зритель смотрит первым. Один на работу; два конкурирующих фокуса заставляют глаз метаться"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Пять инструментов создания фокуса по убыванию силы"
back: "Контраст тона, резкость края, детализация, направляющие линии, изоляция"

```

```card
front: "Зачем нужно правило третей и где его границы?"
back: "Оно защищает от предмета по центру и горизонта посередине. Это костыль, а не закон: центральные композиции бывают очень сильными"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Более полезная замена правилу третей"
back: "Делить кадр неравными частями: небо и земля в отношении 1:2 или 2:1, но не 1:1"

```

```card
front: "Что такое notan?"
back: "Упрощение композиции до 2–3 плоских тональных масс без деталей и полутонов — быстрая проверка, читается ли работа вообще"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Главное правило тональной структуры"
back: "Светлое на тёмном или тёмное на светлом: главный объект должен отличаться по тону от того, на чём он стоит"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Сколько крупных тональных масс должно читаться в хорошей композиции?"
back: "Три-четыре. Три массы лучше десяти"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Что такое направляющие линии (leading lines)?"
back: "Линии, ведущие взгляд внутрь кадра к фокусу: дорога, перила, край стола, тень, взгляд персонажа. Линия, выводящая глаз из кадра — ошибка"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Что такое баланс в композиции?"
back: "Не симметрия, а равновесие: большое спокойное пятно уравновешивается маленьким контрастным акцентом, как груз на рычаге"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Что такое касание (tangent) и как его лечить?"
back: "Соприкосновение или почти-соприкосновение контуров, схлопывающее глубину (дерево «растёт» из плеча, макушка на линии горизонта). Лечение — сдвинуть на сантиметр: либо явно перекрывает, либо явно расходится"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Простейший способ показать глубину"
back: "Перекрытие (overlap): то, что перекрывает другой предмет, воспринимается ближе"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Правила рисования миниатюр (thumbnails)"
back: "Шесть штук 4×6 см, по минуте каждая, только пятна без контуров, варианты обязаны отличаться форматом, кадрированием или раскладкой тонов"
tags: [drawing, composition-and-sketching-habit]
```

## Натура и скетчинг

```card
front: "Признаки хорошего мотива для скетча новичка"
back: "Ясная тональная раскладка, один главный объект, мотив не убежит за 20 минут, вам удобно сидеть"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Чем отличается пятиминутный скетч от получасового?"
back: "Пятиминутный — про выбор (большие массы, одна направляющая, один акцент). Получасовой — про построение (миниатюра, каркас, тональные массы, детали в фокусе)"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Алгоритм urban sketch"
back: "Видоискатель → две миниатюры → компоновка габаритами → линия горизонта и точки схода → большие формы → проверка измерением → тональные массы → детали только в фокусе → дата и место"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Где на уличном скетче проходит линия горизонта?"
back: "На уровне ваших глаз. Отмечается на листе первой, всё остальное строится от неё"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Почему на здании нельзя начинать с окон?"
back: "Здание — это коробка, окна — фактура на ней. Двух рядов окон достаточно, остальное зритель достроит сам"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Почему тональную раскладку на улице фиксируют в первые пять минут?"
back: "Свет меняется. Решение принимается один раз, и дальше вы держитесь его, даже если солнце ушло"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Пять приёмов рисования людей в кафе"
back: "Рисовать позу линией действия, ждать повторения позы, собирать фигуру из разных людей, не смотреть в упор, начинать с читающих и спящих"
tags: [drawing, composition-and-sketching-habit]
```

## Привычка

```card
front: "Структура ежедневной сессии"
back: "Разминка 5 минут (всегда одинаковая) → упражнение 10–20 минут с чек-листом → рисование для удовольствия 10–15 минут"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Правило 50%"
back: "Половина времени практики уходит на рисование ради удовольствия, без критериев. Обучение без удовольствия выгорает, удовольствие без обучения не растёт"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Почему 20 минут в день лучше трёх часов по субботам?"
back: "20 минут шесть дней в неделю дают более 100 часов за год и держатся; занятия «по настроению» обычно заканчиваются к весне"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Три элемента инфраструктуры привычки"
back: "Фиксированное время с привязкой к существующему ритуалу; материалы всегда на виду; минимальная версия сессии на пять минут для плохих дней"

```

```card
front: "Сколько пропусков подряд допустимо?"
```


```card
front: "Обязательный пункт еженедельного разбора"
back: "Что получилось лучше, чем неделю назад. Разбор из одних ошибок демотивирует и потому не работает"
```

```card
front: "Что такое плато и почему оно возникает?"
back: "Период, когда кажется, что стало хуже: глаз растёт быстрее руки, и вы начинаете видеть ошибки, которых раньше не замечали"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "Четыре способа пройти плато"
back: "Сменить жанр на неделю, уменьшить задачу до пяти минут, достать старые работы для сравнения, сравнивать себя только с собой месяц назад"
tags: [drawing, composition-and-sketching-habit]
```

```card
front: "С кем осмысленно сравнивать свои работы?"
back: "Только с собой месяц назад. Сравнение с работами из сети не даёт информации и разрушает мотивацию"
tags: [drawing, composition-and-sketching-habit]
```
