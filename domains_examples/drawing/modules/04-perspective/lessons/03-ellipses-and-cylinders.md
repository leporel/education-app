# Урок 03 — Эллипсы и цилиндры в перспективе: кружка и колесо

Длительность: **45 минут**. Нужны: карандаш HB и 2B, 4 листа A4, кружка, любой круглый
предмет (банка, рулон скотча), таймер. Перед уроком прочитайте
[`theory-2-ellipses-and-cylinders.md`](../theory-2-ellipses-and-cylinders.md).

## Разогрев — 5 минут

Стандартная разминка, но с акцентом на эллипсы: две ячейки таблицы эллипсов вместо
одной и две воронки. Дальше эллипсов будет много.

Плюс пять коробок от руки — фоновая практика модуля.

## Шаг 1. Живой эксперимент — 3 минуты

Возьмите кружку, поставьте её на стол и медленно поднимайте до уровня глаз, глядя
на ободок.

Что вы увидите: ободок из широкого эллипса становится всё уже и на уровне глаз
превращается в **прямую линию**. Поднимите выше — эллипс снова раскроется, но теперь
вы видите кружку снизу.

Это правило степени: **чем дальше круг от линии горизонта, тем он «круглее»**.
Один эксперимент экономит месяц ошибок.

```text
   высоко над HL:   (      )   широкий, видим снизу
   ближе к HL:       (    )
   на HL:            ------    линия
   ниже HL:          (    )
   ещё ниже:        (      )   широкий, видим сверху
```

## Шаг 2. Лестница эллипсов — 8 минут

Упражнение, закрепляющее правило.

1. Проведите вертикальную **ось** через весь лист и горизонтальную **HL** посередине.
2. Нарисуйте на оси семь эллипсов: три выше HL, один **на** HL, три ниже.
3. Степень меняйте по правилу: на HL — линия, дальше от HL — всё шире.
4. Малая ось каждого эллипса лежит на общей вертикали.

Проверка: закройте лист рукой сверху и снизу и посмотрите на переход — он должен быть
плавным, без скачков. И ещё: у эллипсов над HL и под HL на равном удалении степень
одинаковая.

```drill
type: free-form
prompt: "8 минут. Лестница эллипсов: вертикальная ось, HL посередине, семь эллипсов от «широкого сверху» до «широкого снизу», на HL — линия."
answer: "Степень растёт по мере удаления от HL в обе стороны; на HL эллипс выродился в линию; малые оси всех эллипсов лежат на общей вертикали; переход степеней плавный; концы эллипсов без углов."
check: manual
```

## Шаг 3. Цилиндры — 10 минут

Стоящий цилиндр:

1. Проведите **ось** — вертикаль.
2. Верхний эллипс: малая ось на оси, степень по расстоянию от HL.
3. Нижний эллипс на той же оси, **шире по степени** — он дальше от горизонта.
4. Соедините боковыми линиями, касаясь эллипсов **у концов большой оси**.
5. **Draw-through:** дорисуйте дальние половины обоих эллипсов.

Лежащий цилиндр:

1. Проведите **ось** — линию, уходящую в точку схода.
2. Оба эллипса **перпендикулярны оси**: их малые оси лежат **на этой оси**, а не
   вертикальны.
3. Дальний эллипс меньше ближнего.
4. Соедините по краям большой оси.

```text
   стоящий:              лежащий:
      .---.                  ось -> VP
     (     )              __.-'''-.__
      |   |            .-'           '-.
      |   |           (       ....      )
      |   |            '-.__.-'''-.__.-'
     (     )                малая ось лежит ВДОЛЬ оси,
      '---'                 а не вертикальна
   низ шире верха
```

Нарисуйте четыре цилиндра: два стоящих (один выше HL, один ниже) и два лежащих под
разными углами.

```drill
type: free-form
prompt: "10 минут. Четыре цилиндра: два стоящих (выше и ниже HL) и два лежащих под разными углами. У каждого провести ось и построить дальние половины эллипсов."
answer: "У каждого цилиндра проведена ось; малая ось каждого эллипса лежит на оси цилиндра; у стоящих нижний эллипс шире верхнего; боковые линии касаются эллипсов у концов большой оси; дальние половины построены."
check: manual
```

## Шаг 4. Кружка с натуры — 12 минут

Соединяем перспективу с измерением из
[`03-measuring-and-proportions`](../../03-measuring-and-proportions/index.md).

1. Поставьте кружку ниже уровня глаз, ручкой вбок, в 1,5 м.
2. **Замер:** отношение высоты к ширине корпуса, высота ручки к высоте кружки.
   Рука прямая, один глаз закрыт.
3. **Ось:** вертикаль через центр.
4. **Габарит:** верх, низ, левый и правый края.
5. **Эллипс ободка.** Малая ось на оси. Степень — по расстоянию от HL. Сравните с
   натурой: обычно новичок делает **уже**, чем есть.
6. **Толщина стенки:** второй, концентричный эллипс внутри первого, чуть меньше,
   той же степени.
7. **Эллипс донышка.** Обязательно **шире по степени**, чем ободок. Постройте его
   целиком, включая дальнюю половину, — так видно, что кружка стоит, а не приклеена.
8. **Стенки:** от концов большой оси верхнего эллипса к концам большой оси нижнего.
9. **Ручка:** лежит в вертикальной плоскости, проходящей через ось. Стройте её как
   плоскую дугу с толщиной, а не как «петельку сбоку».

Проверка: отойдите на два метра и посмотрите. Если кружка «складывается» или
выглядит наклейкой — почти наверняка донышко уже ободка.

```drill
type: free-form
prompt: "12 минут. Кружка с натуры ниже уровня глаз: замеры, ось, габарит, эллипс ободка, толщина стенки концентричным эллипсом, донышко шире по степени и построенное целиком, стенки от концов большой оси, ручка в вертикальной плоскости через ось."
answer: "Донышко по степени шире ободка; малые оси всех эллипсов лежат на одной вертикали; толщина стенки показана вторым концентричным эллипсом; дальняя половина донышка построена; ручка лежит в плоскости оси; при взгляде издалека кружка не складывается."
check: manual
```

## Шаг 5. Колесо — 7 минут

Колесо — короткий лежащий цилиндр, стоящий на земле. Здесь три ловушки подряд.

1. **Ось** колеса горизонтальна; если машина стоит под углом, ось уходит в точку схода.
2. **Эллипс покрышки:** малая ось = ось колеса.
3. **Диск:** концентричный эллипс той же степени, а не «кружок внутри».
4. **Толщина:** второй эллипс, сдвинутый **вдоль оси**. Не вниз и не вбок — вдоль оси.
   Это ловушка номер один: сдвиг вниз делает колесо плоским.
5. **Точка касания земли:** нижний конец **малой оси**, а не нижняя точка эллипса
   на листе. У наклонённого эллипса это разные точки, и разница видна сразу — машина
   либо «висит», либо «врастает» в асфальт.

```text
        ось колеса -> VP
      ----------------------
          .-'''''-.
         (    o    )   диск концентричен покрышке
          '-.___.-'
              |
              *  <- касание земли: конец малой оси
   ---------------------------- земля
```

```drill
type: multiple-choice
prompt: "Где колесо касается земли на рисунке?"
options: ["в самой нижней точке эллипса на листе", "в нижнем конце малой оси эллипса", "в центре эллипса", "в нижнем конце большой оси"]
answer: "в нижнем конце малой оси эллипса"
check: exact
```

## Чек-лист сессии

- [ ] У каждого круглого объекта проведена ось.
- [ ] Малая ось каждого эллипса лежит на оси объекта.
- [ ] Степень растёт с удалением от HL; на HL эллипс — линия.
- [ ] У стоящего цилиндра низ шире верха по степени.
- [ ] У лежащего цилиндра малая ось лежит вдоль его оси.
- [ ] Дальние половины эллипсов построены.
- [ ] Толщина колеса отложена вдоль оси, касание — конец малой оси.
- [ ] Листы сфотографированы в `misc/` с датой.

## Итог

Круглое в перспективе держится на двух правилах, и оба проверяются за пять секунд:
**малая ось = ось вращения** и **степень растёт с удалением от горизонта**. Всё
остальное — техника эллипса из
[`02-lines-and-basic-shapes`](../../02-lines-and-basic-shapes/index.md): быстро, от
плеча, два-три прохода.

Модуль 04 закончен. У вас есть каркас пространства: горизонт, точки схода, коробка,
цилиндр, деление и умножение. Этого хватает, чтобы построить почти любой рукотворный
предмет и простую сцену.

Не бросайте коробки: 10–15 в день с проверкой продлением ещё несколько недель. Дальше —
[`05-form-light-and-shadow`](../../05-form-light-and-shadow/index.md): те же формы,
но с тоном, и они наконец перестанут быть проволочными.
