# Урок 02 — Эллипсы: таблицы и в плоскостях

Длительность: **30–35 минут**. Нужны: карандаш HB или 2B, 3 листа A4, таймер.

## Разогрев — 5 минут

Наложенные линии (2 набора по 8), затем 10 ghosted-линий между точками, разные
направления. Обязательно включите диагональ вниз-вправо.

Одно напоминание: скорость исполнения равна скорости примерки. Если примеряли быстро,
а провели медленно — линия задрожит.

## Шаг 1. Анатомия эллипса — 3 минуты

Эллипс — это круг, увиденный под углом. Всё остальное следует из этого.

```text
              большая ось (major)
        <----------------------------->
                       :
                 ......:......
             ..'       :       '..
      ------.----------+----------.------  малая ось (minor)
             ''..      :      ..''
                 '''''':'''''
   концы — плавные, кривизна там максимальная, но углов НЕТ
```

- **Большая ось** — самый длинный диаметр.
- **Малая ось** — самый короткий, перпендикулярна большой.
- **Степень (degree)** — отношение малой оси к большой в градусах. 90° — круг (смотрим
  строго сверху), 20° — узкая щёлочка (смотрим почти в плоскости круга).
- **Малая ось = ось вращения объекта.** Стоящая кружка — вертикальная ось вращения,
  значит малая ось ободка вертикальна. Это правило понадобится в
  [`04-perspective`](../../04-perspective/index.md), а начинаем тренировать сейчас.

## Шаг 2. Как рисовать эллипс — 5 минут

Механика та же, что у линии: **быстро, от плеча, с примеркой**.

1. Наметьте место и размер.
2. Ghosting: покрутите карандаш **в воздухе** над листом 5–8 оборотов по нужной
   траектории. Рука должна поймать ритм.
3. Опустите карандаш и обведите **2 прохода** по одному следу, не отрывая карандаш и
   не сбавляя скорость. Три — максимум.
4. Не подправляйте. Кривой эллипс — рисуйте новый рядом.

Разминка: 20 эллипсов свободно по листу, разных размеров. Смотрите только на два
признака — есть ли углы на концах и не превратилось ли в клубок.

Главная ошибка здесь одна: **замедлиться**. Как только рука тормозит на повороте,
на конце большой оси появляется угол. Эллипс — единственная форма, где спешка полезна.

```drill
type: free-form
prompt: "5 минут. 20 свободных эллипсов разного размера по листу, каждый — ghosting в воздухе и 2-3 быстрых прохода от плеча."
answer: "Концы плавные, без углов и вмятин; не больше трёх проходов на эллипс; проходы лежат близко, нет клубка; вы не подправляли ни один эллипс."
check: manual
```

## Шаг 3. Таблица эллипсов — 9 минут

Упражнение на контроль размера и на «попадание в границу».

1. Расчертите лист от руки на **6 ячеек** — прямоугольников разной пропорции.
2. Заполните каждую ячейку рядом эллипсов так, чтобы каждый **касался верхней и нижней
   стенки** ячейки и **касался соседних эллипсов** — без наложений и без зазоров.
3. Внутри одного ряда держите **одинаковую степень**: все эллипсы должны выглядеть
   как один и тот же круг, только разного размера.

```text
   +--------------------------------------+
   | (   ) (   ) (   ) (   ) (   ) (   )  |   ХОРОШО: касаются, не лезут друг в друга
   +--------------------------------------+

   +--------------------------------------+
   | ( ) (  )(( ))  (   )    ( )  (    )  |   ПЛОХО: разная степень, зазоры,
   +--------------------------------------+          наложения
```

Это единственное место, где вы сознательно работаете на попадание в границу. Не
получилось — не стирайте, следующий ряд будет лучше.

```drill
type: free-form
prompt: "9 минут. Таблица эллипсов: 6 ячеек, каждая заполнена рядом эллипсов, касающихся стенок ячейки и друг друга."
answer: "Эллипсы касаются, но не пересекаются, и без зазоров; концы плавные; не больше трёх проходов; внутри ряда степень одинаковая; ничего не стиралось."
check: manual
```

## Шаг 4. Эллипсы в плоскостях — 8 минут

Соединяем два навыка.

1. Постройте плоскость из [урока 01](./01-lines-superimposed-and-ghosted.md): четыре
   точки, четыре ghosted-линии.
2. Впишите в неё эллипс так, чтобы он **касался всех четырёх сторон**.
3. Ключевой момент: если плоскость скошена, эллипс тоже наклонится. Не выравнивайте его
   по привычке в «вертикальный овал» — он должен лежать в плоскости, как монета на
   наклонной крышке стола.

Сделайте 8 таких плоскостей. Смотрите на четыре точки касания: часто эллипс касается
двух сторон и не достаёт до двух других — это значит, вы недооценили ширину.

Дальше — воронки, они закрепляют правило оси.

4. Нарисуйте дугу, проведите через неё прямую ось.
5. Нанижите на ось 5–7 эллипсов разного размера. Ось должна делить каждый **ровно
   пополам** и совпадать с их малой осью.

```text
        \                              /
         \    (  )  ( )  ()  ()  ( )  /
   -------+----+----+---+---+---+----+-------  ось
         /     (  )  ( )  ()  ()  ( ) \
        /                              \
   ось делит каждый эллипс пополам и совпадает с его малой осью
```

```drill
type: free-form
prompt: "8 минут. Восемь плоскостей с вписанными эллипсами (касание всех четырёх сторон), затем 3 воронки по 5-7 эллипсов на общей оси."
answer: "Эллипсы касаются всех четырёх сторон плоскости; наклон эллипса следует наклону плоскости, а не остаётся вертикальным; в воронках ось делит каждый эллипс пополам; малая ось каждого эллипса совпадает с осью воронки; размеры меняются плавно."
check: manual
```

## Чек-лист сессии

- [ ] Каждый эллипс рисовался после примерки в воздухе.
- [ ] Не больше трёх проходов на эллипс.
- [ ] На концах нет углов.
- [ ] В таблице эллипсы касаются без наложений.
- [ ] В воронках малая ось совпадает с осью.
- [ ] Ничего не стиралось; листы в `misc/` с датой.

## Итог

Эллипс — самая частая форма в реальных предметах и самая частая точка провала. Три
правила покрывают почти всё: **быстро от плеча**, **не больше трёх проходов**,
**малая ось = ось вращения**. Всё остальное — повторы.

Ежедневная норма на ближайшие две недели: одна ячейка таблицы и одна воронка в разминке.
Через две недели вернитесь к сегодняшнему листу и сравните концы эллипсов.

Следующая сессия — [урок 03](./03-warmup-and-shapes-sheet.md): собираем постоянную
пятиминутную разминку и делаем первый «лист форм».
