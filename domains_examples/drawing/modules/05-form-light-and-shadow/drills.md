# Упражнения

Все практические упражнения проверяются вами самими по рубрике в `answer`. Работайте с
таймером: время в задании — не «примерно», а ограничение, которое не даёт зависнуть на
вылизывании. Фото результата складывайте в `misc/` по датам — через три недели разница
будет очевидна.

Материалы по умолчанию: HB, 2B, 4B, клячка, офисная бумага A4, настольная лампа сбоку.

## Техника штриха

```drill
type: free-form
prompt: "Ровный тон. 15 минут. Начертите 12 квадратов 4×4 см. Заполните каждый ровным тоном ступени 3 простой штриховкой: одно направление, отрыв карандаша после каждого штриха, одинаковые промежутки."
answer: "Внутри квадрата нет светлых и тёмных полос; все штрихи одного наклона; на концах нет тёмных разворотов от зигзага; края квадрата не заезжают наружу; «отойдя на два метра, квадрат читается как ровное серое поле»"
check: manual
hint: медленнее рука — ровнее тон; скорость придёт сама
```

```drill
type: free-form
prompt: "Перекрёстная штриховка слоями. 10 минут. Один квадрат 6×6 см: положить пять слоёв штриха, каждый под 30–60° к предыдущему, доводя тон до почти чёрного. Ни разу не давить сильнее, чем на первом слое."
answer: "Пять слоёв различимы при близком рассмотрении; тон глубокий, без блеска графита; бумага не продавлена ногтем-рельефом; тон однороден по всему квадрату; «сравнил с 4B в один сильный нажим — слои темнее и чище»"
check: manual
```

```drill
type: free-form
prompt: "Градиент. 12 минут, 3 повтора. Полоска 3×15 см: слева чистая бумага, справа максимально тёмное, переход плавный. Метод — много лёгких проходов, каждый следующий начинается правее."
answer: "Нет видимых ступенек и стыков; левый край действительно белый; правый край действительно тёмный; переход монотонный, нигде не светлеет обратно; «прищурился — вижу плавную ленту, а не полосы»"
check: manual
```

```drill
type: free-form
prompt: "Тональная шкала на 9 ступеней. 25 минут, делается один раз. Полоска 3×27 см на 9 клеток: 1 — бумага, 9 — максимум, 5 — середина, остальные подгоняются между соседями. Подписать номера, повесить над столом."
answer: "Девять ступеней различимы с двух метров; нет двух одинаковых соседей; лестница ровная, без скачка посередине; внутри каждой клетки тон однороден; «шкала теперь висит на стене и я прикладываю её к рисункам»"
check: manual
```

```drill
type: free-form
prompt: "Штрих по форме. 15 минут. Нарисуйте три пустых контура — круг, цилиндр, конус — и заштрихуйте каждый ровным средним тоном, ведя штрих по форме: дугами, вдоль оси, к вершине. Тон везде одинаковый, объём должен читаться только за счёт направления штриха."
answer: "Направление штриха у каждой фигуры своё и соответствует форме; штрихи не сбиваются в клубок у вершины конуса; тон одинаков во всех трёх фигурах; форма угадывается без светотени; «направление штриха уже само рассказывает, что это за предмет»"
check: manual
```

## Свет на примитивах

```drill
type: free-form
prompt: "Карта света. 8 минут, 4 повтора с разным положением лампы. Поставьте на стол мяч или яблоко под настольную лампу. Не рисуя тона, обозначьте лёгкой линией только три вещи: границу света и тени, контур падающей тени, точку касания."
answer: "Граница света и тени изогнута по форме, а не проходит по контуру; падающая тень вытянута от лампы через предмет; тень касается предмета в точке опоры без зазора; при переносе лампы карта менялась логично; «могу пальцем показать, где стоит лампа, глядя только на карту»"
check: manual
```

```drill
type: free-form
prompt: "Шар под одним светом. 25 минут. Полный рендер по порядку: построение → заливка тени одним тоном → полутон → сгустить ядро за терминатором → падающая тень → рефлекс клячкой → блик. Ничего не размазывать пальцем."
answer: "Терминатор — полоса, изогнутая по форме; ядро тени темнее рефлекса; рефлекс темнее любого полутона на свету; самое тёмное место — контакт шара со столом; «блик поставлен последним и это единственное белое пятно на шаре»"
check: manual
```

```drill
type: free-form
prompt: "Куб тремя тонами. 20 минут. Постройте куб в двухточечной перспективе и залейте три видимые грани тремя разными ровными тонами (например ступени 2, 4, 7). Внутри грани градиента быть не должно."
answer: "Внутри каждой грани тон ровный; три тона явно различаются по ступеням; штрих у каждой грани своего направления; падающая тень построена как многоугольник, а не овал; «на изломе рёбер тон меняется скачком»"
check: manual
```

```drill
type: free-form
prompt: "Цилиндр. 20 минут. Кружка или банка без ручки. Штрих вертикальный, вдоль оси. Отдельно решить тон верхнего эллипса — это другая плоскость."
answer: "Тон меняется только по горизонтали, вдоль оси остаётся постоянным; верхний эллипс имеет собственный тон, отличный от боковой стенки; терминатор — вертикальная полоса; нарисована толщина стенки двумя эллипсами; «цилиндр выглядит трубой, а не подушкой»"
check: manual
```

```drill
type: free-form
prompt: "Четыре примитива на одном листе. 40 минут. Шар, куб, цилиндр, конус под одной лампой, стоящие на одном столе. Тени всех четырёх должны быть направлены согласованно."
answer: "Все падающие тени уходят в одну сторону и удлиняются одинаково; ни один предмет не светлее другого без причины; у конуса терминатор прямой, у шара — дуга; контактные тени — самые тёмные места листа; «прищурился: четыре объёма стоят на одном столе, а не висят»"
check: manual
```

## Собственный тон и наблюдение

```drill
type: free-form
prompt: "Светлое и тёмное вместе. 30 минут. Поставьте рядом белую чашку и тёмный предмет (кружка, книга, банка). Отрендерите оба, соблюдая правило: белое в тени темнее тёмного на свету."
answer: "Теневая сторона белой чашки темнее освещённой стороны тёмного предмета; белая чашка не оставлена бумажно-белой в тени; у обоих предметов есть все зоны света; диапазоны ступеней определены заранее и соблюдены; «прищурился — пятна выглядят как в натуре, а не как я знаю про цвет предметов»"
check: manual
```

```drill
type: free-form
prompt: "Диагноз по фото. 10 минут. Сфотографируйте свою последнюю тональную работу, обесцветьте, откройте рядом с фото натуры. Письменно назовите три конкретные тональные ошибки, используя термины модуля."
answer: "Названы ровно три ошибки; каждая сформулирована термином (терминатор, рефлекс, контактная тень, мутность, местный тон); для каждой записано конкретное действие на следующий раз; ни одна формулировка не звучит как «в целом не похоже»; «список лежит рядом при следующем рендере»"
check: manual
```

## Проверка понимания

```drill
type: multiple-choice
prompt: "Где на рисунке предмета, стоящего на столе, должно быть самое тёмное место?"
options: ["В сердцевине тени на самом предмете", "В контактной тени у точки касания со столом", "На дальнем краю падающей тени", "В рефлексе"]
answer: "В контактной тени у точки касания со столом"
check: exact
```

```drill
type: multiple-choice

answer: "Край предмета начнёт «светиться» и объём развалится"
check: exact
```


