## Слабые места

Прогнозируемые зоны риска для человека с Go+TS-фоном (проверить на практике, не
постулировать заранее):
- Реактивность как «магия»: забыть `.value` у `ref`, потерять реактивность при
  деструктуризации `reactive`-объекта.
- `ref` vs `reactive` — когда что; разворачивание `ref` в шаблоне.
- `watch` vs `watchEffect` vs `computed` — что выбрать.
- Мутация props (в Go передача по значению/указателю явная, тут — «не трогай чужое»).
- Декларативный рендер вместо императивного DOM — отпустить привычку «сделай X руками».
- Реактивность ≠ конкурентность: один UI-поток, никаких goroutines.
- `:key` в `v-for`; почему без него баги переиспользования DOM.
