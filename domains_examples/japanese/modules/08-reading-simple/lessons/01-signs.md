# Урок 01 — Вывески и указатели

Начнём с самого практичного — вывесок. Это короткий текст (часто один-два кандзи), с
которым сталкиваешься в реальной Японии: двери, станции, магазины, ценники. Задача урока
— узнавать типовые надписи мгновенно.

## Разогрев

Из теории: вывеска — это «команда или статус», читается за секунду, если знаешь набор.
Многие используют кандзи из модуля 07.

## Новая тема

### Двери и направления

`入口` (iriguchi — вход; `入` входить + `口` рот/отверстие), `出口` (deguchi — выход;
`出` выходить), `開` (открыто), `閉` (закрыто), `止まれ` (tomare — стоп).

### Места

`駅` (eki — станция), `お手洗い` / `トイレ` (туалет — кандзи-вежливо / катакана),
`病院` (byōin — больница), `銀行` (ginkō — банк). Многие узнаются по знакомым кандзи или
по катакане.

### Ценники и время

Число + `円` (en — иена): `四百円` (400 иен). Время: число + `時` (ji — час): `九時`
(9 часов). Все числа — из модуля 06.

## Разобранные примеры

1. `入口` → iriguchi → вход.
2. `出口` → deguchi → выход.
3. `駅` → eki → станция.
4. `三百円` → sanbyaku en → 300 иен.
5. `トイレ` → toire → туалет (катакана = заимствование).

```

```

## Итог

Вывески — короткие надписи: двери (`入口`/`出口`, `開`/`閉`), места (`駅`, `トイレ`,
`病院`), ценники (число + `円`), время (число + `時`). Узнаются по кандзи из модуля 07 и
по катакане. Следующий урок — приветствия и ходовые фразы.
