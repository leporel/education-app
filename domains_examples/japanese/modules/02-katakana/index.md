# Модуль 02 — Катакана

## Цель

Вторая азбука японского. Та же звуковая система, что у хираганы, но другие формы и другая
работа. После модуля ты:

1. Понимаешь, **зачем** нужна катакана (заимствования, имена, звукоподражания, акцент).
2. Читаешь все 46 знаков катаканы + дакутэн/хандакутэн + ёон.
3. Различаешь коварные похожие пары (ソ/ン, シ/ツ, ク/ワ, ロ/ニ…).
4. Читаешь японские записи заимствованных слов (`コーヒー`, `テレビ`, имена).
5. Читаешь расширенную катакану для чужих звуков: `ファ`, `ティ`, `シェ`, `ウィ`, `ヴ`.
6. Узнаёшь вывески и меню современного города, которые почти целиком записаны катаканой.

## Предпосылки

Модуль [`01-hiragana`](../01-hiragana/index.md). Катакана покрывает те же слоги, так что
знание хираганы — половина дела (надо выучить только новые формы).
