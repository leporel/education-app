# Упражнения

Определение и сказуемое, спряжение обоих типов. Следи: い-тип цепляется напрямую,
な-тип — через な.

## Блок 1. Перед существительным

```drill
type: translate
prompt: "Собери: большой дом (おおきい — большой, いえ — дом)"
answer: おおきい いえ | おおきいいえ
check: fuzzy
```

```drill
type: fill-in
prompt: "しずか___ へや (тихая комната — добавь частицу)"
answer: な
check: exact
hint: な-прилагательное → な
```

```drill
type: multiple-choice
prompt: "«красивый цветок» (きれい — красивый, はな — цветок):"
options: [きれい はな, きれいい はな, きれいな はな, きれいの はな]
answer: きれいな はな
check: exact
hint: きれい — な-тип!
```

```drill
type: multiple-choice
prompt: "Где ошибка?"
options: [おおきい いえ, おいしい コーヒー, しずかな へや, おおきいな いえ]
answer: おおきいな いえ
check: exact
hint: い-прилагательному な не нужно
```

```drill

```

```drill
type: fill-in

```

```drill
type: multiple-choice
prompt: "«Дом был большим» — как правильно?"
options: [いえは おおきいでした, いえは おおきかったです, いえは おおきくでした, いえは おおきいました]
answer: いえは おおきかったです
check: exact
hint: "い-тип: прошлое в самом слове (~かった), не через です"
```

```drill
type: fill-in
prompt: "«не тихий» от しずか: ___"
answer: しずかでは ありません
check: fuzzy
hint: な-тип спрягается через です как существительное
```

```drill
type: free-form
prompt: "Объясни, почему «おおきいでした» неправильно, а «しずかでした» правильно."
answer: "おおきい — い-прилагательное, у него прошлое в самом слове: おおきかった(です), а не через でした. しずか — な-прилагательное, склоняется как существительное через связку, поэтому でした правильно."
check: manual
```

## Блок 4. Свободное

```drill

answer: "Например: この コーヒーは おいしいです。(い-тип) / この まちは しずかです。(な-тип). Проверь: い-тип — слово+です напрямую; な-тип — слово+です как существительное."
check: manual
```

## Блок 7. Склейка описаний

```drill
type: fill-in
prompt: "やすい + おいしい (дёшево и вкусно): やす___ おいしいです。"
answer: くて
check: fuzzy
```

```drill
type: fill-in
prompt: "しずか + きれい (тихо и красиво): しずか___ きれいです。"
answer: で
check: fuzzy
```

```drill
type: free-form
prompt: "Опиши знакомое кафе тремя фразами: какое оно (два прилагательных через 〜くて или で), сравни с другим (より), и назови самое-самое (いちばん)."
answer: "Например: この みせは やすくて おいしいです。あの みせより やすいです。ここが いちばん すきです。 (проверь: 〜くて/で для склейки, より после того, с чем сравниваем, いちばん перед прилагательным)"
check: manual
```
