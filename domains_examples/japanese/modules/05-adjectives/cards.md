# Карточки

Два типа прилагательных, их спряжение и лексика. Слова — кана + ромадзи-подсказка.

## Принцип (два типа)

```card
front: い-прилагательное vs な-прилагательное — суть?
back: い-тип спрягается сам (как глагол), цепляется к сущ. напрямую; な-тип ведёт себя как существительное, цепляется через な, склоняется через です
tags: [principle]
```

```card
front: Как い-прилагательное цепляется к существительному?
back: "напрямую: おおきい いえ (большой дом)"
tags: [i-adj]
```

```card
front: Как な-прилагательное цепляется к существительному?
back: "через な: しずかな へや (тихая комната)"
tags: [na-adj]
```

```card
front: "Ловушка: きれい и ゆうめい — какой тип?"
back: "な-прилагательные! (кончаются на い, но это исключения: きれいな, ゆうめいな)"
tags: [trap]
```

## い-прилагательные (слова)

```card
front: おおきい / ちいさい
back: ōkii — большой / chiisai — маленький
tags: [i-adj]
```

```card
front: たかい / やすい
back: takai — высокий/дорогой / yasui — дешёвый
tags: [i-adj]
```

```card
front: おいしい
back: oishii — вкусный
tags: [i-adj]
```

```card
front: あつい / さむい
back: atsui — жаркий / samui — холодный (о погоде)
tags: [i-adj]
```

```card
front: あたらしい / ふるい
back: atarashii — новый / furui — старый
tags: [i-adj]
```

```card
front: いい
back: "ii — хороший (спрягается от よい: よくない, よかった)"
tags: [i-adj, irregular]
```

## Спряжение

```card
front: "い-прилагательное: 4 формы (おおきい)"
back: おおきい (есть), おおきくない (не), おおきかった (был), おおきくなかった (не был) + です для вежливости
tags: [i-adj, conjugation]
```

```card
front: い-прилагательное в прошлом — как? (НЕ через です!)
back: "~かった: おおきかった (был большим). ❌ おおきいでした → ✅ おおきかったです"
tags: [i-adj, conjugation]
```

```card
front: "な-прилагательное: 4 формы (しずか)"
back: しずかです (есть), しずかでは ありません (не), しずかでした (был), しずかでは ありませんでした (не был) — как существительное
tags: [na-adj, conjugation]
```

```card
front: "\"Этот дом большой.\" — собрать (この — этот)"
back: この いえは おおきいです。
tags: [sentence]
```

```card
front: "\"Эта комната тихая.\" — собрать"
back: この へやは しずかです。
tags: [sentence]
```

## Наречия

```card
front: Как из い-прилагательного сделать наречие?
back: "い → く: はやい (быстрый) → はやく (быстро), おおきい → おおきく"
tags: [adverb]
```

```card
front: Как из な-прилагательного сделать наречие?
back: "+ に: しずか → しずかに (тихо), きれい → きれいに"
tags: [adverb]
```

```card
front: "\"Ведите себя тихо.\" — готовая фраза"
back: しずかに してください。
tags: [adverb, phrase]
```

## Усилители

```card
front: とても / すこし / ちょっと
back: очень / немного / чуть-чуть — とても おいしいです (очень вкусно)
tags: [degree]
```

```card
front: あまり — как употребляется?
back: "«не очень», ТОЛЬКО с отрицанием: あまり おいしくないです。 ❌ あまり おいしいです"
tags: [degree, trap]
```

```card
front: ぜんぜん — как употребляется?
back: "«совсем не», тоже требует отрицания: ぜんぜん わかりません。"
tags: [degree, trap]
```

```card
front: Что значит одинокое «ちょっと…» в ответ на предложение?
back: вежливый отказ («ну, это как-то…»). Не переспрашивай — это «нет»
tags: [degree, phrase]
```

## Сравнение

```card
front: «Поезд быстрее автобуса» — собрать
back: でんしゃは バスより はやいです。 (より — «чем», ставится после того, с чем сравниваем)
tags: [comparison]
```

```card
front: Меняется ли само прилагательное при сравнении?
back: "нет! Никаких «-ее». Работают служебные слова: より (чем), のほうが (скорее уж), いちばん (самый)"
tags: [comparison]
```

```card
front: Как сказать «самый»?
back: "いちばん перед прилагательным: これが いちばん やすいです。 (это самое дешёвое)"
tags: [comparison]
```

```card
front: «Что быстрее — поезд или автобус?» — собрать
back: でんしゃと バスと、どちらが はやいですか。 (どちら — который из двух)
tags: [comparison, question]
```

## Склейка описаний

```card
front: Как соединить два い-прилагательных?
back: "через 〜くて: やすくて おいしいです。 (дёшево и вкусно)"
tags: [connect]
```

```card
front: Как соединить два な-прилагательных?
back: "через で: しずかで きれいです。 (тихо и красиво)"
tags: [connect]
```

```card
front: そして / でも
back: «и, а также» / «но, однако» — соединяют предложения, а не слова
tags: [connect]
```
