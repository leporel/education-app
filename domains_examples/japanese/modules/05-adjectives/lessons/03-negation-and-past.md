# Урок 03 — Отрицание и прошлое прилагательных

Оба типа есть — теперь спряжение: «не такой» и «был таким». Тут типы расходятся сильнее
всего, и это главный источник ошибок. Задача урока — крутить все формы без путаницы.

## Разогрев

- `い`-тип — самодостаточный (спрягается сам).
- `な`-тип — как существительное (спрягается через связку `です`).
Это различие и определяет всё ниже.

## Новая тема

### い-прилагательные: спрягаем сам корень

Отбрасываем `い`, приклеиваем хвост (как у глаголов):

| | хвост | пример (おおきい) |
|---|------|------------------|
| есть | `~い` | `おおきい` |
| не | `~くない` | `おおきくない` — не большой |
| был | `~かった` | `おおきかった` — был большим |
| не был | `~くなかった` | `おおきくなかった` |

+ `です` для вежливости: `おおきくないです`, `おおきかったです`.

⚠️ Прошлое — в самом слове, **не через です**: ❌ `おおきいでした` → ✅ `おおきかったです`.
Особый случай: `いい` (хороший) спрягается от `よい`: `よくない`, `よかった`.

### な-прилагательные: спрягаем связку

Само слово не меняется — меняется `です`, ровно как у существительных (модуль 03):

| | форма | пример (しずか) |
|---|------|----------------|
| есть | `です` | `しずかです` |
| не | `では ありません` | `しずかでは ありません` |
| был | `でした` | `しずかでした` |
| не был | `では ありませんでした` | `しずかでは ありませんでした` |

## Разобранные примеры

1. «Дом не большой.» → `いえは おおきくないです。`
2. «Кофе был вкусным.» → `コーヒーは おいしかったです。`
3. «Комната не тихая.» → `へやは しずかでは ありません。`
4. «Город был знаменитым.» → `まちは ゆうめいでした。`
5. «Погода была не жаркой.» → `てんきは あつくなかったです。` (tenki — погода)

## Итог

`い`-тип спрягает **сам корень** (`おおきくない`, `おおきかった`) — прошлое в слове, не
через です. `な`-тип спрягает **связку です** как существительное (`しずかでは ありません`,
`しずかでした`). Не путать: `おおきいでした` ❌ — классическая ошибка. Это закрывает
прилагательные. Дальше — модуль `06`: первые кандзи (иероглифы).
