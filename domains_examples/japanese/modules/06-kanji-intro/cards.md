# Карточки

Понятие кандзи + числа 一〜十, 百, 千. Для чисел на лице — кандзи, на обороте — чтение
и значение.

## Понятия

```card
front: Чем кандзи отличается от каны?
back: кана записывает звук (слог), кандзи — смысл (значение/корень слова)
tags: [concept]
```

```card
front: Что такое онъёми и кунъёми?
back: он — «китайское» чтение (в составных словах, кандзи+кандзи); кун — «японское» (одиночное слово, часто + окуригана)
tags: [concept]
```

```card
front: Что такое окуригана?
back: "кана-хвост после кандзи-корня, который спрягается: 食べる = 食 (корень) + べる (окуригана)"
tags: [concept]
```

```card
front: Зачем кандзи, если есть кана? (3 причины)
back: "1) режут текст на слова (пробелов нет); 2) различают омофоны (はし: 橋 мост / 箸 палочки); 3) сжимают смысл (один знак = корень)"
tags: [concept]
```

## Большие числа и счёт

```card
front: 百 / 千
back: hyaku — 100 / sen — 1000
tags: [number]
```

```card
front: Как сказать 11, 12, 20, 21 кандзи?
back: 11 = 十一 (jū-ichi), 12 = 十二, 20 = 二十 (ni-jū), 21 = 二十一 (ni-jū-ichi)
tags: [number]
```

```card
front: 100 и 300 — 百 / 三百, но осторожно с чтением?
back: 100 = 百 (hyaku), 300 = 三百 (sanbyaku — звук меняется!), 600 = 六百 (roppyaku), 800 = 八百 (happyaku)
tags: [number]
```

```card
front: "Прочитай: 二千二十六"
back: ni-sen ni-jū-roku = 2026
tags: [number]
```

```card
front: 山 — чтения?
back: "кун やま (yama, гора сама по себе) / он サン (san, в составных: 火山 kazan вулкан)"
tags: [example]
```

## Ноль, чтения каной и счётные суффиксы

```card
front: Как записывают и говорят «ноль»?
back: 〇 / 零 (rei), но в быту чаще всего катаканой ゼロ (в номерах ещё まる)
tags: [numbers]
```

```card
front: "Чтения каной: 四 / 七 / 九"
back: よん (или し) / なな (или しち) / きゅう (или く) — в быту предпочитают よん, なな, きゅう
tags: [numbers]
```

```card
front: Что такое счётный суффикс?
back: "хвост после числа, сообщающий, ЧТО считают: 〜円 (иены), 〜時 (часы), 〜分 (минуты), 〜人 (людей), 〜つ (штук)"
tags: [counter]
```

```card
front: «Три человека» и особые случаи 1 и 2 человека?
back: 三人 (sannin); но 一人 hitori (один человек) и 二人 futari (двое) — особые чтения
tags: [counter, trap]
```

```card
front: 三百 / 六百 / 八百 — чтения?
back: sanbyaku / roppyaku / happyaku — фонетические исключения, запомнить
tags: [numbers, trap]
```

## Термины про кандзи

```card
front: Онъёми и кунъёми — простыми словами?
back: он — «китайское» чтение, работает в составных словах (大学 dai-gaku); кун — «японское», когда кандзи стоит один (山 やま)
tags: [term]
```

```card
front: Что такое окуригана?
back: "кана-хвост после кандзи, который спрягается: 食べる = 食 + べる, 食べました — 食 не меняется"
tags: [term]
```

```card
front: Что такое фуригана?
back: мелкая кана НАД кандзи с подсказкой чтения. В учебных текстах — законная опора, не жульничество
tags: [term]
```

```card
front: Что такое радикал?
back: «кирпичик» в составе сложного кандзи (木 в 林 и 森). По радикалам ищут знаки в словаре
tags: [term]
```

```card
front: Сколько кандзи нужно знать?
back: официальный список дзёё — 2136, но первые ~100 (числа, дни, люди, направления) уже дают вывески и заголовки, а ~300 — большую часть простого текста
tags: [term]
```

```card
front: Как найти незнакомый кандзи?
back: вставить текст на jisho.org; нарисовать знак рукописным вводом; искать по радикалу. Камера-переводчик годится «понять», но не «выучить»
tags: [term, strategy]
```
