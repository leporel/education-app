# Упражнения

Чтение кандзи, дней недели, составных слов, смешанного текста.

## Блок 1. Дни недели и природа

```drill
type: multiple-choice
prompt: "Какой кандзи означает «вода»?"
options: [火, 水, 木, 金]
answer: 水
check: exact
```

```drill
type: translate
prompt: "Какой день недели: 月曜日?"
answer: понедельник | getsuyōbi
check: fuzzy
```

```drill
type: multiple-choice
prompt: "金曜日 — это:"
options: [среда, четверг, пятница, суббота]
answer: пятница
check: exact
```

```drill
type: translate
prompt: "Прочитай слово: 火山 (огонь + гора)"
answer: kazan — вулкан
check: fuzzy
```

## Блок 3. Похожие кандзи

```drill
type: multiple-choice
prompt: "Где «книга» (а не «дерево»)?"
options: [木, 本, 体, 休]
answer: 本
check: exact
hint: у 本 лишняя чёрточка снизу
```

```drill
type: free-form
prompt: "Чем отличаются 人 и 入?"
answer: 人 — человек (два штриха расходятся вниз симметрично); 入 — входить (правый штрих заходит выше левого). Похожи, но это разные кандзи.
check: manual
```

## Блок 4. Чтение в тексте

```drill
type: translate
prompt: "Прочитай: 日本人 (солнце+основа+человек)"
answer: Nihonjin — японец
check: fuzzy
```

```drill
type: free-form
prompt: "Прочитай и переведи: 私は日本の大学の学生です。 (学生 — студент)"
answer: "watashi-wa Nihon-no daigaku-no gakusei desu — «Я студент японского университета». (кандзи: 私 я, 日本 Япония, 大学 университет, 学生 студент; кана: は, の, です)"
check: manual
```

```drill
type: free-form
prompt: "Прочитай дату/день: 土曜日に大きい本を読みます。 (読みます yomimasu — читать)"
answer: doyōbi-ni ōkii hon-o yomimasu — «В субботу читаю большую книгу». (土曜日 суббота, 大きい большой, 本 книга)
check: manual
```

## Блок 5. Группа 3: учёба, страна, время

```drill
type: translate
prompt: "Что значит 学校?"
answer: gakkō — школа
check: fuzzy
hint: учёба + здание
```

```drill
type: multiple-choice
prompt: "今日 — как читается и что значит?"
options: [ima-hi, сегодня (kyō), этот год, сейчас]
answer: сегодня (kyō)
check: exact
hint: особое чтение, запоминается как слово
```

```drill
type: translate
prompt: "Что значит 中国 и из чего собрано?"
answer: Chūgoku — Китай; середина + страна («срединная страна»)
check: fuzzy
```

```drill
type: multiple-choice
prompt: "Какой кандзи стоит в корне глагола 行きます?"
options: [今, 行, 時, 校]
answer: 行
check: exact
hint: корень кандзи + окуригана きます
```

```drill
type: free-form
prompt: "Разбери 私は 七時に 学校に 行きます по кандзи: что означает каждый?"
answer: "私 — я, 七 — семь, 時 — час, 学 — учёба, 校 — здание школы, 行 — идти. Кана (は, に, きます) — грамматика. Смысл: «Я в 7 часов иду в школу»."
check: manual
```

```drill
type: multiple-choice
prompt: "Что общего у 分 в 十分 и в 分かります?"
options: [ничего, один и тот же кандзи «делить»: минута — часть часа, «понять» — разложить по полочкам, случайное совпадение начертания, это разные знаки]
answer: "один и тот же кандзи «делить»: минута — часть часа, «понять» — разложить по полочкам"
check: exact
```


```drill
type: multiple-choice
prompt: "Где «человек», а не «входить»?"
options: [入, 人, 八, 大]
answer: 人
check: exact
```

```drill
type: free-form
prompt: "Назови три пары похожих кандзи и объясни, чем они различаются."
answer: 木/本 (у 本 лишняя нижняя черта), 日/目 (у 目 внутри две черты), 人/入 (разное положение верхней черты), 土/士 (у 土 длиннее нижняя черта).
check: manual
```
