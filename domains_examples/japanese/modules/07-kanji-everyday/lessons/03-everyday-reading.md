# Урок 03 — Чтение в реальном тексте

Кандзи выучены — применим их к чтению настоящих предложений со смешанным письмом. Задача
урока — собрать кандзи из модулей 06–07 в навык чтения и угадывания составных слов.

## Разогрев

В арсенале: числа (`一〜十`, `百`, `千`), стихии/дни (`日月火水木金土`), люди/размеры
(`人大小上下中本`). Этого хватает на много бытовых фраз.

## Новая тема

### Угадывание составных слов

Зная корни, угадывай новые слова по смыслу частей:
- `小学校` = маленький + учёба + школа = **начальная школа**.
- `中学` = середина + учёба = **средняя школа**.
- `大学生` = университет + студент = **студент университета**.
- `三人` = три + человек = **три человека** (sannin).
Это и есть «суперсила» кандзи: новое слово часто читается без словаря, если знаешь его
кирпичики.

### Чтение смешанного текста

Глаз ловит кандзи (смысл), кана достраивает грамматику:

> `日本人は土曜日に大きい本を読みます。`
> Nihonjin-wa doyōbi-ni ōkii hon-o yomimasu — «Японцы по субботам читают большие книги.»
> Кандзи: `日本人`(японец) `土曜日`(суббота) `大きい`(большой) `本`(книга) `読`(читать).
> Кана: は, に, を, みます — грамматика.

Стратегия: сначала пройдись по кандзи (схвати смысл-каркас), потом кана свяжет.

## Разобранные примеры

1. `小学校` → shōgakkō → начальная школа.
2. `大学生` → daigakusei → студент университета.
3. `三人の人` → sannin-no hito → «три человека».
4. `水曜日に学校に行きます` → suiyōbi-ni gakkō-ni ikimasu → «в среду иду в школу».
5. `日本の大学` → Nihon-no daigaku → «японский университет».

## Итог

Зная корни-кандзи, ты угадываешь составные слова (`小学校`, `大学生`, `中学`) и читаешь
смешанный текст, ловя смысл по кандзи и связывая каной. Это последний кирпич перед
финалом: у тебя есть кана, грамматика и стартовый набор кандзи. Дальше — модуль `08`:
стратегии чтения простых текстов целиком.
