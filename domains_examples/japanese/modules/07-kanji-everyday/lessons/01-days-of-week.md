# Урок 01 — Дни недели и стихии

Лучший «пакет» кандзи на старте — семь стихий, которые одновременно дни недели. Задача
урока — выучить `日 月 火 水 木 金 土` и собирать из них дни недели и слова природы.

## Разогрев

Из модуля 06: кандзи = смысл, у него есть он/кун, чтение зависит от слова. Эти семь —
очень частотные, встречаются в календарях, расписаниях, заголовках.

## Новая тема

### Семь кандзи

| `日` день/солнце | `月` луна/месяц | `火` огонь | `水` вода |
| `木` дерево | `金` золото/деньги | `土` земля | |

Японская неделя названа по стихиям-светилам (как у нас Sun-day, Mo(o)n-day).

### Дни недели = стихия + 曜日

`曜日` (yōbi) — «день недели». Приставляешь стихию:
- `月曜日` getsuyōbi — понедельник (луна)
- `火曜日` kayōbi — вторник (огонь)
- `水曜日` suiyōbi — среда (вода)
- `木曜日` mokuyōbi — четверг (дерево)
- `金曜日` kin'yōbi — пятница (золото)
- `土曜日` doyōbi — суббота (земля)
- `日曜日` nichiyōbi — воскресенье (солнце)

### Те же кандзи в других словах

`日本` (Nihon — Япония, «корень солнца»), `火山` (kazan — вулкан), `水` (mizu — вода),
`お金` (okane — деньги). Один кирпичик — много слов.

## Разобранные примеры

1. `水曜日` → suiyōbi → среда.
2. `日本` → Nihon → Япония.
3. `火` → hi/ka → огонь.
4. `金曜日` → kin'yōbi → пятница.
5. `土曜日に行きます` → doyōbi-ni ikimasu → «пойду в субботу».

## Mini-drill

```drill
type: translate
prompt: "Какой день: 火曜日?"
answer: вторник | kayōbi
check: fuzzy
```

```drill
type: multiple-choice
prompt: "Кандзи «дерево»:"
options: [水, 木, 本, 土]
answer: 木
check: exact
```

```drill

```

```drill
type: multiple-choice

```

```drill
type: free-form
prompt: "Соедини стихию и день: какой день «水曜日» и почему так называется?"

check: manual
```

## Итог

Семь кандзи `日 月 火 水 木 金 土` — это и стихии, и дни недели (стихия + `曜日`:
`月曜日` пн … `日曜日` вс). Те же кандзи дают `日本`, `火山`, `お金`. Следующий урок —
кандзи людей, размеров и положения.
