# Урок 02 — Люди, размеры, положение

Второй пакет — семь кандзи про «кто и какой»: `人 大 小 上 下 中 本`. Они частотны и
многие уже знакомы тебе по словам из прошлых модулей. Задача урока — выучить их и видеть
в составных словах.

## Разогрев

Вспомни из модуля 05: `大きい` (большой), `小さい` (маленький); из модуля 04: `上`/`下`
(верх/низ). Сейчас узнаешь их кандзи-корни.

## Новая тема

### Семь кандзи

| `人` человек | `大` большой | `小` маленький | `上` верх |
| `下` низ | `中` середина/внутри | `本` книга/основа | |

Связь со знакомым: `大きい` (ōkii) — это `大` + окуригана `きい`; `小さい` (chiisai) —
`小` + `さい`. Корни прилагательных теперь записаны кандзи.

### В составных словах

- `日本人` = Япония + человек = японец.
- `大学` = большой + учёба = университет; `大人` = большой + человек = взрослый (otona —
  особое чтение!).
- `中国` = середина + страна = Китай; `中学` = средняя школа.
- `一人` = один + человек = один человек (hitori — особое чтение).

### Оны и куны видно наглядно

- в составе → он: `大学` (dai-gaku), `日本人` (…jin).
- одиночно/с окуриганой → кун: `人` (hito), `大きい` (ōkii), `中` (naka).

## Разобранные примеры

1. `人` → hito/jin → человек.
2. `大学` → daigaku → университет.
3. `中` → naka → середина/внутри.
4. `日本人` → Nihonjin → японец.
5. `大人` → otona → взрослый (особое чтение, запомнить).

## Mini-drill

```drill
type: multiple-choice
prompt: "Кандзи «человек»:"
options: [入, 人, 大, 八]
answer: 人
check: exact
```

```drill
type: translate
prompt: "Прочитай: 大学"
answer: daigaku — университет
check: fuzzy
```

```drill
type: translate
prompt: "Прочитай: 中国"
answer: Chūgoku — Китай
check: fuzzy
```

```drill
type: multiple-choice
prompt: "Где «книга» (а не «дерево»)?"
options: [木, 本, 大, 中]
answer: 本
check: exact
```

```drill
type: free-form
prompt: "Разложи 日本人 на кандзи со смыслами."
answer: 日 (солнце/день) + 本 (основа/корень) = 日本 (Япония, «корень солнца») + 人 (человек) = 日本人 «японец».
check: manual
```

## Итог

Семь кандзи `人 大 小 上 下 中 本` — про людей, размеры и положение; многие уже знакомы
по словам (`大きい`, `小さい`, `上/下`). В составе дают `日本人`, `大学`, `中国`. Помни
особые чтения `大人` (otona), `一人` (hitori). Следующий урок — собираем кандзи в чтение
реального смешанного текста.
