# Карточки

Узнавание каны: на лицевой стороне — знак, на обороте — чтение (ромадзи как подсказка
произношения). Гонять через SRS по рядам; отдельный блок — на похожие пары и первые
слова. Цель — узнавать знак мгновенно, без проговаривания «к плюс а».

## Похожие пары (ловушки)

```card
front: Чем あ отличается от お?
back: у お есть дополнительный крючок-петля справа сверху, у あ его нет
tags: [pairs]
```

```card
front: Чем い отличается от り?
back: い — две раздельные чёрточки; り — соединённые, со «спинкой» справа
tags: [pairs]
```

```card
front: Чем さ отличается от ち?
back: さ смотрит «крючком» влево-вверх; ち — зеркально, крючок вправо-вниз
tags: [pairs]
```

```card
front: Чем は отличается от ほ?
back: у ほ сверху лишняя горизонтальная чёрточка (как «крыша»), у は её нет
tags: [pairs]
```

```card
front: Различи ね / れ / わ
back: ね — с петлёй-хвостиком справа; れ — с прямым хвостом; わ — закруглённая без петли
tags: [pairs]
```

## Сокуон: маленькая っ

```card
front: Маленькая っ — что делает?
back: "удваивает следующий согласный, вставляя паузу-затор длиной в такт: がっこう = «гак-ко:» (школа)"
tags: [sokuon]
```

```card
front: つ vs っ — в чём разница?
back: большая つ — слог «цу»; маленькая っ — сокуон, пауза-удвоение. Размер решает всё
tags: [sokuon]
```

```card
front: おと и おっと — одно слово или два?
back: "два разных: おと = звук, おっと = муж. Пауза смыслоразличительна"
tags: [sokuon]
```

```card
front: がっこう
back: gakkō — школа
tags: [word, sokuon]
```

```card
front: きって
back: kitte — почтовая марка
tags: [word, sokuon]
```

```card
front: ちょっと
back: chotto — немного, чуть-чуть (одно из самых частых слов)
tags: [word, sokuon, yoon]
```

## Долгие гласные

```card
front: Как в хирагане записывается долгий гласный?
back: "добавлением гласного знака: おかあさん (а:), おにいさん (и:), くうき (у:)"
tags: [long-vowel]
```

```card
front: Чем обычно тянут долгое «э» и долгое «о»?
back: "через い и う: せんせい читается «сэнсэ:», ありがとう — «арига-то:». Исключения: おおきい, とおい"
tags: [long-vowel]
```

```card
front: おじさん vs おじいさん
back: дядя vs дедушка — разница только в долготе, но это разные слова
tags: [long-vowel, trap]
```

```card
front: とうきょう
back: Tōkyō — Токио (ёон きょ + долгота через う, дважды)
tags: [word, long-vowel]
```

```card
front: ありがとう
back: arigatō — спасибо (читается «арига-то:», う тянет о)
tags: [word, long-vowel]
```

## Как это звучит

```card
front: Почему です звучит как «дэс»?
back: "у и и между глухими согласными и в конце слова проглатываются: です → «дэс», ます → «мас», すき → «ски»"
tags: [pronunciation]
```

```card
front: Как звучит ん перед b/p/m?
back: "как «м»: こんばんは → «комбанва». Пишется всегда ん, а звучит по соседу"
tags: [pronunciation]
```

```card
front: Как произносится ряд ら?
back: один быстрый удар языка о нёбо, среднее между русскими «р» и «л». Не раскатывать
tags: [pronunciation]
```

```card
front: Есть ли в японском ударение?
back: силового ударения нет — есть тональный рисунок (высоко/низко). はし может быть «палочки» или «мост» в зависимости от тона
tags: [pronunciation]
```

## Знаки препинания и термины

```card
front: Японские точка, запятая и кавычки?
back: 。 (точка-кружок), 、 (наклонная запятая), 「 」 (кавычки-уголки)
tags: [punctuation]
```

```card
front: Что такое годзюон?
back: 五十音 «пятьдесят звуков» — таблица 5 гласных × ряды согласных; стандартный порядок сортировки в японском
tags: [term]
```

```card
front: Что такое мора?
back: "«такт» японского ритма: один знак каны = один такт. Долгий гласный и пауза っ — это отдельные такты"
tags: [term]
```

```card
front: Что такое ромадзи и зачем оно тут?
back: запись японского латиницей. В этом курсе — костыль только на первое знакомство со знаком; дальше читаем кану
tags: [term]
```
