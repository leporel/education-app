# Урок 03 — Озвончение, ёон и чтение слов

Базовые знаки уже читаются — пора добрать два «множителя», которые из тех же знаков
дают вдвое больше звуков: **дакутэн** (озвончение) и **ёон** (слияние с маленькими
ゃゅょ). И, главное, потренироваться читать настоящие слова.

## Разогрев

Прочитай по памяти, закрыв подсказки:
- гласные: `あ い う え お`
- ряд k: `か き く け こ`
- ряд s: `さ し す せ そ` (помнишь, что `し` = shi?)

Если идёт бегло — отлично, сегодня надстраиваем над этим.

## Новая тема

### 1. Дакутэн (゛) — «ручка громкости»

Хорошая новость: новых форм учить **не надо**. Берёшь знакомый знак и ставишь две
чёрточки `゛` в правом верхнем углу — согласный становится звонким:

- ряд **k → g**: `か ka → が ga`, `き ki → ぎ gi`, `く → ぐ gu` …
- ряд **s → z**: `さ sa → ざ za`, `す → ず zu`, **`し shi → じ ji`** (выбивается в «ji»)
- ряд **t → d**: `た ta → だ da`, `て → で de`, `と → ど do`
- ряд **h → b**: `は ha → ば ba`, `ほ → ぼ bo`

Думай о дакутэн как о флаге-модификаторе: тот же символ, включён «звонкий режим».

### 2. Хандакутэн (゜) — только для ряда は

Маленький кружок `゜` вместо чёрточек — и **только** на ряду `は` — даёт звук `p`:

- `は ha → ぱ pa`, `ひ → ぴ pi`, `ふ → ぷ pu`, `へ → ぺ pe`, `ほ → ぽ po`

Больше нигде хандакутэн не ставится — это эксклюзив ряда は.

### 3. Сокуон — маленькая `っ` (пауза-удвоение)

Ещё один «мелкий» знак с большими последствиями. Маленькая `っ` не читается как «цу» —
она **удваивает следующий согласный**, вставляя короткую паузу:

- `がっこう` → *gakkō* → «школа» («гак-ко:»)
- `きって` → *kitte* → «марка»
- `ちょっと` → *chotto* → «немного» (одно из самых ходовых слов языка)

Пауза занимает целый такт, и её нельзя проглотить: `おと` (звук) ≠ `おっと` (муж),
`かた` (плечо) ≠ `かった` (купил). И, как с `ゃ`, всё решает размер: большая `つ` — это
слог «цу», маленькая `っ` — пауза.

### 4. Ёон — маленькие ゃ ゅ ょ

Если после знака на `-i` (`き し ち に ひ み り ぎ じ…`) поставить **маленькие** `ゃ ゅ
ょ`, два знака сливаются в **один** слог:

- `き + ゃ → きゃ kya`
- `し + ゅ → しゅ shu`
- `ち + ょ → ちょ cho`

Размер решает всё: большой `や` — отдельный слог («ки-я»), маленький `ゃ` — слияние
(«кя»). `きや` ≠ `きゃ`. Так появляются звуки вроде «Токио» → `とうきょう`.

## Разобранные примеры

Читаем настоящие слова, **глядя на кану** (ромадзи — только для самопроверки):

- `かぎ` → *kagi* → «ключ» (`か` + озвончённая `ぎ`).
- `みず` → *mizu* → «вода» (`み` + `ず` = zu).
- `だいがく` → *daigaku* → «университет» (`だ・い・が・く` — два озвончения подряд).
- `でんわ` → *denwa* → «телефон» (`で・ん・わ`; здесь `ん` = одинокий «n»).
- `がっこう` → *gakkō* → «школа» (маленькая `っ` удваивает согласный — «гак-ко:»;
  подробный разбор сокуона — в [`theory.md`](../theory.md), раздел «Сокуон»).
- `きょう` → *kyō* → «сегодня» (ёон `きょ` + `う` тянет «о:»).

Разбор `だいがく` по слогам: `だ`(da) → `い`(i) → `が`(ga) → `く`(ku) = da-i-ga-ku. Два
дакутэна, но читается по тому же принципу «знак за знаком».

## Итог

Дакутэн `゛` озвончает согласный (k→g, s→z, t→d, h→b) — новых форм учить не нужно, это
«режим звонкости» поверх знакомого знака. Маленькая `っ` (сокуон) даёт паузу-удвоение
(`がっこう`) и различает слова (`かた` ≠ `かった`). Хандакутэн `゜` даёт `p` и живёт только на ряду
`は`. Ёон — маленькие `ゃ ゅ ょ` сливают два знака в один слог (`きゃ` = kya), и размер
знака критичен. С этими множителями ты покрываешь почти всю фонетику японского и читаешь
настоящие слова. Дальше — добить остальные ряды таблицы по карточкам, а затем модуль
`02-katakana`.
