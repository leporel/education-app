# Упражнения

Спряжение `-ます` и выбор частиц. Глагол — в конец.

## Блок 1. Спряжение -ます

```drill
type: fill-in
prompt: "Отрицание от のみます (не пью): ___"
answer: のみません
check: fuzzy
```

```drill
type: fill-in
prompt: "Прошлое от たべます (ел): ___"
answer: たべました
check: fuzzy
```

```drill
type: fill-in
prompt: "Отрицательное прошлое от いきます (не ходил): ___"
answer: いきませんでした
check: fuzzy
```

```drill
type: multiple-choice
prompt: "のみます означает:"
options: [только «пью», только «буду пить», и «пью», и «буду пить», «пил»]
answer: и «пью», и «буду пить»
check: exact
```

## Блок 3. に / で / へ

```drill
type: fill-in
prompt: "がっこう___ いきます。 (направление в школу)"
answer: に
check: fuzzy
hint: направление → に (или へ)
```

```drill
type: fill-in
prompt: "としょかん___ ほんを よみます。 (в библиотеке читаю — место действия)"
answer: で
check: exact
hint: арена действия → で
```

```drill
type: fill-in
prompt: "でんしゃ___ いきます。 (еду поездом — средство)"
answer: で
check: exact
hint: средство → で
```

```drill
type: multiple-choice
prompt: "Где правильно «в школе учусь»?"
options: [がっこうに べんきょうします, がっこうで べんきょうします, がっこうを べんきょうします, がっこうへ べんきょうします]
answer: がっこうで べんきょうします
check: exact
hint: там идёт действие → で
```

```drill
type: free-form
prompt: "Объясни разницу: «がっこうに いきます» и «がっこうで べんきょうします»."
answer: に — направление (иду В школу, движение к точке); で — место действия (В школе учусь, там происходит действие). Глагол движения → に; глагол действия на месте → で.
check: manual
```

## Блок 4. Полная фраза

```drill

answer: わたしは まいにち としょかんで ほんを よみます。 | まいにち としょかんで ほんを よみます
check: fuzzy
```

```drill
type: free-form
prompt: "Составь своё предложение по шаблону [время]に [место]で [объект]を [глагол-ます] о своём дне."
answer: "Например: しちじに うちで コーヒーを のみます (в 7 часов дома пью кофе). Проверь: точка времени → に, место действия → で, объект → を, глагол в конце."
check: manual
```

## Блок 6. Вопрос и приглашение

```drill
type: fill-in
prompt: "コーヒーを のみます___ (сделай вопрос)"
answer: か
check: exact
```

```drill
type: multiple-choice
prompt: "«いっしょに いきませんか。» — что это значит?"
options: [Ты не идёшь?, Не пойти ли нам вместе?, Я не пойду., Куда ты идёшь?]
answer: Не пойти ли нам вместе?
check: exact
hint: отрицательный вопрос = вежливое приглашение
```

```drill
type: multiple-choice
prompt: "Ты уже договорился и зовёшь идти. Что скажешь?"
options: [いきますか。, いきませんか。, いきましょう。, いきません。]
answer: いきましょう。
check: exact
```

```drill
type: translate
prompt: "Собери: Иду с другом. (ともだち — друг)"
answer: ともだちと いきます。 | ともだちといきます
check: fuzzy
```

```drill
type: free-form
prompt: "Составь три фразы: спроси, будет ли собеседник кофе; пригласи его пойти вместе; предложи «пойдёмте»."
answer: "Например: コーヒーを のみますか。 / いっしょに いきませんか。 / いきましょう。 (проверь: か в конце вопроса, 〜ませんか как приглашение, 〜ましょう как «давайте»)"
check: manual
```
