# Карточки

Спряжение `-ます`, частотные глаголы, частицы に/で/へ. Слова — кана + ромадзи-подсказка.

## Спряжение -ます

```card
front: "-ます: четыре базовые формы (на примере のみます)"
back: のみます (пью/буду), のみません (не пью), のみました (пил), のみませんでした (не пил)
tags: [conjugation]
```

```card
front: Настоящее и будущее в форме -ます — сколько форм?
back: одна! のみます = и «пью», и «буду пить». Отдельного будущего нет.
tags: [conjugation]
```

```card
front: Как сделать отрицание из -ます?
back: -ます → -ません (のみます → のみません)
tags: [conjugation]
```

```card
front: Как сделать прошлое из -ます?
back: -ます → -ました; отрицательное прошлое → -ませんでした
tags: [conjugation]
```

## Частицы に / で / へ

```card
front: Частица に — три роли?
back: направление (がっこうに いきます), точка времени (しちじに), место существования (に あります/います)
tags: [particle]
```

```card
front: Частица で — две роли?
back: место действия (としょかんで よみます), средство (でんしゃで いきます)
tags: [particle]
```

```card
front: に vs で — в чём разница?
back: に — точка (направление/нахождение, без действия); で — арена действия / средство
tags: [particle]
```

```card
front: Частица へ — что и как читается?
back: направление движения; читается E (にほんへ いきます — еду в Японию)
tags: [particle]
```

## あります / います — «есть, имеется»

```card
front: あります или います — как выбрать?
back: います — про живое, что двигается само (люди, животные); あります — про всё остальное (вещи, события). «Шевелится само → います»
tags: [existence]
```

```card
front: Какая частица у того, что существует?
back: "が, а не を: ほんが あります (есть книга), ねこが います (есть кошка)"
tags: [existence, ga]
```

```card
front: Шаблон «где что есть»?
back: "[место]に [предмет]が あります/います。 — つくえの うえに ほんが あります (на столе есть книга)"
tags: [existence]
```

```card
front: "\"У меня есть машина.\" — собрать"
back: わたしは くるまが あります。
tags: [existence]
```

```card
front: Отрицание от あります / います?
back: ありません / いません («нет, не имеется»)
tags: [existence]
```

## Вопрос и приглашение

```card
front: Как задать вопрос с глаголом?
back: "добавить か в конец: コーヒーを のみますか。 (будешь кофе?) — порядок слов не меняется"
tags: [ka]
```

```card
front: 〜ませんか — что это значит?
back: "вежливое приглашение «не хотите ли…»: いっしょに いきませんか。 (не пойти ли нам вместе?). Отрицание тут = вежливость"
tags: [invitation]
```

```card
front: 〜ましょう — что это значит?
back: "«давай(те)», предложение к совместному действию: いきましょう。 (пойдёмте)"
tags: [invitation]
```

```card
front: Разница между いきますか и いきましょう?
back: いきますか — «пойдёшь?» (спрашиваю); いきましょう — «пойдёмте» (уже зову)
tags: [invitation]
```

```card
front: Как вежливо отказаться от приглашения?
back: すみません、ちょっと… — «извините, я не очень…»; фразу не договаривают до конца, и это норма
tags: [invitation, phrase]
```

## と и から…まで

```card
front: "\"Иду с другом.\" — собрать"
back: ともだちと いきます。 (と — «с кем»)
tags: [particle]
```

```card
front: から … まで — что значит?
back: "«от … до», и для времени, и для места: くじから ごじまで (с 9 до 5), うちから がっこうまで (от дома до школы)"
tags: [particle]
```
