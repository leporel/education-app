# Карточки

Частицы как «теги ролей», формы `です`, опорная лексика. Слова — кана с ромадзи-подсказкой.

## Частицы (теги ролей)

```card
front: Частица は — что помечает и как читается?
back: тему предложения («что касается X»); читается WA (хотя пишется は)
tags: [particle]
```

```card
front: Частица が — что помечает?
back: подлежащее, особенно конкретное/новое и в вопросах «кто?» (だれが…)
tags: [particle]
```

```card
front: Частица を — что помечает и как читается?
back: прямой объект (на что направлено действие); читается O
tags: [particle]
```

```card
front: Частица の — что помечает?
back: "принадлежность: A の B = «B, принадлежащее A» (わたしの ほん — моя книга)"
tags: [particle]
```

```card
front: Где стоит сказуемое (глагол/です) в японском предложении?
back: "в самом КОНЦЕ (порядок SOV: тема — объект — сказуемое)"
tags: [structure]
```

## です и его формы

```card
front: です — что это и где стоит?
back: связка «есть/является» (как am/is/are), не спрягается по лицам, стоит в конце
tags: [desu]
```

```card
front: "です: отрицание «не является»?"
back: では ありません (разг. じゃ ありません)
tags: [desu]
```

```card
front: "です: прошедшее «был»?"
back: でした
tags: [desu]
```

```card
front: "\"Я студент.\" — собрать"
back: わたしは がくせいです。 (watashi-wa gakusei desu)
tags: [desu, sentence]
```

## Сборка

```card
front: Базовый шаблон предложения с действием?
back: "[тема]は [объект]を [глагол]。 — например わたしは ほんを よみます (Я книгу читаю)"
tags: [structure]
```

```card
front: "\"Это моя книга.\" — собрать"
back: これは わたしの ほんです。 (kore-wa watashi-no hon desu)
tags: [sentence]
```

```card
front: Почему в "みずを のみます" нет подлежащего?
back: оно опущено (скрытое/ゼロ-подлежащее) — понятно из контекста, что «я». Японский договаривает контекстом.
tags: [structure]
```

## Вопрос か и вопросительные слова

```card
front: Как сделать из утверждения вопрос?
back: добавить か в конец; порядок слов НЕ меняется. これは ペンです。→ これは ペンですか。
tags: [ka, question]
```

```card
front: Почему в японском тексте нет вопросительного знака?
back: его роль играет частица か в конце предложения (в неформальной переписке ？ встречается)
tags: [ka, question]
```

```card
front: なに / なん — что и когда какое?
back: "«что»; перед です — なん: これは なんですか。 (что это?)"
tags: [question-word]
```

```card
front: だれ / どこ / いつ / いくら / どう
back: кто / где / когда / сколько стоит / как
tags: [question-word]
```

```card
front: Где стоит вопросительное слово в японском вопросе?
back: там же, где стояло бы обычное слово, с той же частицей (в отличие от английского, где оно выпрыгивает вперёд)
tags: [question-word]
```

```card
front: だれ___ きましたか — は или が?
back: "が. Вопросительное слово в роли подлежащего берёт が: は помечает известное, а вопрос — это неизвестное"
tags: [question-word, ga]
```

```card
front: Как ответить «да, так и есть» / «нет, не так»?
back: はい、そうです。 / いいえ、ちがいます。
tags: [question, phrase]
```

## も / と / ね / よ

```card
front: Частица も — что значит и как ставится?
back: "«тоже»; ЗАМЕНЯЕТ は/が, а не дополняет: たなかさんも がくせいです (❌ たなかさんはも)"
tags: [mo]
```

```card
front: Частица と — две роли?
back: «и» между существительными (ねこと いぬ) и «с» (ともだちと いきます). Предложения ею не соединяют
tags: [to]
```

```card
front: ね и よ в конце фразы — разница?
back: ね — «правда ведь?», ищет согласия (おいしいですね); よ — «имей в виду», сообщает новое (おいしいですよ)
tags: [ne-yo]
```

## Указатели こそあど

```card
front: これ / それ / あれ / どれ
back: это (у меня) / то (у тебя) / вон то (далеко от обоих) / который? — три степени вместо русских двух
tags: [kosoado]
```

```card
front: この / その / あの / どの — чем отличаются от これ/それ/あれ?
back: "требуют существительное после себя: この ほんは… (эта книга…). これ стоит само: これは ほんです"
tags: [kosoado, trap]
```

```card
front: ここ / そこ / あそこ / どこ
back: здесь / там (у тебя) / вон там / где?
tags: [kosoado]
```

```card
front: そうです / そうですか
back: «да, именно так» / «вот как?» — две самые ходовые реплики диалога
tags: [kosoado, phrase]
```

```card
front: "\"Дайте вон то (что у продавца).\" — собрать"
back: それを ください。
tags: [kosoado, phrase]
```

## Обращения

```card
front: Суффикс さん — что значит и к кому?
back: "вежливое «господин/госпожа» к фамилии, без различия пола: たなかさん. К себе НИКОГДА не ставится"
tags: [address]
```

```card
front: Как представиться, если фамилия Танака?
back: わたしは たなかです。 (без さん — иначе звучит «я господин Танака»)
tags: [address, trap]
```

```card
front: Почему не говорят あなた?
back: звучит слишком в лоб; вместо него зовут по фамилии с さん или вообще опускают обращение. Чем меньше местоимений — тем вежливее
tags: [address, trap]
```

```card
front: Как обратиться к учителю или врачу?
back: "せんせい вместо さん: やまだせんせい"
tags: [address]
```

## Термины простыми словами

```card
front: Что такое частица (в японском)?
back: короткое служебное слово ПОСЛЕ слова, вешающее на него ярлык роли (は тема, を объект). Своего перевода обычно нет
tags: [term]
```

```card
front: Чем тема отличается от подлежащего?
back: тема (は) — рамка «про что говорим»; подлежащее (が) — кто действует внутри неё. Русское «Слонов-то я видел» устроено по-японски
tags: [term]
```

```card
front: Что такое SOV?
back: порядок «подлежащее — объект — сказуемое». Английский SVO (глагол в середине), японский SOV (глагол в конце)
tags: [term]
```

```card
front: Японские точка, запятая, кавычки?
back: 。 、 「 」
tags: [term, punctuation]
```
