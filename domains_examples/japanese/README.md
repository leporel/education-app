# Японский язык

Японский с абсолютного нуля до уровня «начинающий→средний иностранец»: бегло читать
кану, понимать базовую грамматику и **читать простой текст со смыслом**. Цель — втянуться
в язык и почувствовать его логику, а не достичь беглости и не готовиться к JLPT.

## Файлы

- [`CLAUDE.md`](./CLAUDE.md) — инструкции для Claude по этому домену.
- [`memory.md`](./memory.md) — память: что выучено, слабости, рабочие приёмы.
- [`roadmap.md`](./roadmap.md) — план обучения.
