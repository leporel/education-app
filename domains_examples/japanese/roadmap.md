# План обучения

Упорядоченный план модулей. Статусы: `todo` / `in-progress` / `done`.
План — не догма: можно менять порядок, вставлять модули, резать лишние. Каждый модуль —
самостоятельный слайс на одну-несколько сессий.

## Этап 1. Письменность (без неё ничего не прочитать)

- [ ] [`01-hiragana`](./modules/01-hiragana/index.md) — хирагана: слоговой принцип,
      таблица годзюон (46 знаков), дакутэн/хандакутэн, ёон, сокуон `っ`, долгие гласные,
      базовое произношение (проглатывание `у`/`и`, `ん`, тон), чтение первых слов —
      **todo**.
- [ ] [`02-katakana`](./modules/02-katakana/index.md) — катакана: заимствования и имена,
      знак долготы `ー`, похожие пары, расширенная катакана для чужих звуков
      (`ファ`, `ティ`, `シェ`), контраст с хираганой — **todo**.

## Идеи на потом

- Счётные суффиксы вглубь — первые пять (`〜円`, `〜時`, `〜分`, `〜人`, `〜つ`) уже даны в
  модуле 06; дальше — `〜本`, `〜枚`, `〜匹`, `〜台` и логика выбора категории.
- て-форма глагола — узел, из которого растёт половина грамматики (просьбы `〜てください`,
  длительность `〜ている`, соединение действий). Сейчас её учат только **узнавать** при
  чтении (модуль 08); для построения нужен отдельный модуль.
- Простая (словарная) форма и регистры (です/ます vs だ/する) — сейчас на узнавание
  (модуль 08); для активного употребления нужен свой модуль, желательно вместе с て-формой.
- `〜たい` («хочу сделать»), `〜ことができます` («умею») — базовые желания и возможности.
- Расширение кандзи до ~300 частотных (отдельный длинный трек, если затянет).
